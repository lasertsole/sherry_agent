# 计划：直播安全过滤器（关键词 + LLM 审查 + 流式截断）

- 建档日期：2026-10-09
- 状态：**计划（未开工）**
- 触发问题：sherry 的输出流（model → WS → 前端）中间**没有任何内容过滤器**。直播 / 演示场景下，模型生成什么用户就看到什么。当前唯一保护是 LLM provider 自己的安全策略（被动检测 `content_filter`），sherry 自身不做任何过滤

## 市面上怎么做的

千问网页版 / DeepSeek 网页版 / 豆包网页版的通用模式是**四层防线**：

| 层 | 干什么 | 延迟 | sherry 能做吗 |
|---|---|---|---|
| ① 关键词预过滤 | 输入 + 输出做 regex/字符串匹配，命中即拦截 | <1ms | ✅ 可做 |
| ② LLM 内容审查 | 用小模型/辅助 LLM 判定"这条输入/输出是否敏感" | 0.5-2s | ✅ 有 auxiliary LLM |
| ③ 模型内置安全 | RLHF/SFT 训练时植入的安全对齐（模型自己拒绝） | 0 | ❌ 无法训练自己的模型 |
| ④ 流式截断 | streaming 时按窗口缓冲扫描，敏感词出现即切断 + 替换 | 实时 | ✅ 可做（stream_dispatch） |

sherry 无法做第③层（不能训练自己的模型），但①②④都可以做。第③层靠 provider 自己的对齐（sherry 已有的 `content_filter` 检测 + `llm_retry` fallback 是对这层的被动响应）。

## 设计

### 核心架构：直播模式开关 + 三层过滤

```
用户消息 → [①输入关键词过滤] → 模型 → [④流式窗口扫描] → WS → 前端
                              ↑                    ↓
                     [②LLM 输出审查] ← [①输出关键词过滤]
```

**直播模式**（per-session 开关，前端菜单"直播安全"）：
- 开 = ① + ② + ④ 全开
- 关 = 全关（当前行为，无回归）

### Layer ①：关键词预过滤（快速，<1ms）

#### 关键词表

- **不捆绑**——sherry 不自带任何敏感词表（法律风险）。提供**基础设施**，用户自行导入关键词表
- 文件位置：`workspace/sensitive_words.json`
- 格式：

```json
{
  "version": 1,
  "rules": [
    {
      "pattern": "具体关键词",
      "type": "exact",           // exact | regex | contains
      "action": "block",         // block | replace | warn
      "replacement": "[内容已过滤]",  // action=replace 时用
      "scope": "both"            // input | output | both
    },
    {
      "pattern": "某.*词",
      "type": "regex",
      "action": "block",
      "scope": "output"
    }
  ]
}
```

- 支持三种匹配：`exact`（精确匹配）、`contains`（子串包含）、`regex`（正则）
- 三种动作：`block`（拦截，不输出）、`replace`（替换为 replacement 文本）、`warn`（放行但 WS 通知前端）
- 两种范围：`input`（扫用户输入）、`output`（扫模型输出）、`both`（两者都扫）
- 加载时编译 regex 为 `re.Pattern`，缓存编译结果
- 热重载：文件 mtime 变化时重新加载（不阻塞 turn）

#### 输入过滤中间件（`before_model` hook）

`agent/middlewares/safety_filter/input_filter.py`：

```python
class InputSafetyFilter(BaseModelMiddleware):
    """before_model: 扫描用户输入，命中 block 规则时拦截并返回安全拒绝。"""

    def abefore_model(self, state, runtime=None):
        if not _is_live_mode(state):
            return  # 直播模式关 → 放行
        last_msg = _last_human_message(state)
        if not last_msg:
            return
        hits = _scan(last_msg.content, scope="input")
        if not hits:
            return
        block_hits = [h for h in hits if h.action == "block"]
        if block_hits:
            # 拦截：不调模型，直接返回安全拒绝
            return _safe_refusal(block_hits)
        # warn/replace：记录但放行（replace 在输出端处理）
        _notify_frontend(state, hits)
```

- 命中 `block` → **不调模型**，直接返回"抱歉，我无法回答这个问题"（省 token + 零延迟）
- 命中 `warn` → 放行 + WS 通知前端"输入命中 N 条规则"
- 命中 `replace` → 输入端不改（输入是用户发的），只在输出端替换

#### 输出过滤中间件（`after_model` hook）

`agent/middlewares/safety_filter/output_filter.py`：

```python
class OutputSafetyFilter(BaseModelMiddleware):
    """after_model: 扫描模型完整输出，命中规则时替换或拦截。"""

    def aafter_model(self, state, runtime=None):
        if not _is_live_mode(state):
            return
        last_msg = _last_ai_message(state)
        if not last_msg:
            return
        hits = _scan(last_msg.content, scope="output")
        if not hits:
            return
        block_hits = [h for h in hits if h.action == "block"]
        replace_hits = [h for h in hits if h.action == "replace"]
        if block_hits:
            _replace_ai_content(state, "[该内容已被安全过滤拦截]")
        elif replace_hits:
            new_content = _apply_replacements(last_msg.content, replace_hits)
            _replace_ai_content(state, new_content)
        _notify_frontend(state, hits)
```

- `after_agent` 钩子运行在**逆序**——注册在 HITL 之后（最先执行），在 MessagePersistence 之前拦截
- 命中 `block` → 整条 AI 消息替换为 "[该内容已被安全过滤拦截]"
- 命中 `replace` → 只替换命中部分，保留其余内容
- 命中 `warn` → 内容不变 + WS 通知

### Layer ②：LLM 内容审查（可选，较慢）

#### 输入审查

`agent/middlewares/safety_filter/llm_moderation.py`：

```python
class LLMModerationFilter(BaseModelMiddleware):
    """before_model: 用辅助 LLM 判定输入是否敏感。可配置为 always / on-keyword-hit。"""

    def abefore_model(self, state, runtime=None):
        if not _is_live_mode(state):
            return
        mode = SAFETY_FILTER["llm_moderation_mode"]  # "off" | "always" | "on_keyword_hit"
        if mode == "off":
            return
        last_msg = _last_human_message(state)
        if not last_msg:
            return
        if mode == "on_keyword_hit":
            hits = _scan(last_msg.content, scope="input")
            if not hits:
                return  # 关键词没命中 → 不调 LLM 审查（省 token）
        # 调辅助 LLM
        verdict = await _moderate(last_msg.content)
        if verdict == "unsafe":
            return _safe_refusal(...)
```

审查 prompt：

```
你是一个内容安全审查员。判断以下用户消息是否包含政治敏感、违法违规、
或不适合在直播场景公开展示的内容。只回答 JSON：{"safe": true/false, "reason": "..."}。
```

- 用 auxiliary LLM（temperature=0），已有基础设施
- `mode="always"` → 每条输入都审查（+0.5-2s 延迟）
- `mode="on_keyword_hit"` → 关键词命中后才调 LLM（省 token，关键词是快筛）
- `mode="off"` → 不做 LLM 审查（只靠关键词）

#### 输出审查（可选，非流式时）

非流式模式下，`after_model` 可以调辅助 LLM 审查完整输出。流式模式下走 Layer ④。

### Layer ④：流式截断（实时，直播核心）

`server/service/stream_dispatch.py` 修改——在 streaming 输出路径加窗口扫描：

```python
# StreamTurn.run() 的 text delta 发射循环
_buffer = ""
_BUFFER_WINDOW = 20  # 每 20 个字符扫一次

for delta in stream:
    chunk_text = delta.text or ""
    if _is_live_mode(session_id):
        _buffer += chunk_text
        if len(_buffer) >= _BUFFER_WINDOW:
            hits = _scan_stream(_buffer, scope="output")
            if hits and any(h.action == "block" for h in hits):
                # 截断：不发送剩余内容，替换为安全消息
                yield _safe_replacement_frame()
                _notify_stream_cut(session_id, hits)
                break  # 停止流式
            elif hits and any(h.action == "replace" for h in hits):
                chunk_text = _apply_replacements(_buffer, hits)
                _buffer = ""  # 重置缓冲
            else:
                _buffer = ""  # 清缓冲，继续
    yield _text_frame(chunk_text)  # 正常发送
```

- **窗口缓冲**：积累 20 字符后扫描一次（平衡延迟和 CPU）
- **命中 block**：立即停止流式，发送安全替换帧（"该内容已被安全过滤拦截"）
- **命中 replace**：替换命中部分，继续流式
- **命中 warn**：内容不变 + WS 通知
- **缓冲尾部**：流结束时扫描剩余缓冲（< 20 字符的部分）

### 扫描器实现

`agent/middlewares/safety_filter/scanner.py`（~100 行）：

```python
@dataclass(frozen=True, slots=True)
class FilterHit:
    pattern: str
    matched_text: str
    action: str       # block | replace | warn
    replacement: str
    scope: str        # input | output | both

@dataclass(slots=True)
class CompiledRule:
    pattern: re.Pattern | str
    action: str
    replacement: str
    scope: str
    match_type: str   # exact | contains | regex

_rules: list[CompiledRule] = []
_loaded_mtime: float = 0

def _load_rules() -> None:
    """热重载：文件 mtime 变化时重新编译。"""
    global _rules, _loaded_mtime
    path = WORKSPACE_DIR / SAFETY_FILTER["keyword_file"]
    if not path.is_file():
        _rules = []
        return
    mtime = path.stat().st_mtime
    if mtime == _loaded_mtime:
        return
    data = json.loads(path.read_text(encoding="utf-8"))
    _rules = [_compile(r) for r in data.get("rules", [])]
    _loaded_mtime = mtime

def scan(text: str, *, scope: str) -> list[FilterHit]:
    """扫描文本，返回所有命中。"""
    _load_rules()  # 热重载检查
    hits = []
    for rule in _rules:
        if scope not in (rule.scope, "both"):
            continue
        matched = _match(rule, text)
        if matched:
            hits.append(FilterHit(
                pattern=rule.pattern if isinstance(rule.pattern, str) else rule.pattern.pattern,
                matched_text=matched,
                action=rule.action,
                replacement=rule.replacement,
                scope=rule.scope,
            ))
    return hits

def scan_stream(buffer: str, *, scope: str = "output") -> list[FilterHit]:
    """流式扫描：同 scan 但针对部分缓冲（可能匹配到半截词）。"""
    return scan(buffer, scope=scope)
```

## 验收

- 直播模式关 → 所有中间件 early-return，零开销（当前行为，无回归）
- 直播模式开 + 输入命中 block → 不调模型，直接返回"抱歉，我无法回答这个问题"
- 直播模式开 + 输出命中 block → 整条 AI 消息替换为 "[该内容已被安全过滤拦截]"
- 直播模式开 + 输出命中 replace → 命中部分被替换，其余保留
- 直播模式开 + 流式输出命中 block → 流式截断，发送安全替换帧
- LLM 审查 mode=on_keyword_hit → 关键词没命中时不调 LLM（省 token）
- 关键词文件热重载 → 不重启即生效
- 前端有"直播安全"菜单入口 + sidebar tab（开关 + 关键词管理 + LLM 设置 + 过滤日志）
- WS `safety_filter` 帧在过滤时推送，前端显示 banner/toast
- `workspace/sensitive_words.json` 空模板不预填任何关键词

## 不做的事

- **不捆绑任何关键词表**——sherry 只提供过滤基础设施，用户自行导入关键词表（法律安全）
- **不训练自己的安全模型**——第③层（模型内置对齐）靠 provider 自己
- **不做输入端的 replace**——输入是用户发的，不修改用户消息；replace 只在输出端
- **不做图像/语音过滤**——只过滤文本；多媒体内容靠 `media_pipeline` 和 provider 自己的策略
- **不做敏感词表的网络更新/同步**——用户手动管理 `workspace/sensitive_words.json`
