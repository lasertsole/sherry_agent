# SDD 规格 S7：未实现界面占位（四语言）

- 日期：2026-11-17
- 状态：**待评审**
- 定位：UI 升级中，功能导航项已注册但后端/组件未实现时，显示"暂未实现，敬请期待"占位。四语言 i18n。
- 依赖：S1（左栏导航注册表）

## 1. 场景

S1-S6 分阶段实施。某个导航项（如 S4 会议）已注册到左栏（图标出现），但后端 API / 组件尚未实现。用户点击后应看到友好的占位提示，而不是空白或报错。

```

│              │
└──────────────┘
```

## 4. 使用方式

在 nav store 注册导航项时，如果后端/组件未就绪，用 `NotImplementedPanel` 作为占位：

```typescript
// stores/nav.ts
import NotImplementedPanel from '~/components/NotImplementedPanel.vue'

const items = ref<NavItem[]>([
  { id: 'chat', icon: 'pi-comments', labelKey: 'nav.chat', component: () => import('./nav/SessionListPanel.vue'), scope: 'global' },
  { id: 'files', icon: 'pi-folder', labelKey: 'nav.files', component: () => import('./nav/FilesPanel.vue'), scope: 'session' },

  // S2 专家库——后端 API 就绪后替换为真实组件
  { id: 'experts', icon: 'pi-users', labelKey: 'nav.experts', component: NotImplementedPanel, scope: 'global' },

  // S3 任务看板——后端 API 就绪后替换
  { id: 'tasks', icon: 'pi-list-check', labelKey: 'nav.tasks', component: NotImplementedPanel, scope: 'global' },

  // S4 会议——后端 API 就绪后替换
  { id: 'meetings', icon: 'pi-video', labelKey: 'nav.meetings', component: NotImplementedPanel, scope: 'global' },
])
```

**切换为真实组件**：后端就绪后，把 `component: NotImplementedPanel` 改为 `component: () => import('./nav/ExpertListPanel.vue')`。导航项的 id/icon/label/scope 不变——用户无感知切换。
