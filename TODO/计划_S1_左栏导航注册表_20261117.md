## 2. 目标架构

### 2.1 新建 nav store

**文件**：`client/app/stores/nav.ts`（新建）

```typescript
import type { Component } from 'vue'

export interface NavItem {
  id: string                    // 唯一标识
  icon: string                  // PrimeIcons name（'pi-comments' 等）
  labelKey: string              // i18n key（'nav.chat' 等）
  component: Component          // 左栏内容组件
  scope: 'global' | 'session'   // global=不绑定 session；session=绑定当前 session
  badge?: () => number           // 动态 badge（可选，如未读会议数）
  minWidth?: number             // 该导航项需要的最小左栏宽度（默认 280）
}

export const useNavStore = defineStore('nav', () => {
  // 导航项注册表
  const items = ref<NavItem[]>([
    {
      id: 'chat',
      icon: 'pi-comments',
      labelKey: 'nav.chat',
      component: () => import('./nav/SessionListPanel.vue'),
      scope: 'global',
    },
    {
      id: 'files',
      icon: 'pi-folder',
      labelKey: 'nav.files',
      component: () => import('./nav/FilesPanel.vue'),
      scope: 'session',
    },
  ])

  // 当前激活的导航项
  const activeId = ref<string>('chat')

  // 激活某个导航项
  function activate(id: string) {
    if (items.value.some(i => i.id === id)) {
      activeId.value = id
    }
  }

  // 注册新导航项（S2/S3/S4 用）
  function register(item: NavItem) {
    if (!items.value.some(i => i.id === item.id)) {
      items.value.push(item)
    }
  }

  // 注销导航项
  function unregister(id: string) {
    items.value = items.value.filter(i => i.id !== id)
  }

  // 当前激活的 NavItem
  const activeItem = computed(() =>
    items.value.find(i => i.id === activeId.value)
  )

  // 持久化 activeId
  persistedState(activeId, 'nav-active')

  return { items, activeId, activeItem, activate, register, unregister }
})
```

### 2.2 重构 SessionSidebar.vue

**文件**：`client/app/pages/home/components/SessionSidebar.vue`

重构后 template：

```vue
<template>
  <div class="session-sidebar" :style="{ width: width + 'px' }">
    <!-- Logo 行（不变）-->
    <div class="logo-row">🍊 {{ defaultAiName }}</div>

    <!-- 导航图标行（新）-->
    <div class="nav-icons flex gap-1 px-2 py-1">
      <button
        v-for="item in nav.items"
        :key="item.id"
        :class="{ active: item.id === nav.activeId }"
        @click="nav.activate(item.id)"
        :title="t(item.labelKey)"
      >
        <i :class="item.icon" />
        <span v-if="item.badge?.()" class="badge">{{ item.badge() }}</span>
      </button>
    </div>

    <!-- 导航内容区（动态组件）-->
    <div class="nav-content flex-1 overflow-hidden">
      <KeepAlive>
        <component :is="nav.activeItem?.component" />
      </KeepAlive>
    </div>
  </div>
</template>
```

**关键变化**：
- 删掉 `v-if="ui.sidebarBody === 'sessions'"` / `v-else-if="ui.sidebarBody === 'files'"`
- 改为 `<component :is="nav.activeItem?.component">` 动态渲染
- 加 `<KeepAlive>` 保持各导航项状态（会话列表滚动位置/筛选条件不丢）
- 导航图标行数据驱动——`v-for="item in nav.items"`

## 4. 验收标准

| # | 场景 | 预期 |
|---|------|------|
| 1 | 打开 Sherry | 左栏显示 logo + 导航图标行（💬 📁）+ 会话列表 |
| 2 | 点 📁 图标 | 左栏内容切换为文件树 + Git（行为同当前 `body='files'`） |
| 3 | 点 💬 图标 | 左栏内容切换回会话列表（行为同当前 `body='sessions'`） |
| 4 | 在会话列表滚动 + 筛选 → 切到 📁 → 切回 💬 | 会话列表滚动位置 + 筛选条件保持（KeepAlive） |
| 5 | files + git 都展开 + Splitter 拖拽 | Splitter 行为不变（比例 persisted） |
| 6 | 左栏折叠/展开 | 行为不变（`sidebarCollapsed`） |
| 7 | 左栏宽度拖拽 | 行为不变（`sidebar-width` store） |
| 8 | 浮窗模式 | 行为不变（浮窗不影响左栏导航） |
| 9 | 右栏 tab | 行为不变（右栏不受左栏导航影响） |
| 10 | `nav.register(item)` 注入新导航项 | 图标行立即出现新图标 + 可点击切换 |

## 5. 风险

| 风险 | 缓解 |
|------|------|
| KeepAlive 导致内存增长（多个导航项组件不卸载） | 限制 max="5"（LRU 淘汰），会话列表和文件树优先保留 |
| 抽取 SessionListPanel 时遗漏 composable 依赖 | 抽取后跑现有前端测试（`pnpm test:unit` + `pnpm test:integration`） |
| 导航图标行在窄屏（<280px 左栏）太挤 | 图标行 `flex-wrap: nowrap` + `overflow-x: auto` 横向滚动；或 <280px 时收为汉堡菜单 |
| `ui.sidebarBody` 被其他组件引用 | grep `sidebarBody` 全前端，确保只改 SessionSidebar + toolbar |
