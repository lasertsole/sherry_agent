## 0. 背景（已核实）

### 0.1 sherry 现状

sherry **无 onboarding**。首次启动 → `NewSessionPresetDialog` 强制选预设 → 直接进对话页。新用户面对工具栏九宫格 + 右栏 20+ tab 会迷茫。`NewSessionPresetDialog`（`:85-88`）已列出四个内置预设（纯净/编程助手/情感陪伴/全量），`confirm()`（`:110-160`）是创建编排器。`persona-catalog.ts` 的 `BUILTIN_PRESETS`（`:60-85`）+ `loadPresetPayload`（`:407-443`）已有完整预设解析。

### 0.2 ZCode 做法

ZCode 的 `onboarding/` 有欢迎页、职业网格、模式选择、AGENTS.md 迁移步骤，ASCII/mesh 视觉。`useOnboardingTrigger.ts` 控制触发。

## 2. 任务一：引导流程设计

### 2.1 目标

3-4 步引导，覆盖核心概念。

### 2.2 步骤设计

- **步骤 1：欢迎** — sherry 简介 + "开始"按钮 + "跳过"链接
- **步骤 2：选预设** — 复用 `BUILTIN_PRESETS`，每个预设带一句话说明（纯净=无预设配置 / 编程助手=代码任务 / 情感陪伴=角色扮演 / 全量=全部能力），选择后进入步骤 3
- **步骤 3：核心操作指引** — 图文/动图说明：
  - 发消息（输入框 + Enter 发送）
  - 工具栏（模型切换/模式/思考/项目目录）
  - 右栏（设置 tab 简介）
  - turn 折叠（点击摘要展开看执行流程）
- **步骤 4：完成** — "开始使用" → 调用 `NewSessionPresetDialog.confirm()` 创建会话

## 3. 任务二：引导组件

### 3.1 目标

新建引导弹窗组件，多步 + 可跳过。

### 3.2 改动清单

- [ ] **3.2.1** 新建 `client/app/components/OnboardingDialog.vue`：
  - PrimeVue `Dialog`（`modal` true，`dismissableMask: false`——必须走完或跳过）
  - 多步：用 `step` ref + `<Transition>` 切换
  - 每步：标题 + 内容 + "下一步"/"上一步"/"跳过"按钮
  - 步骤 2 复用 `persona-catalog.ts` 的 `catalogEntries` + `entryName`
  - 步骤 3 用图文卡片（icon + 一句话 + 可选动图/GIF）

- [ ] **3.2.2** 首次启动检测：
  - Dexie `db.ts` v4 bump，新增 `appFlags` 表：`'key'`（PK），存 `{key: 'onboarding_completed', value: true}`
  - `client/app/composables/use-app-flags.ts`：`getFlag(key)` / `setFlag(key, value)`
  - `index.vue` 启动时 `getFlag('onboarding_completed')`——未完成则显示引导

- [ ] **3.2.3** 引导完成 → 创建会话：
  - 步骤 4 调 `NewSessionPresetDialog` 的 `confirm()` 逻辑（`persona-catalog.ts:110-160`）

  - `setFlag('onboarding_completed', true)`

- [ ] **3.2.4** 跳过引导：
  - 每步"跳过" → `setFlag('onboarding_completed', true)` → 关闭 → 打开 `NewSessionPresetDialog`（现有行为）

- [ ] **3.2.5** i18n：四语言增 `onboarding.*` 键

**验收**：F2 + F3 + F4。
