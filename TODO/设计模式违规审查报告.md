# 设计模式违规审查报告

- 审查日期：2026-10-08
- 范围：全仓库（`agent/` `server/` `runtime/` `pub/` `config/` `context_engine/` `workspace/` `skills/` `models/`）

## 四、中间件模式不一致

### M1. Hook 签名四种写法

| 签名风格 | 中间件 |
|---|---|
| `(self, state: AgentState, runtime: Runtime)` | context_eviction、tool_call_normalize、HITL、media_pipeline、tool_guardrails、summarization |
| `(self, state, runtime=None)` | subagent_drain、task_intent、todo_continuation |

- **基类约定**：`base.py` mixin 是 `(self, state: Any, runtime: Any = None) -> None`
- **修复**：统一一种签名（typed-with-default 最安全），至少给 bare-`state` 的加上 `state: AgentState` 注解。

### M2. `TodoContinuationEnforcer` 只有 async `aafter_agent`，无 sync `after_agent`

- **文件**：`todo_continuation/core.py:239`
- **问题**：若 sync 路径执行，hook 静默不工作
- **修复**：加 sync 版或文档声明 production async-only。

## 十五、单例模式不一致

### SG1. 三种单例写法，线程安全性不一

| 写法 | 代表 | 线程安全 |
|---|---|---|
| `__new__` + RLock | `SessionRegister`（`runtime/session/core.py:7-19`） | ✅ |
| `global _x` 无锁 | `get_lane_manager()`（`lane/core.py:226`）、`get_config()`（`subagent/config.py:59`）、`get_browser_manager()`（`browser_manager.py:828`） | ❌ 竞态 |
| 模块级 eager | `state_register_mem = StateRegisterMeM()` 等 ~12 处 | ✅（GIL）但无法 reset |

- **修复**：统一到 `__new__`+lock 模式（或 `get_X()` + `threading.Lock`），给三个无锁 lazy global 加锁。

## 已确认无违规（不需修改）

| 维度 | 结论 |
|---|---|
| DIP（依赖反转） | `runtime/hooks.py` + `runtime/data_provider.py` seam 设计正确，无直接跨禁令导入 |
| 导入禁令 | agent↛server、config↛models、context_engine↛agent、workspace↛agent/context_engine、skills↛server——零违反 |
| TypedDict 全量 re-export | 35 agent_side + 24 infra_side 全部通过 `__init__.py` 导出 |
| `scope: "main_only"` | 所有 main-only 工具一致标记 |
| `runtime/` 边界 | 不 import langchain/langgraph，干净 |
| Repository 基类 | taskflow/todolist/subagent/auth 四个 store 正确继承，只覆写 DDL hooks |
