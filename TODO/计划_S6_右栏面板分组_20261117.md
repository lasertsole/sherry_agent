- 日期：2026-11-17
- 状态：**待评审**
- 定位：右栏 26 种 tab 按功能分组 + 搜索，解决"找东西困难"。

- 改动量：~200 行

## 1. 当前

**文件**：`client/app/stores/right-sidebar.ts`

右栏有 26 种 panel kind（`RightSidebarPanelKind`），全部平铺在 tab 行里：

```
logs | stats | knowledgeGraph | skills | systemConfig | persona | memory |
heartbeat | cron | extend | webSearch | fileViewer | account | notification |
sessionPreset | subagentActivity | taskFlowBoard | sessionActivity | gitDiff |
contextViewer | trajectory | tokenBudget | browser | terminal | whiteboard | sideChat
```

tab 行可滚动，但 26 个 tab 没有分类——找特定面板靠记忆或滚动扫描。

### 当前 tab 生命周期

- `openTab(kind, payload?)` — 去重 + 激活 + 展开
- `closeTab(id)` — 邻居激活
- tab 行在 `RightSidebar.vue` header strip 渲染，可滚动，有 fade mask
- `recentClosed` 最近关闭列表（下拉菜单恢复）

---

## 2. 目标

26 种 tab 按功能分 3 组 + 搜索框。打开 tab 时先选分组，再在分组内选面板。

### 分组定义

```typescript
type PanelGroup = 'session' | 'tools' | 'config'

const PANEL_GROUPS: Record<PanelGroup, { labelKey: string; icon: string; kinds: RightSidebarPanelKind[] }> = {
  session: {
    labelKey: 'rightSidebar.group.session',
    icon: 'pi pi-comments',
    kinds: [
      'sideChat', 'subagentActivity', 'taskFlowBoard', 'sessionActivity',
      'sessionPreset', 'gitDiff', 'contextViewer', 'trajectory', 'tokenBudget',
      'fileViewer',
    ],
  },
  tools: {
    labelKey: 'rightSidebar.group.tools',
    icon: 'pi pi-bolt',
    kinds: [
      'browser', 'terminal', 'whiteboard', 'webSearch', 'extend',
    ],
  },
  config: {
    labelKey: 'rightSidebar.group.config',
    icon: 'pi pi-cog',
    kinds: [
      'systemConfig', 'persona', 'memory', 'heartbeat', 'cron',
      'skills', 'knowledgeGraph', 'logs', 'stats', 'account',
      'notification',
    ],
  },
}
```

### UI 变化

```
当前右栏 tab 行：
┌──────────────────────────────────────────────────────┐
│ [侧聊][子Agent][任务流][Git Diff][上下文][Trajectory] │ ← 26 个平铺可滚动
│ [Token][浏览器][终端][白板][系统][角色][记忆][技能]... │
└──────────────────────────────────────────────────────┘

目标右栏 tab 行：
┌──────────────────────────────────────────────────────┐
│ [会话] [工具] [配置]  🔍[搜索面板...]                 │ ← 分组 + 搜索
│ [侧聊][子Agent][任务流]  ← 当前分组的已打开 tab       │ ← 只显示当前分组
└──────────────────────────────────────────────────────┘

点击分组 → 切换显示该分组的 tab
搜索 → 跨所有分组搜索面板名 → 选中后打开
```

### 已打开 tab 的显示逻辑

当前：所有已打开的 tab 平铺在 tab 行。
目标：只显示**当前分组**的已打开 tab。切换分组 → tab 行内容切换。

但已打开的 tab 不丢失——切回原分组还在。`tabs[]` 数组不变，只是 tab 行渲染时按当前分组过滤。

## 3. 改动

### 3.1 right-sidebar store 加分组状态

**文件**：`client/app/stores/right-sidebar.ts`

```typescript
// 新增
type PanelGroup = 'session' | 'tools' | 'config'

const activeGroup = ref<PanelGroup>('session')

// 根据 kind 查所属分组
function groupOfKind(kind: RightSidebarPanelKind): PanelGroup {
  for (const [group, def] of Object.entries(PANEL_GROUPS)) {
    if (def.kinds.includes(kind)) return group as PanelGroup
  }
  return 'config'  // fallback
}

// 当前分组下已打开的 tab
const groupTabs = computed(() =>
  tabs.value.filter(t => groupOfKind(t.kind) === activeGroup.value)
)

// 打开 tab 时自动切到对应分组
function openTab(kind, payload?) {
  // ... 现有逻辑 ...
  activeGroup.value = groupOfKind(kind)  // 自动切到 tab 所属分组
}

// 搜索面板
function searchPanels(query: string): { kind: RightSidebarPanelKind; labelKey: string; group: PanelGroup }[] {
  if (!query) return []
  const q = query.toLowerCase()
  return ALL_PANELS
    .filter(p => t(p.labelKey).toLowerCase().includes(q))
    .map(p => ({ ...p, group: groupOfKind(p.kind) }))
}
```

### 3.2 RightSidebar.vue tab 行重构

**文件**：`client/app/pages/home/components/RightSidebar.vue`

```vue
<template>
  <!-- header strip -->
  <div class="header-strip">
    <RecentClosedTabsMenu />

    <!-- 分组切换（新）-->
    <div class="group-tabs flex gap-1">
      <button
        v-for="(def, key) in PANEL_GROUPS"
        :key="key"
        :class="{ active: rightSidebar.activeGroup === key }"
        @click="rightSidebar.activeGroup = key"
      >
        <i :class="def.icon" />
      </button>
    </div>

    <!-- 搜索框（新）-->
    <AutoComplete
      v-model="searchQuery"
      :suggestions="searchResults"
      @complete="onSearch"
      @item-select="onSelectPanel"
      :placeholder="t('rightSidebar.searchPanel')"
      class="search-input"
    />

    <MaximizeButton />
  </div>

  <!-- tab 行：只显示当前分组的 tab -->
  <div class="tab-row">
    <TabButton
      v-for="tab in rightSidebar.groupTabs"
      :key="tab.id"
      :tab="tab"
      :active="tab.id === rightSidebar.activeTabId"
      @click="rightSidebar.activateTab(tab.id)"
      @close="rightSidebar.closeTab(tab.id)"
    />
  </div>

  <!-- 面板内容（不变）-->
  <div class="panel-body">
    <component :is="activePanel" />
  </div>
</template>
```

### 3.3 搜索打开面板

搜索结果是一个下拉列表，选中后调 `openTab(kind)`：

```typescript
function onSelectPanel(event) {
  const { kind } = event.value
  rightSidebar.openTab(kind)
  searchQuery.value = ''
}
```

## 5. 验收标准

| # | 场景 | 预期 |
|---|------|------|
| 1 | 右栏 header 有 3 个分组按钮（会话/工具/配置） | 点击切换分组 |
| 2 | tab 行只显示当前分组的已打开 tab | 切分组 → tab 行内容切换 |
| 3 | 已打开的其他分组 tab 不丢失 | 切回原分组 → tab 还在 |
| 4 | openTab 时自动切到 tab 所属分组 | 如打开 `browser` → 自动切到"工具"分组 |
| 5 | 搜索框输入关键词 | 跨所有分组搜索面板名 → 下拉显示匹配结果 |
| 6 | 选中搜索结果 | 打开该面板 tab + 切到对应分组 |
| 7 | 现有 openTab/closeTab/recentClosed 行为不变 | 打开/关闭/恢复全部正常 |
| 8 | 最大化/最小化右栏 | 行为不变 |

## 7. Kill criteria

- 如果分组后找 tab 反而更慢（多一次点击切分组），退化为平铺 + 搜索（不分组，所有 tab 平铺 + 搜索框过滤）
- 如果 `expertEdit`（S2）等新 kind 不在 `PANEL_GROUPS` 里，fallback 到 'config' 分组（不报错）
- 如果搜索的 AutoComplete 在窄右栏（280px）太挤，改为图标按钮点开搜索 Dialog
