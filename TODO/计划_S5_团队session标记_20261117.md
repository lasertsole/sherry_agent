# SDD 规格 S5：团队 session 标记

- 日期：2026-11-17
- 状态：**待评审**
- 定位：会话列表区分普通/团队/会议 session，用图标 + 标签标记。
- 依赖：S1（左栏导航注册表）
- 改动量：~100 行

---

## 1. 当前

会话列表（`SessionListPanel.vue` 从 SessionSidebar 抽取后）的 `HistoryItem.vue` 渲染每个 session 行：

**文件**：`client/app/pages/home/components/HistoryItem.vue`

当前每个 session 行显示：session 标题 + 时间 + pin 标记。无 session 类型区分。

session 数据结构（从 `GET /sessions` 返回）没有 `type` 字段——所有 session 都是普通对话。

---

## 2. 目标

session 加 `type` 字段：`'chat' | 'team' | 'meeting'`。会话列表用不同图标/标签区分。

```
会话列表：
┌──────────────────┐
│ 💬 昨天的对话      │  ← chat（默认）
│ 💬 修 bug         │
│ 👥 Web 项目开发    │  ← team（团队图标 + 团队名）
│ 🎤 架构讨论       │  ← meeting（会议图标 + 会议名）
└──────────────────┘
```

---

## 3. 改动

### 3.1 后端：session 加 type 字段

**文件**：`server/service/messages.py` 或 `context_engine/store/db.py`

session 列表 API 返回加 `type` 字段：
- 默认 `'chat'`（普通对话）
- 创建团队 session 时设 `'team'`（专家团计划步骤 12 的 session 创建入口设）
- 创建会议时设 `'meeting'`（会议创建时关联的 session）

### 3.2 前端：HistoryItem 加类型图标

**文件**：`client/app/pages/home/components/HistoryItem.vue`

```vue
<template>
  <div class="history-item ..." @click="onSelect">
    <!-- 类型图标（新）-->
    <i :class="typeIcon" class="text-gray-400 mr-1" />

    <!-- 标题（不变）-->
    <span class="truncate">{{ session.title }}</span>

    <!-- 团队名/会议名标签（新）-->
    <Badge v-if="session.type === 'team'" :value="session.team_name" severity="info" />
    <Badge v-if="session.type === 'meeting'" :value="session.meeting_topic" severity="warn" />
  </div>
</template>

<script setup>
const props = defineProps<{ session: Session }>()

const typeIcon = computed(() => ({
  chat: 'pi pi-comments',
  team: 'pi pi-users',
  meeting: 'pi pi-video',
}[props.session.type || 'chat']))
</script>
```

### 3.3 前端：点击行为区分

**文件**：`client/app/pages/home/components/nav/SessionListPanel.vue`

点击 session 行的行为根据 type 区分：

```typescript
function onSelect(session: Session) {
  if (session.type === 'meeting') {
    // 会议 session → 跳转到会议页面
    router.push(localePath(`/meeting/${session.meeting_id}`))
  } else {
    // 普通/团队 session → 跳转到聊天
    router.push(localePath(`/home/${session.id}`))
  }
}
```

### 3.4 前端：session 创建时带 type

**文件**：`client/app/composables/persona-catalog.ts` 或 `client/app/stores/new-session.ts`

`NewSessionPresetDialog` 选预设时：
- 选普通预设 → type='chat'
- 选团队预设 → type='team' + team_name

## 5. 验收标准

| # | 场景 | 预期 |
|---|------|------|
| 1 | 普通对话 session | 💬 图标，无标签 |
| 2 | 团队 session | 👥 图标 + 团队名 badge |
| 3 | 会议 session | 🎤 图标 + 会议名 badge |
| 4 | 点击普通/团队 session | 跳转到 `/home/[sid]`（聊天界面） |
| 5 | 点击会议 session | 跳转到 `/meeting/[id]`（会议页面） |
| 6 | 无 type 字段的旧 session | 默认显示为 💬 普通 |

---

## 6. Kill criteria

- 如果后端 session type 字段延迟，前端用 session metadata（如 `metadata.team_name` 存在 → team）推断 type
- 如果会议 session 和聊天 session 的跳转逻辑冲突（同一 session_id），接受——会议 session 不出现在会话列表里（只在会议列表里）
