## 0. 背景（已核实）

### 0.1 sherry 现状

sherry 后端 STT 已是可配模型族（`llm-profiles.ts:7-8` 注释列出 `STT`），i18n 有 STT help 文本（四语言 `i18n/locales/*.json:493`），`LlmModelManager.vue:352` 有 STT group 映射。但**客户端无任何音频录制代码**——grep `getUserMedia` / `MediaRecorder` / `AudioContext` 在 `client/app` 零匹配。

transport/render 管线已存在：`ChatRequest.audio_bytes_list` / `audio_path_list`（`chat-types.ts:33-36`），`agent-socket-upload.ts` 处理 `/audio/upload`，`MessageItem.audios` 由 `ChatMediaAttachments.vue:31-42` 渲染 `<audio controls>`。**只有 capture 段缺失**。

### 0.2 ZCode 做法

ZCode 的 `speech-input.tsx` + `voice-selector.tsx` + `transcription.tsx` 提供录音 + 转录 + 选择器。

## 1. ⚠️ 硬约束

| 约束 | 含义 | 验收方式 |
|---|---|---|
| **F1**：不影响输入/发送 | 录音是独立功能，不改 contenteditable/Enter/Shift+Enter/draft | 现有行为不变 |
| **F2**：用户授权 | `getUserMedia` 需用户授权 | 未授权时提示 |
| **F3**：STT 未配置时禁用 | STT 模型族未激活时按钮 disabled + tooltip 提示 | 未配置时不录音 |
| **F4**：转录失败不崩 | STT 接口失败时提示 + 保留原输入 | 失败不丢输入 |
| **F5**：后端零改 | 复用已有 STT 端点 + audio transport | 后端零改动（如已有 STT API） |

## 2. 任务一：录音 + 转录 composable

### 2.1 目标

封装 `MediaRecorder` 录音 + 调后端 STT 转录 + 插入输入框。

### 2.2 改动清单

- [ ] **2.2.1** 新建 `client/app/composables/use-voice-input.ts`：
  ```typescript
  const { isRecording, startRecording, stopRecording, transcript, error } = useVoiceInput()
  ```
  - `startRecording()`：`navigator.mediaDevices.getUserMedia({audio: true})` → `new MediaRecorder(stream)` → 录音
  - `stopRecording()`：`recorder.stop()` → 获取 audio blob → base64 → 调后端 STT
  - 后端 STT 调用：复用已有 STT 模型族端点（需确认 STT API 路径——可能在 `server/trigger/` 下）
  - 转录结果 → `transcript` ref
  - fail-open：`error` ref + toast 提示

- [ ] **2.2.2** STT 配置检测：
  - 从 `useLlmProfilesStore`（`llm-profiles.ts:32`）读 STT group 的 `activeByGroup`（`:38`）
  - STT 未激活时 `isSttAvailable = false` → 按钮 disabled

- [ ] **2.2.3** 录音 UI 状态：
  - `isRecording = true` 时按钮变红色脉动 + 计时器
  - `stopRecording` → 加载态 → 转录完成

**验收**：F2 + F3 + F4。

## 3. 任务二：输入框集成

### 3.1 目标

在 inputBox 加麦克风按钮，转录文本插入光标位置。

### 3.2 改动清单

- [ ] **3.2.1** `inputBox.vue:9-22` contenteditable 旁加麦克风按钮：
  - PrimeVue `Button`（mic 图标）
  - 点击切换 `startRecording` / `stopRecording`
  - `isSttAvailable = false` 时 `disabled` + tooltip "请先配置 STT 模型"（i18n）
  - 录音中：按钮变红 + 脉动动画 + 时长显示（`mm:ss`）

- [ ] **3.2.2** 转录文本插入：
  - `transcript` 变化时，将文本插入 contenteditable 光标位置（range-aware，参考 `use-file-mention.ts:81` 的 `insertFileMention` 模式）
  - 或追加到末尾（光标不在输入框时）
  - 插入后 dispatch `InputEvent('input')` 触发 draft 同步（参考 `use-file-mention.ts` 的做法）

- [ ] **3.2.3** 录音中断处理：
  - 录音中页面切走/组件卸载 → `stopRecording` 清理 stream
  - `getUserMedia` 拒绝 → toast "麦克风权限被拒绝"

- [ ] **3.2.4** i18n：四语言增 `voiceInput.*` 键（录音中/转录中/未配置/权限拒绝）

**验收**：F1 + F4。

---

## 7. 不做的事

| 项 | 不做的原因 |
|---|---|
| 实时流式转录 | 第一版录完再转录（非流式）；实时流式后续 |
| 多语言语音切换 | 复用 STT 模型族的配置，不在前端做语言切换 |
| 语音命令（"新建会话"等） | 只做文本输入，命令触发走命令面板 |
