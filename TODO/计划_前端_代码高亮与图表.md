## 0. 背景（已核实）

### 0.1 sherry 现状

sherry 的 markdown 渲染是一条管线：`markdown-it render` → `DOMPurify.sanitize(chatPurifyConfig)` → `el.innerHTML`（`safeHtml.ts:60`）。**无任何 markdown-it 插件**（grep 确认），**无 shiki/hljs/prism/mermaid/katex 依赖**（`package.json` 确认）。`security.ts:9-13` 注释明确记载"本项目不启用语法高亮、数学公式或任务列表插件"。

代码块当前渲染为裸 `<pre><code class="language-xxx">…</code></pre>`，`class` 属性能过 DOMPurify（`security.ts:70` 允许 `class`），但**没有任何东西消费它**——只有浏览器默认等宽字体样式。

### 0.2 关键性能约束

`use-stream-chunks.ts:178` 每 120ms flush 一次文本。`safeHtml.ts` 的 `updated` 钩子在每次 bound-value 变化时重跑 `safeMarkdownHtml`（即 markdown-it render + DOMPurify sanitize）。注释 `use-stream-chunks.ts:158-169` 警告这对长回答已经是 O(n²)。**任何在流式期间追加的 Shiki/KaTeX/Mermaid 渲染会加剧性能崩溃**，必须延迟到流式 settle 后。

### 0.3 ZCode 做法

ZCode 用 `streamdown` 库 + `@streamdown/code`(Shiki) + `@streamdown/mermaid` + `@streamdown/math`。代码块带"复制/换行/放大/语言标签"工具栏（`code-block.tsx`），Mermaid 有 pan/zoom 预览弹窗（`diagram-preview-dialog.tsx`）。

## 1. ⚠️ 硬约束

| 约束 | 含义 | 验收方式 |
|---|---|---|
| **F1**：不另开裸 HTML 注入 | shiki/math/mermaid 输出必须经 `v-safe-html` 扩展后的 allowlist 或独立沙箱，不绕过 DOMPurify | 无未经 DOMPurify 的 HTML 进 DOM |
| **F2**：流式期间不高亮 | Shiki/KaTeX/Mermaid 仅在 `bubbleView()` 判定非流式（`message.streaming` false）时执行 | 流式期间代码块纯文本，settle 后高亮 |
| **F3**：fail-open | Shiki/KaTeX/Mermaid 初始化失败或渲染异常时退化到纯文本，不崩 | 组件加载失败时降级纯 `<pre>` |
| **F4**：现有渲染不破坏 | 未启用增强时，代码块渲染 byte-identical 当前行为 | 现有 ChatBox 渲染不变 |
| **F5**：allowlist 白名单枚举 | DOMPurify 增补的 tag/attr 是枚举白名单，非通配 `*` | 无 `ALLOW_UNKNOWN` / `*` 通配 |

## 2. 任务一：Shiki 语法高亮

### 2.1 目标

在 markdown 代码块上提供 Shiki 语法高亮 + 工具栏（复制/语言标签/换行切换），延迟到流式 settle 后执行。

### 2.2 改动清单

- [ ] **2.2.1** `client/app/constants/security.ts`：DOMPurify allowlist 增补 Shiki 输出所需的 tag/attr：
  - `ALLOWED_TAGS` 增 `span`（已有，确认保留）
  - `SAFE_STYLE_VALUE_REGEXP` 放宽：允许 `color:` / `background-color:` / `font-style:` 等 Shiki inline style 值（白名单正则枚举，非通配）
  - **优先方案**：Shiki 用 class-based 主题（`markdown-it-shiki` 的 `theme` 输出 class 而非 inline style），则只需 allowlist 保留 `class`（已有），不改 `SAFE_STYLE_VALUE_REGEXP`——**首选此方案**

- [ ] **2.2.2** 新建 `client/app/composables/use-shiki.ts`：
  - 懒加载 Shiki highlighter（WASM，按需初始化，`await getHighlighter(...)`）
  - 按主题切换（light/dark 跟随 `color-mode`）
  - 暴露 `highlightCode(code, lang): string`（返回 HTML string，fail-open 返回空串退化纯文本）
  - 缓存已初始化的 highlighter 单例

- [ ] **2.2.3** `client/app/directives/safeHtml.ts`：在 `safeMarkdownHtml()` 的 `md.render` 之后、`DOMPurify.sanitize` 之前，加一个后处理步骤：
  - 解析 `<pre><code class="language-xxx">…</code></pre>` 块
  - 对每个块调用 `highlightCode(content, lang)` 替换 innerHTML
  - **仅当 `highlightCode` 返回非空时替换**，否则保留原始裸 `<pre><code>`
  - 异常 try-catch，fail-open 跳过

- [ ] **2.2.4** 新建 `client/app/components/chat/CodeBlockToolbar.vue`：
  - 复制按钮（复用 `useMessageCopy` 的逻辑）
  - 语言标签（从 `class="language-xxx"` 提取）
  - 换行切换（`white-space: pre-wrap` / `pre`）
  - hover 显示，PrimeVue Button 组件

- [ ] **2.2.5** `ChatBox.vue:177`：代码块渲染增强——在 `v-safe-html` 注入的 HTML 中，`<pre>` 块需能挂载 `CodeBlockToolbar`。方案：`v-safe-html` 渲染后用 `onUpdated`/`nextTick` 扫描 `<pre>` 节点，用 Vue 的 `createApp`/`h` 挂载工具栏（或改用 `<CodeBlockEnhanced>` 组件包裹，见下）

- [ ] **2.2.6**（备选）新建 `client/app/components/chat/CodeBlockEnhanced.vue`：替代 `v-safe-html` 在代码块上的使用——在 `ChatBox.vue` 模板中检测代码块并用组件渲染（需要拆分 markdown 输出为段落 + 代码块段）。**如果方案 2.2.5 的后处理挂载太复杂，改用此方案**

### 2.3 风险与约束

- **F2 流式不高亮**：`bubbleView()` 返回 `{ text, truncated }`，流式时 `truncated=true`——在 `v-safe-html` 渲染逻辑里检查 `truncated` 跳过高亮
- **F3 fail-open**：`use-shiki.ts` 的 `highlightCode` 全程 try-catch，异常返回空串
- **性能**：Shiki 初始化有 ~200ms 延迟（WASM），懒加载 + 缓存单例；高亮缓存（同 code+lang 不重复高亮）
- **主题切换**：`color-mode` 切换时需重新高亮（Shiki 的 `theme` 参数变）

**验收**：F1 + F2 + F3 + F4 + F5。新建 `client/app/components/chat/__tests__/CodeBlockEnhanced.test.ts`。

### 4.1 目标

在 markdown 中渲染行内 `$...$` 和块级 `$$...$$` 数学公式。

### 4.2 改动清单

- [ ] **4.2.1** 安装 `katex` + `markdown-it-katex`（或 `@traptitech/markdown-it-katex`，维护更活跃）

- [ ] **4.2.3** `security.ts` allowlist 增补 KaTeX 输出 tag/attr：
  - `ALLOWED_TAGS` 增：`math, semantics, mrow, mi, mo, mn, msup, msub, mfrac, mroot, msqrt, mtable, mtr, mtd, mtext, mspace, annotation`（KaTeX MathML 输出）
  - 或用 `katex.renderToString({ throwOnError: false })` 纯 HTML 输出（不输出 MathML），只增补 `span.katex` 等 class——**首选 HTML-only 模式，最小化 allowlist 扩展**
- [ ] **4.2.4** `security.ts`：放宽 `SAFE_STYLE_VALUE_REGEXP` 允许 KaTeX 的 inline style（`position:relative` 等），或改用 KaTeX CSS class 主题模式

- **F1 安全**：KaTeX `renderToString` 是纯字符串输出（不经 eval），安全可控；需确认 `katex.min.css` 引入
- **F2 流式**：公式渲染较轻（纯字符串替换），可考虑流式期间也渲染，但保守起见仍延迟到 settle

## 8. 不做的事

| 项 | 不做的原因 |
|---|---|
| 替换 markdown-it 为 streamdown | sherry 是 Vue 生态，streamdown 是 React 库；重写 markdown 渲染器工作量过大 |
| 在流式期间实时高亮 | O(n²) 性能风险，延迟到 settle |
| 放弃 DOMPurify allowlist | 安全红线，通过白名单枚举扩展而非通配放开 |
| KaTeX MathML 输出 | 优先 HTML-only 模式，最小化 allowlist 扩展 |
