## 0. 问题

taskflow 可跑满 24h × 90 迭代，token 花费无硬顶。`MODEL_PRICING` 配置存在但无 per-session 累计用量。用户无法回答"这个 session 烧了多少 token / 多少钱"。

## 1. 设计

### 1.1 新增 state keys

**文件**：`runtime/session/state_keys.py`

```python
TOKEN_BUDGET_CAP = "token_budget_cap"              # 上限（int tokens），absent = 无上限
TOKEN_BUDGET_CAP_PENDING = "token_budget_cap_pending"  # parked twin
TOKEN_BUDGET_USED = "token_budget_used"             # 累计已用（跨 turn 累积，不 per-turn 重置）
TOKEN_BUDGET_COST = "token_budget_cost"             # 累计花费（USD，用 MODEL_PRICING 算）
TOKEN_BUDGET_LIMITED = "token_budget_limited"       # flag：本 session 已触达上限
```

### 1.2 park/promote twin

**文件**：`server/service/session_settings_service.py`

`_SETTINGS_KEYS` 加一行：
```python
(StateKey.TOKEN_BUDGET_CAP, StateKey.TOKEN_BUDGET_CAP_PENDING),
```

新增 `apply_token_budget_choice(session_id, cap: int | None)` 镜像 `apply_thinking_choice`：
- busy → park 到 `TOKEN_BUDGET_CAP_PENDING`
- idle → 写 live `TOKEN_BUDGET_CAP`（mem + db 双写）

- turn 边界 `promote_pending_settings` 自动 promote

### 1.3 新中间件：TokenBudget

**新文件**：`agent/middlewares/token_budget/core.py`

对标 `IterationBudget`（`agent/middlewares/iteration_budget/core.py`），用 `wrap_model_call` / `awrap_model_call`：

```python
class TokenBudget(AgentMiddleware):
    """Per-session token budget cap. Short-circuits model call when cap is hit."""

    async def awrap_model_call(self, request, handler):
        session_id = _extract_session_id(request)
        cap = state_register_mem.get_state(session_id, StateKey.TOKEN_BUDGET_CAP, 0)
        if cap and cap > 0:
            used = state_register_mem.get_state(session_id, StateKey.TOKEN_BUDGET_USED, 0)
            if used >= cap:
                # 上限触达 → 短路 + WS 通知
                state_register_mem.set_state(session_id, StateKey.TOKEN_BUDGET_LIMITED, True)
                await _push_budget_limited(session_id, used, cap)
                return AIMessage(content=(
                    f"[SYSTEM] Token budget exhausted ({used}/{cap} tokens). "
                    f"Stop calling tools and provide a summary. "
                    f"The user can reset the budget by sending a new message."
                ))
        # 正常执行
        result = await handler(request)
        # 后置：从 result 提取 usage_metadata，累加
        await self._accumulate_usage(session_id, result)
        return result

    async def _accumulate_usage(self, session_id, result):
        """从 AIMessage.usage_metadata 提取 token 数，累加到 state_register。"""
        ai_msg = _extract_ai_message(result)  # 复用 llm_retry/core.py 的提取模式
        if ai_msg is None:
            return
        usage = getattr(ai_msg, "usage_metadata", None)
        if not usage:
            return
        input_tokens = int(usage.get("input_tokens", 0))
        output_tokens = int(usage.get("output_tokens", 0))
        reasoning = int((usage.get("output_token_details") or {}).get("reasoning_tokens", 0))
        total = input_tokens + output_tokens

        # 累加（per-session lock，对标 ToolGuardrails._state_lock）
        with _budget_lock(session_id):
            used = state_register_mem.get_state(session_id, StateKey.TOKEN_BUDGET_USED, 0)
            state_register_mem.set_state(session_id, StateKey.TOKEN_BUDGET_USED, used + total)

            # 花费（复用 taskflow_resume.py:329-342 的 MODEL_PRICING 模式）
            model_name = _extract_model_name(ai_msg)
            pricing = MODEL_PRICING["model_pricing_per_m_tokens"].get(
                model_name, MODEL_PRICING["model_pricing_per_m_tokens"]["_default"])
            cost_delta = (input_tokens * pricing["input"] + output_tokens * pricing["output"]) / 1_000_000
            cost = state_register_mem.get_state(session_id, StateKey.TOKEN_BUDGET_COST, 0.0)
            state_register_mem.set_state(session_id, StateKey.TOKEN_BUDGET_COST, round(cost + cost_delta, 6))

        # 预警阈值（MODEL_PRICING["budget_warn_threshold"] = 0.80）
        cap = state_register_mem.get_state(session_id, StateKey.TOKEN_BUDGET_CAP, 0)
        if cap and cap > 0:
            new_used = used + total
            if new_used >= cap * MODEL_PRICING["budget_warn_threshold"] and not _warned:
                await _push_budget_warning(session_id, new_used, cap)
```

### 1.4 WS 事件推送

对标 `push_taskflow_progress`（`agent/tools/taskflow/progress_push.py:86-107`）：

```python
BUDGET_LIMITED_EVENT = "budget_limited"
BUDGET_WARNING_EVENT = "budget_warning"

async def _push_budget_limited(session_id, used, cap):
    """Best-effort WS push when budget is exhausted."""
    websocket = relation_register.get_websocket_by_session_id(session_id)
    if websocket is None:
        return
    payload = {"event": BUDGET_LIMITED_EVENT, "session_id": session_id,
               "content": {"used": used, "cap": cap}}
    await websocket.send_text(json.dumps(payload, ensure_ascii=False))
```

### 1.5 HTTP 端点

**文件**：`server/trigger/http/session_settings.py`

- `GET /sessions/budget?session_id=<sid>` → `{cap, used, cost, limited, pending}`
- `PUT /sessions/budget` body `{session_id, cap: int | null}` → `{success, pending}`
- `POST /sessions/budget/reset` → 重置 `TOKEN_BUDGET_USED` + `TOKEN_BUDGET_COST` + `TOKEN_BUDGET_LIMITED`（不清 cap）

### 1.6 重置时机

- **不清**：`before_agent`（不是 per-turn 重置，跨 turn 累积）
- **清**：`clear_session`（`server/DAO/messages.py:17`）清所有 state register 变量
- **清**：`POST /sessions/budget/reset`（用户主动重置）
- **不清**：turn 边界 `on_turn_finished`（只 promote cap 设置，不清 used 计数器）

### 1.7 中间件注册

- 加到 `agent/core.py::_build_middlewares` 中 `IterationBudget` 旁边
- 加到 `agent/middlewares/catalog.py::MIDDLEWARE_ORDER`
- 放 `ALWAYS_ON_MIDDLEWARES`（cap absent 时无操作，不需 per-session 关闭）
