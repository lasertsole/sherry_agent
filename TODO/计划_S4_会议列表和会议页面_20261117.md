## 1. 后端依赖

会议模式 API（来自会议模式计划）：

```
POST   /meetings                    创建会议（body: {topic, participant_ids[]}）
GET    /meetings                    列出用户的会议
GET    /meetings/:id               会议详情
DELETE /meetings/:id               取消会议
GET    /meetings/:id/messages      会议消息历史（分页）
POST   /meetings/:id/interrupt     用户插话（body: {content}）
POST   /meetings/:id/reply         回复 ask_user
POST   /meetings/:id/confirm-end   确认结束
POST   /meetings/:id/execute       会议结论转 TaskFlow 执行
GET    /meetings/:id/conclusion    获取会议结论
WS     /meetings/ws?meeting_id=...  实时流
```

## 2. 前端 store

**文件**：`client/app/stores/meeting.ts`（新建）

```typescript
interface MeetingSummary {
  id: string
  topic: string
  status: 'in_progress' | 'waiting_user' | 'ended' | 'cancelled'
  participant_count: number
  flow_stage: string
  iteration_count: number
  created_at: number
  updated_at: number
}

interface MeetingMessage {
  id: number
  meeting_id: string
  sequence: number
  speaker_kind: 'agent' | 'host' | 'user'
  speaker_id: string
  speaker_name: string
  message_role: 'normal' | 'summary' | 'inquiry'
  content: string
  thinking_md?: string
  is_partial: boolean
  timestamp: number
}

interface MeetingPhase {
  id: string
  allowed_agent_ids: string[]
  prerequisites: string[]
  completion_criteria: string
}

interface MeetingExecutionPlan {
  phases: MeetingPhase[]
}

export const useMeetingStore = defineStore('meeting', () => {
  const meetings = ref<MeetingSummary[]>([])
  const currentMeeting = ref<MeetingSummary | null>(null)
  const messages = ref<MeetingMessage[]>([])
  const executionPlan = ref<MeetingExecutionPlan | null>(null)
  const wsConnection = ref<WebSocket | null>(null)

  // 列表
  async function loadMeetings() { ... }

  // 创建
  async function createMeeting(topic: string, participantIds: string[]) { ... }

  // 进入会议
  async function openMeeting(id: string) {
    const [detail, msgs] = await Promise.all([
      $fetch(`/api/meetings/${id}`),
      $fetch(`/api/meetings/${id}/messages`),
    ])
    currentMeeting.value = detail
    messages.value = msgs.messages
    connectWs(id)
  }

  // WS 连接
  function connectWs(meetingId: string) {
    const wsUrl = `${wsBase}/meetings/ws?meeting_id=${meetingId}&token=${gatewayToken}`
    wsConnection.value = new WebSocket(wsUrl)
    wsConnection.value.onmessage = (event) => {
      const frame = JSON.parse(event.data)
      handleWsFrame(frame)
    }
  }

  function handleWsFrame(frame: any) {
    switch (frame.event) {
      case 'meeting_speaker_changed':
        // 更新当前发言者
        break
      case 'meeting_message_delta':
        // 流式追加到消息
        appendDelta(frame)
        break
      case 'meeting_message_completed':
        // 完成消息
        completeMessage(frame)
        break
      case 'meeting_thinking_delta':
        // thinking 流
        appendThinking(frame)
        break
      case 'meeting_ask_user':
        // 显示 ask_user 对话框
        break
      case 'meeting_summary_draft':
        // 显示总结草稿
        break
    }
  }

  // 插话
  async function interrupt(content: string) {
    await $fetch(`/api/meetings/${currentMeeting.value!.id}/interrupt`, {
      method: 'POST', body: { content }
    })
  }

  // 确认结束
  async function confirmEnd() { ... }

  // 转执行
  async function execute() { ... }

  // 断开
  function closeMeeting() {
    wsConnection.value?.close()
    wsConnection.value = null
    currentMeeting.value = null
    messages.value = []
  }

  return {
    meetings, currentMeeting, messages, executionPlan,
    loadMeetings, createMeeting, openMeeting, closeMeeting,
    interrupt, confirmEnd, execute,
  }
})
```

## 6. 验收标准

| # | 场景 | 预期 |

| 1 | 左栏导航行有 🎤 图标 | 点击切换到会议列表 |

## 8. Kill criteria

- 如果 WS 实时流在长会议（>40 轮）下卡顿，发言流虚拟滚动（复用 SessionSidebar 的 `useVirtualRows`）
- 如果独立路由 `/meeting/[id]` 与 home shell 的布局冲突（TitleBar/左栏），改为 home shell 内的右栏 tab（全屏最大化）
- 如果创建会议时专家列表为空（专家注册库未实现），提示"请先在专家库创建专家"
- 如果会议结论 → TaskFlow 转化在后端未实现，"立即执行"按钮 disabled + tooltip "功能开发中"
