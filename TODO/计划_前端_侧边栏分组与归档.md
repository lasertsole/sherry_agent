## 0. 背景（已核实）

### 0.1 sherry 现状

`SessionSidebar.vue` 有标题/日期过滤（`:343-395`），但**无分组/文件夹/拖拽**。`historyList` 是 flat `ref<SessionRecord[]>`（`:340`），从 `getSessionList`（`messages.ts:317`）拉取。`SessionRecord`（`type.ts:2-14`）只有 `title/createTime/id/messages?/renamed?`——**无 group/folder/archive 字段**。

虚拟列表（`:154-183`）用 `use-sidebar-virtual-rows.ts`（`SESSION_ROW_ESTIMATE_PX=100`，`overscan=6`）。删除是硬删除（`handleDeleteSession` `:531-562`，调 `clearSession`）。重命名持久化到 Dexie `sessionTitles` 表（`db.ts:375`）——**分组持久化可参考同一模式**。

### 0.2 ZCode 做法

ZCode 的 `project-sidebar/grouped/` 支持 project/pinned/timeline 分组、粘性组头、拖拽覆盖层（`group-drag-overlay.tsx`、`useGroupedDrag.ts`），归档管理（`ArchiveManagement.tsx`、`DeleteAllArchivedTasksButton.tsx`）。

| 约束 | 含义 | 验收方式 |
|---|---|---| 
| **F1**：现有行为不破坏 | 过滤/重命名/删除/批量删除行为不变 | 现有行为 byte-identical |

## 2. 任务一：数据模型 + 持久化

### 2.1 目标

扩展 `SessionRecord` 增分组/归档字段，Dexie 持久化。

### 2.2 改动清单

- [ ] **2.2.1** `type.ts:2-14` `SessionRecord` 增：
  - `group?: string`（自定义分组名，未分组 = undefined/'默认'）
  - `pinned?: boolean`（置顶）
  - `archived?: boolean`（归档软删除）
- [ ] **2.2.2** Dexie `db.ts` v4 bump，新增 `sessionGroups` 表：`'id, sessionId, groupName, pinned, archived'`
  - PK `id`（auto-inc 或 `sessionId`）
  - 参考已有 `sessionTitles` 表模式（`:375`）
- [ ] **2.2.3** 新建 `client/app/composables/use-session-groups.ts`：
  - `saveSessionGroup(sessionId, group/pinned/archived)` → Dexie 写入
  - `readSessionGroups()` → 批量读
  - `clearSessionGroup(sessionId)` → 清除（会话删除时）
- [ ] **2.2.4** `SessionSidebar.vue:425-478` `loadSessionList` 合并 Dexie 分组数据到 `historyList`

**验收**：F2。

## 3. 任务二：分组渲染 + 拖拽

### 3.1 目标

会话按分组渲染，粘性组头，拖拽排序/移动分组。

### 3.2 改动清单

- [ ] **3.2.1** `SessionSidebar.vue:363` `buildSessionRows` 改为分组构建：
  - 先置顶组（`pinned=true`）
  - 后自定义分组（按 `group` 名排序）
  - 最后默认组（`group` undefined）
  - 归档组隐藏（切换 toggle 才显示）
- [ ] **3.2.2** 虚拟列表中渲染分组头（粘性 sticky header，类似 `GitGraphPanel` 的 section header 模式）
  - 分组头是特殊 row type（不绑 `HistoryItem`）
  - 需调整 `use-sidebar-virtual-rows.ts` 的 row 类型支持 header + item 混合
- [ ] **3.2.3** `HistoryItem.vue` 增拖拽：
  - `draggable=true` + `dragstart`/`drop` 事件
  - 拖拽到另一个分组头 → 移动到该组
  - 拖拽排序 → 调整组内顺序（Dexie 存 `order` 字段）
  - 拖拽视觉反馈（半透明 + 占位线）

- [ ] **3.2.4** 右键菜单增：
  - "移动到分组..." → 子菜单列出自定义分组 + "新建分组"
  - "置顶" / "取消置顶"
  - "归档" / "取消归档"

**验收**：F1 + F4。
