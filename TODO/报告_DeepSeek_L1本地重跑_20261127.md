# DeepSeek L1 本地重跑报告（2026-11-27）

## 背景

- 原计划通过 SSH 在宿主机 `wsl-home`（`192.168.31.39:2222`）重跑 L1 中此前因 DeepSeek 402 未完成的第 9–12 题。
- 第 9 题 `langchain-request-coalescing` 已由 SSH 跑完并通过：`resolved=True reward=1`，F2P 50/50、P2P 232/232、`orchestration=ok`，经验抽取已产出。
- 之后宿主机二层/三层不可达（ARP 未完成、`No route to host`），用户改令：**本地跑 L1，只跑之前没跑过的 3 题**。
- 本报告覆盖第 10–12 题：`happy-dom-abort-pending-body-reads`、`csstree-shorthand-expansion-compression`、`pest-character-class-coalescing`。

## 运行方式

- 主模型：DeepSeek `deepseek-flash`（`MAIN_LLM_API_BASE=https://api.deepseek.com/v1`，来自项目 `.models`）。
- Agent：`sherry_agent` 当前产品 agent，由 eval-only `evals/deepswe/local_agent_worker.py` 直接驱动，编排门 `install_orchestration_gate()`，温度固定 0，最大迭代 180。
- 判分：`deepswe-local/deepswe_local.py grade --no-setup --offline`，使用每题原始 `tests/test.sh`、`tests/test.patch`、`tests/grader.py`。
- 单题硬超时：3600 秒。强制经验抽取开关已开启。
- 工作树：从 `deepswe-local/work/<task>/base` 复制独立副本；运行前 `git reset --hard HEAD && git clean -fd`。

## 与官方/容器口径的关系

- 判分链与容器版一致：同一 `test.sh`、`test.patch`、`grader.py`，同一 F2P/P2P 白名单；GOLD 校准此前已全 12 题 reward=1。
