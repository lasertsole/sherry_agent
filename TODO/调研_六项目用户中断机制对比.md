## 1. 触发 + 机制

| 维度 | claudecode | hermes | codex | openclaw | ZCode | sherry |

## 5. 每个项目的核心特点

### claudecode——最保守
- Esc 是 flag-based 优雅中断，但**工具运行到完成不中断**
- **partial 从历史丢弃**——模型下一轮完全不知道
- 不传播子代理

### hermes——最灵活
- **唯一传播子代理**（`child.interrupt()`）+ **唯一支持打字中断**
- per-thread flag 隔离——多 agent 同进程只中断目标
- 工具协作式 clean up
- marker 不结构化（文本后缀）

### codex——最正式
- **唯一正式 `TurnAborted` 事件 + `TurnAbortReason` 枚举**
- **唯一结构化 `<turn_aborted>` marker** 告诉模型"用户故意中断的"
- **唯一 `drain_in_flight`** 收集在飞 tool 结果
- **唯一不杀后台进程**——marker 告知模型
- 100ms grace

### openclaw——最彻底的子代理 kill
- **子代理 kill 最彻底**——durable `SubagentKillIntent` 持久化 → abort → clear queues → tombstone → `abortedLastRun` → 崩溃后可 reconcile
- `AbortController` + AbortSignal 传入 fetch——LLM HTTP 请求 transport 层 cancel
- partial 持久化（`captureAbortedPartial` + transcript message）
- **process-tree kill**——bash tool 杀整个进程树
- `openclawAbort` 是 metadata 不是 model-visible marker

### ZCode——最优雅的 AbortController 级联
- **AbortController parent→child linked 级联**——parent abort 自动 cascade 到所有 linked child（LLM fetch / tools / 前台子代理）
- **优雅 cooperative**——`throwIfTurnAborted` 在每个 await 检查，streaming-tool 250ms drain
- **前台子代理自动传播**（linked signal）；**后台子代理 detached** 不传播
- **partial 持久化**（`persistCancelledStreamSnapshot`）
- **未执行工具合成 error result**——`stream_recovery_interrupted_tool` + "don't retry blindly"
- **工具级 model-visible marker**——`"[Tool execution was interrupted before resume]"`
- **后台 stop 通知含 initiator**——"用户停的，不要自行恢复"
- **后台进程前台杀 / 后台脱钩不杀**——跟 sherry 的需求最接近
- cancellation 是**正常终态**（`TurnComplete(resultType:"cancelled")`）不是 error

### sherry——最彻底持久化，最弱传播
- **trailing tool call healing 独有**——确定性 id error ToolMessage 保 checkpoint provider-valid
- **双写持久化独有**——checkpointer + MesMemory
- 但**不传播子代理**——多 agent gap
- **不告诉模型中断原因**
- **可能杀后台进程**

## 7. 一句话

六个项目按中断彻底度排序：openclaw（durable kill + cascade + process-tree kill）> ZCode（AbortController 级联 + 前台自动传播 + 后台脱钩 + cooperative + partial 持久化 + 工具级 marker）> codex（CancellationToken + `<turn_aborted>` + drain_in_flight + 不杀后台）> hermes（child.interrupt 传播 + 打字中断 + per-thread 隔离）> sherry（heal + 双写但不传播 + 不告诉模型）> claudecode（工具不中断 + partial 丢弃）。sherry 的计划取 hermes 子代理传播 + codex `<turn_aborted>` marker + ZCode 未执行工具合成 error + sherry 自己的 heal/双写——四个项目的优点组合。
