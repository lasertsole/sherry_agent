## 0. 背景（已核实）

### 0.1 sherry 现状

sherry 侧边栏有标题/日期过滤（`SessionSidebar.vue:343-395`），但**会话内无全文搜索**。会话折叠后内容多（`useChatTurnFold` 把工具/推理行折叠成摘要），缺 Ctrl+F 体验。

### 0.2 虚拟列表关键结构

- **渲染单元**：一个 turn group（`use-chat-virtual-list.ts:51`，`buildChatVirtualRows`）
- **虚拟窗口**：`virtualRows` computed（`:164`），只有 visible + overscan(6) 行在 DOM（ChatBox `:24-225`）
- **内存上限**：`MAX_LOADED_ROWS=400`（`:63`），最老的行释放（`headRowsToReleaseMessageIds` `:213-227`）
- **分页**：`onScroll` 顶部触发 `onReachTop`（`:242-245`，`TOP_TRIGGER_PX=120`）→ ChatBox emit `reach-top` → `useChatOlderHistory.loadOlder()`（`:78-103`）
- **head 释放后**：`resetExhausted()`（`:109`）重新启用分页
- **跳转先例**：`ChatBox.scrollToMessage(messageId)`（`:624-638`）——展开工具卡 + `scrollToRow` + `focusedMessageId` 高亮环

### 0.3 ZCode 做法

ZCode 的 `useConversationTimelineFind` 在时间线里高亮匹配并逐条跳转，`conversationFindHighlightDom.ts` 管理 DOM 高亮。

## 2. 任务一：搜索逻辑

### 2.1 目标

对已渲染的 message 文本做客户端全文匹配 + 逐条跳转。

### 2.2 改动清单

- [ ] **2.2.1** 新建 `client/app/composables/use-conversation-find.ts`：
  ```typescript
  interface FindState {
    query: string
    matches: FindMatch[]      // {messageId, groupIndex, charIndex}
    currentIndex: number     // 当前高亮的 match 索引
    total: number
  }
  ```
  - `search(query, messages)`：遍历所有 message（含折叠的——需先展开），匹配 `content` 文本（大小写不敏感）
  - `next()` / `prev()`：跳转到下一个/上一个匹配
  - `clear()`：清空搜索状态

- [ ] **2.2.2** 搜索范围：遍历 `chatMessages`（`[sid].vue:549`）的所有 message 的 `content` 文本
  - **折叠 turn**：搜索时临时展开所有 turn（`useChatTurnFold` 的展开状态），搜索完成后恢复
  - 或：只搜已展开 turn（第一版），折叠行提示"展开后搜索"

- [ ] **2.2.3** 高亮：匹配文本包 `<mark class="find-highlight">`（CSS 高亮 + 当前匹配额外样式）

**验收**：F2 + F4。

## 4. 任务三：与虚拟列表协调

### 4.1 目标

跳转到匹配行时，如果该行不在虚拟窗口或已被释放，触发加载 + 滚动。

### 4.2 改动清单

- [ ] **4.2.1** 跳转逻辑 `jumpToMatch(match)`：
  1. 找到匹配所在 message → 所在 turn group → `rows.value.findIndex(r => r.key === groupKey)`（参考 `scrollToMessage` `:625`）
  2. 如果 index 在虚拟窗口内：直接 `scrollToRow(index)`（`:335-355`）
  3. 如果不在窗口但 rows 里有：`scrollToRow` 会加载它
  4. **如果行已被释放（head dropped）**：先 `resetExhausted()`（`use-chat-older-history.ts:109`）+ `loadOlder()` 加载到该行 → 再 `scrollToRow`
  5. `focusedMessageId` 高亮（复用 `:612-634` 的环模式）

- [ ] **4.2.2** 高亮渲染：`ChatBox.vue` 在 message 渲染时检查 `findState.matches`，匹配位置包 `<mark>`
  - 流式期间不高亮（同代码高亮的 F2 约束）

### 4.3 风险与约束

- **F1 虚拟列表**：跳转触发加载/scroll 是已有能力的组合，不新增虚拟列表逻辑
- **大列表性能**：搜索是 O(N) 遍历 chatMessages（内存数组，非 DOM），400 行可接受
- **折叠行**：折叠的 turn group 在 DOM 里只有摘要行——搜索需展开才能高亮

**验收**：F1 + F3 + F4。
