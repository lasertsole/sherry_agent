## 0. 背景（已核实）

### 0.1 sherry 现状：无命令面板，但有可复用的命令注册表模式

sherry **没有命令面板**（grep `CommandPalette`/`commandPalette`/`Ctrl+K` 零命中）。功能入口散落在：
- 九宫格菜单（`dialogs.ts` 的 `HOME_TOOLBAR_EVENTS`，17 个事件）+ 锤子按钮工具箱（browser/terminal）
- 右栏 tab（`right-sidebar.ts` 的 `openTab`，24 种 `RightSidebarPanelKind`）
- 会话工具栏（`session-toolbar.ts` 的 4 个事件）

但 sherry **已有两套"命令注册表"先例**，结构统一：`EVENTS` 数组（事件词汇表）+ `buildCommands(context): Record<Event, () => void>`（内部完备 Record 保证缺项编译报错）。命令面板**复用这套模式**，不另造体系——直接把 `HOME_TOOLBAR_EVENTS` 包成 `CommandEntry[]`。

- [ ] **2.1.1** 新建 `client/app/composables/use-command-registry.ts`：
  ```typescript
  export type CommandSection = 'session' | 'navigate' | 'tools' | 'skills';

  export interface CommandEntry {
    id: string;              // 唯一 id，如 'toolbar.skills' / 'session.new' / 'skill.<name>'
    label: string;           // 显示名（i18n key 解析后的文本，或技能 name）
    section: CommandSection;
    icon?: string;           // PrimeVue icon 名（如 'pi pi-bolt'）
    shortcut?: string;       // 快捷键提示 badge（如 'Ctrl+K'，阶段三从快捷键系统读）
    handler: () => void | Promise<void>;  // 执行函数

  }
  ```
  注册 API：
  ```typescript
  // 进程级命令表（静态命令在 app 启动时注册一次）
  const staticCommands = ref<CommandEntry[]>([]);
  function registerStatic(entry: CommandEntry): void { /* push, dedupe by id */ }
  function registerStaticBatch(entries: CommandEntry[]): void { /* 批量 */ }
  // 动态命令（技能/会话列表，面板打开时刷新）
  function setDynamicCommands(entries: CommandEntry[]): void { dynamicCommands.value = entries; }
  function allCommands(): CommandEntry[] { return [...staticCommands.value, ...dynamicCommands.value]; }
  ```
  导出为 composable：`export function useCommandRegistry() { return { registerStatic, registerStaticBatch, setDynamicCommands, allCommands }; }`

### 2.4 模糊匹配算法

- [ ] **2.4.1** `use-command-registry.ts` 内实现 `search(query, commands): ScoredEntry[]`，**自写子串匹配 + 评分排序**（零依赖，不引 fuse.js）：
  ```typescript
  interface ScoredEntry { entry: CommandEntry; score: number; }

  function scoreEntry(entry: CommandEntry, q: string): number {
    if (!q) return 1;                          // 空查询：全部保留，按原序
    const label = entry.label.toLowerCase();
    const kws = (entry.keywords ?? []).map(k => k.toLowerCase());
    if (label === q) return 1000;             // 完全匹配
    if (label.startsWith(q)) return 500 - label.length;   // 前缀（越短越好）
    if (label.includes(q)) return 300 - label.indexOf(q); // 子串（越靠前越好）
    if (kws.some(k => k === q)) return 200;
    if (kws.some(k => k.startsWith(q))) return 150;
    if (kws.some(k => k.includes(q))) return 50;
    return -1;                                 // 不匹配
  }

  export function search(query: string, commands: CommandEntry[]): ScoredEntry[] {
    return commands
      .map(entry => ({ entry, score: scoreEntry(entry, query.trim().toLowerCase()) }))
      .filter(s => s.score >= 0)
      .sort((a, b) => b.score - a.score);
  }
  ```
  - **不做的**：拼音首字母匹配（sherry i18n 是四语言，拼音仅中文场景，复杂度高，进阶再加）。

  function highlight(label: string): string {
    const q = query.value.trim();
    if (!q) return escapeHtml(label);
    const idx = label.toLowerCase().indexOf(q.toLowerCase());
    if (idx < 0) return escapeHtml(label);

  export function useCommandHistory() {
    async function record(entry: CommandEntry): Promise<void> {
      await db.commandHistory.add({ commandId: entry.id, label: entry.label, icon: entry.icon, executedAt: Date.now() });
      // cap 50: 删除最旧的
      const count = await db.commandHistory.count();
      if (count > 50) {
        const oldest = await db.commandHistory.orderBy('executedAt').limit(count - 50).primaryKeys();
        await db.commandHistory.bulkDelete(oldest);
      }
    }
    async function recent(limit = 5): Promise<CommandHistoryEntry[]> {
      return db.commandHistory.orderBy('executedAt').reverse().limit(limit).toArray();
    }
    async function clear(): Promise<void> { await db.commandHistory.clear(); }
    return { record, recent, clear };
  }

| 拼音首字母匹配 | 四语言 i18n，拼音仅中文场景，复杂度高，进阶再加 |
| 引入 fuse.js | 自写子串匹配零依赖够用 |
| AutoComplete 组件 | 自写过滤列表更可控（AutoComplete 未在用，自写避免学习其 API 约束） |
