## 0. 背景（已核实）

### 0.1 sherry 现状

sherry **没有命令面板**。功能散落在九宫格菜单（`dialogs.ts` 的 `HOME_TOOLBAR_EVENTS`）、右栏 tab（`right-sidebar.ts` 的 `openTab`）、各组件局部快捷键里。全局 keydown 监听只有 `ToolbarPopover.vue:100` 一个 `document.addEventListener('keydown', ...)`（Escape 关闭 popover）。`mitt.ts` 是通用事件总线（`emit/on/off`），事件名是散落的字符串字面量。

### 0.2 Dexie 持久化

sherry 用单一 Dexie 库 `'ema-history-cache'`（`db.ts:356`），当前 3 个 version（`db.ts:360-392`），最后是 v3（`browserVisits`）。**没有命令历史表**——需 version bump v4 新增。

### 0.3 ZCode 做法

ZCode 的 `CommandCenterDialog` 是跨工作区任务搜索 + 命令触发统一入口，附带搜索历史（`commandCenterSearchHistory.ts`）。命令来源分 section（`quickPickCommands.ts`）+ 图标（`quickPickCommandIcons.ts`）。

## 1. ⚠️ 硬约束

| 约束 | 含义 | 验收方式 |
|---|---|---|
| **F1**：现有快捷键不破坏 | Enter/Shift+Enter/Esc/↑↓ 等现有绑定不受影响 | 现有输入/导航行为不变 |
| **F2**：命令注册 additive | 命令注册表是追加式，新命令随时可加 | 新增命令不需改面板代码 |
| **F3**：无匹配不崩 | 搜索无结果时显示空状态 | 空查询/无匹配不崩 |
| **F4**：后端零改 | 纯前端 | 后端零改动 |

## 2. 任务一：命令注册表

### 2.1 目标

建立命令注册系统，各功能模块注册自己的命令。

### 2.2 改动清单

- [ ] **2.2.1** 新建 `client/app/composables/use-command-registry.ts`：
  ```typescript
  interface CommandEntry {
    id: string
    label: string          // 显示名（i18n key 或直接文本）
    section: string        // 分组：'session' | 'settings' | 'tools' | 'skills'
    icon?: string         // 图标名
    shortcut?: string     // 快捷键提示（如 'Ctrl+S'）
    handler: () => void   // 执行函数
    keywords?: string[]   // 模糊匹配额外关键词
  }
  ```
  - `registerCommand(entry)` / `unregisterCommand(id)`
  - `allCommands()` 返回已注册命令列表
  - `search(query)` 模糊匹配（label + keywords，大小写不敏感，支持拼音首字母可选）

- [ ] **2.2.2** 命令来源接入：
  - **会话操作**：新建会话（`newSession.openDialog()`）、切换会话（列表前/后）、删除当前会话
  - **设置 tab**：遍历 `RightSidebarPanelKind`，每个 kind 注册一个"打开 X"命令 → `useRightSidebarStore().openTab(kind)`
  - **工具栏操作**：从 `dialogs.ts` 的 `HOME_TOOLBAR_EVENTS` 派生命令（切换模型/模式/思考/项目目录）
  - **技能/slash 命令**：从已加载技能列表注册（如有 slash 命令体系）

**验收**：F2。命令注册表可追加，新命令随时注册。

## 3. 任务二：命令面板 UI

### 3.1 目标

`Ctrl+K` 唤起面板，模糊匹配 + 搜索历史 + 键盘导航。

### 3.2 改动清单

- [ ] **3.2.1** 新建 `client/app/components/CommandPalette.vue`：
  - PrimeVue `Dialog`（`v-model:visible`，`modal` true，`dismissableMask` true）
  - 输入框（`AutoComplete` 或自写 `<input>` + 模糊匹配）
  - 命令列表：按 section 分组，每行 icon + label + shortcut badge
  - 键盘导航：↑↓ 选择，Enter 执行，Esc 关闭
  - 匹配高亮（`<mark>`）
  - 空状态提示

- [ ] **3.2.2** 搜索历史：
  - 执行命令后记录到 Dexie（`db.ts` version bump v4，新增 `commandHistory` 表：`'++id, query, ts'`）
  - 面板打开时显示最近 5 条搜索历史（点击直接执行/填充）
  - cap 50 条（oldest pruned）

- [ ] **3.2.3** `client/app/pages/home/index.vue`：
  - 挂载 `<CommandPalette>`
  - 注册全局 `Ctrl+K`（macOS）/ `Ctrl+K`（Win/Linux）快捷键：
    - `document.addEventListener('keydown', ...)`（参考 `ToolbarPopover.vue:100` 的先例）
    - 检测 `(e.ctrlKey || e.metaKey) && e.key === 'k'` → `e.preventDefault()` → 打开面板
    - 排除：输入框聚焦时不拦截（除非用 `Ctrl+K`——但输入框里 `Ctrl+K` 可能冲突，改为面板始终响应）

- [ ] **3.2.4** 模糊匹配算法：
  - 简单实现：子串匹配 + 按匹配位置排序
  - 或引入轻量库（如 `fuse.js`，已有 PrimeVue 生态兼容）
  - **首选自写子串匹配**，避免额外依赖

**验收**：F1 + F3。新建 `client/app/components/__tests__/CommandPalette.test.ts`。

## 7. 不做的事

| 项 | 不做的原因 |
|---|---|
| 替换现有九宫格菜单 | 命令面板是补充入口，不替代菜单 |
| 跨会话全局搜索 | 第一版只搜命令，不搜会话内容（会话内搜索另见 `计划_前端_会话内搜索.md`） |
| 命令面板内嵌 AI 对话 | 只做命令触发，不做 AI 问答 |
