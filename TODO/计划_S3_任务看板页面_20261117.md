## 1. 后端依赖

当前 TaskFlow 只有 per-session 的 API。需要新增全局列表 API：

```
GET /taskflow/flows?status=running|waiting|done|failed  全局 flow 列表
```

返回：
```json
{
  "flows": [
    {
      "flow_id": "taskflow-abc123",
      "session_id": "session-xyz",
      "description": "搭建 CI/CD 流水线",
      "status": "running",
      "total_steps": 5,
      "done_steps": 3,
      "updated_at": 1700000000
    }
  ]
}
```

如果后端 API 尚未实现，S3 前端先用 per-session 的 `taskflow_inspect(action='summary')` 聚合（遍历所有 session），或用 mock。

## 2. 前端 store

**文件**：`client/app/stores/task-board.ts`（新建）

```typescript
interface FlowCard {
  flow_id: string
  session_id: string
  description: string
  status: 'running' | 'waiting' | 'done' | 'failed'
  total_steps: number
  done_steps: number
  updated_at: number
}

export const useTaskBoardStore = defineStore('task-board', () => {
  const flows = ref<FlowCard[]>([])
  const loading = ref(false)
  const filter = ref<'all' | 'running' | 'waiting' | 'done' | 'failed'>('all')

  const filteredFlows = computed(() =>
    filter.value === 'all'
      ? flows.value
      : flows.value.filter(f => f.status === filter.value)
  )

  async function loadAll() {
    loading.value = true
    try {
      const res = await $fetch('/api/taskflow/flows')
      flows.value = res.flows
    } catch (e) {
      // fail-open：列表为空，不报错
    } finally {
      loading.value = false
    }
  }

  // 轮询（可选，TaskFlow 状态变化时刷新）
  let pollTimer: ReturnType<typeof setInterval> | null = null
  function startPolling(intervalMs = 5000) {
    stopPolling()
    pollTimer = setInterval(loadAll, intervalMs)
  }
  function stopPolling() {
    if (pollTimer) { clearInterval(pollTimer); pollTimer = null }
  }

  return { flows, loading, filter, filteredFlows, loadAll, startPolling, stopPolling }
})
```

### 3.2 TaskBoardNavPanel.vue（左栏内容）

**文件**：`client/app/pages/home/components/nav/TaskBoardNavPanel.vue`（新建）

```vue
<template>
  <div class="task-board-nav flex flex-col h-full">
    <!-- 标题 -->
    <div class="px-3 py-2 font-medium">{{ t('nav.tasks') }}</div>

    <!-- 筛选 -->
    <Select v-model="board.filter" :options="statusOptions" optionLabel="label" optionValue="value" class="mx-3 mb-2" />

    <!-- flow 卡片列表 -->
    <div class="flex-1 overflow-y-auto px-3">
      <div v-if="board.loading" class="text-center py-4"><ProgressSpinner /></div>
      <div v-else-if="board.filteredFlows.length === 0" class="text-center py-4 text-gray-400">
        {{ t('tasks.empty') }}
      </div>
      <div v-else class="space-y-2">
        <FlowCardItem
          v-for="flow in board.filteredFlows"
          :key="flow.flow_id"
          :flow="flow"
          @click="onFlowClick(flow)"
        />
      </div>
    </div>
  </div>
</template>

<script setup>
const board = useTaskBoardStore()
const router = useRouter()
const localePath = useLocalePath()
const rightSidebar = useRightSidebarStore()

const statusOptions = [
  { label: t('tasks.filterAll'), value: 'all' },
  { label: t('tasks.filterRunning'), value: 'running' },
  { label: t('tasks.filterWaiting'), value: 'waiting' },
  { label: t('tasks.filterDone'), value: 'done' },
  { label: t('tasks.filterFailed'), value: 'failed' },
]

onMounted(() => { board.loadAll(); board.startPolling() })
onUnmounted(() => { board.stopPolling() })

function onFlowClick(flow: FlowCard) {
  // 跳转到对应 session
  router.push(localePath(`/home/${flow.session_id}`))
  // 右栏打开 TaskFlowBoardPanel
  rightSidebar.openTab('taskFlowBoard', { flowId: flow.flow_id })
}
</script>
```

### 3.3 FlowCardItem.vue（单个 flow 卡片）

**文件**：`client/app/pages/home/components/FlowCardItem.vue`（新建）

```vue
<template>
  <div class="flow-card border rounded-lg p-3 cursor-pointer hover:bg-gray-50 dark:hover:bg-gray-800" @click="$emit('click')">
    <div class="flex items-center justify-between">
      <span class="font-medium text-sm truncate">{{ flow.description || flow.flow_id }}</span>
      <StatusBadge :status="flow.status" />
    </div>
    <!-- 进度条 -->
    <ProgressBar :value="progress" :showValue="false" class="mt-2 h-1" />
    <div class="flex justify-between mt-1 text-xs text-gray-400">
      <span>{{ flow.done_steps }}/{{ flow.total_steps }} {{ t('tasks.steps') }}</span>
      <span>{{ formatTime(flow.updated_at) }}</span>
    </div>
  </div>
</template>

<script setup>
const props = defineProps<{ flow: FlowCard }>()
defineEmits<{ click: [] }>()

const progress = computed(() =>
  props.flow.total_steps > 0
    ? Math.round((props.flow.done_steps / props.flow.total_steps) * 100)
    : 0
)
</script>
```

## 5. 验收标准

| # | 场景 | 预期 |
|---|------|------|
| 1 | 左栏导航行有 📋 图标 | 点击切换到任务看板 |
| 2 | 任务看板加载 | 显示所有 session 的 flow 卡片（描述 + 进度 + 状态 + 时间） |
| 3 | 有 running flow 时 📋 图标显示 badge 数字 | badge = running flow 数 |
| 4 | 筛选选 running | 只显示 running 状态的 flow |
| 5 | 点击 flow 卡片 | 跳转到对应 session + 右栏打开 TaskFlowBoardPanel |
| 6 | 5 秒轮询 | flow 状态变化时卡片自动更新（进度条 + 状态 badge） |
| 7 | 切到其他导航项再切回 | 任务看板列表保持（KeepAlive）+ 轮询恢复 |
| 8 | 后端 API 未就绪 | 前端用 mock 数据或空状态（不报错） |

## 7. Kill criteria

- 如果全局 flow 列表 API 实现困难（需要跨 session 查询），降级为只显示当前 session 的 flow（等于现有 TaskFlowBoardPanel 的内容）
- 如果轮询导致性能问题（大量 flow），改为 WS 推送（复用 taskflow progress push 机制）
- 如果 badge 数字在无 running flow 时不显示——这是预期行为（badge 只在有值时显示）
