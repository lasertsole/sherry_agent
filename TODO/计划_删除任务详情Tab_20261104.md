# 计划_删除任务详情Tab_20261104

删除右侧栏"任务详情"（taskDetail）标签页及其关联的全部组件、状态和测试。
保留 TasksButton 工具栏按钮（它将被计划 C 的智能体列表复用）和 subagent WS 通道
（计划 C 的实况页仍需 spawn/ended 事件）。

---

## 删除范围

### 策略：删 UI 组件 + tab 注册，保留 store/composables/ws 供 TasksButton 和计划 C 复用

`stores/subagent.ts`、`composables/subagent-sync.ts`、`composables/useSubagentTasks.ts`、
`utils/subagent*.ts`、`server/trigger/ws/subagent_ws.py` **保留**——它们是 TasksButton
的活跃子代理徽标和计划 C 智能体列表的数据源。只删除 taskDetail tab 专属的渲染组件
和注册。
