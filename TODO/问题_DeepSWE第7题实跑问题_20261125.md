## 2. 唯一失败用例：跨 world roundtrip 的关系目标失效

### 现象

失败用例：

```text
tests/snapshot.test.ts: Entity Snapshot & Rollback > roundtrip and integration >
snapshot-rollback-snapshot roundtrip produces identical world diff
```

错误信息：

```text
Koota: Relation "Follows" targets entity 1, which does not exist.
```

### 场景

隐藏 verifier 用例的流程是：

```text
world A 中 b Follows a
→ snapshotWorld(world, registry)
→ 新建 world2
→ rollbackWorld(world2, registry, snap1)
→ snapshotWorld(world2, registry)
→ diffWorldSnapshots(snap1, snap2)
```

agent 的实现在这次跨 world 恢复中没有稳定还原 relation target，导致 `Follows` 指向的实体 1 在目标 world 中不存在。

### 证据

CTRF：

```text

```

失败详情：

```json
{
  "name": "[f2p] tests/snapshot.test.ts: Entity Snapshot & Rollback > roundtrip and integration > snapshot-rollback-snapshot roundtrip produces identical world diff",
  "status": "failed",
  "message": "Koota: Relation \"Follows\" targets entity 1, which does not exist."
}
```

agent patch 中可见的相关实现形态：

```ts
const snapshot: EntitySnapshot = { id: entity, traits };
const entry: RelationSnapshotEntry = { targetId: target };
const entity = packEntity(worldId, 0, id);
```

这些值来自原 world 的实体句柄，在跨 world roundtrip 时与 `rollbackEntity` 的 relation target 存活校验发生冲突。
