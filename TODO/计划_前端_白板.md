## 0. 背景（已核实）

### 0.1 sherry 现状

sherry **无任何自由手绘画板**。grep `canvas`/`CanvasRenderingContext2D`/`fabric`/`konva`/`excalidraw` 在 `client/app` 只有一个命中：`AvatarCropDialog.vue:27,131`——用 `cropperjs` 做头像裁剪（Canvas2D `toDataURL` 先例可复用）。`@antv/g6`（知识图谱）和 `@antv/g2`（统计图表）是图/图表库，不是自由绘图。

### 0.2 ZCode 白板是纯 Canvas2D

ZCode 白板**不依赖任何第三方绘图库**：
- `lib/whiteboard.ts:96-151`：`drawWhiteboardDocument()` 清画布 + 重绘所有 stroke + draftStroke；`drawWhiteboardStroke()` 设 `lineCap='round'`/`lineJoin='round'`，单点→`arc`（点），多点→`moveTo`/`lineTo` 折线
- 画布固定 1280×800（`:35-36`），backing store 按 `devicePixelRatio` 缩放
- 工具只有 `pen` 和 `eraser`（橡皮用背景色画线模拟擦除，`:130-131`）
- 6 色固定调色板，线宽 2-18
- "加入对话"：`createWhiteboardPngFile`（`:165-181`）——离屏 canvas → `toDataURL('image/png')` → base64 → `Uint8Array` → `new File([bytes], 'name.png', {type:'image/png'})` → 图片附件
- 状态 in-memory only（zustand store 无 `persist`），关闭 tab 不删 board，刷新丢失

### 0.3 sherry 的 mention relay 模式

`use-file-mention.ts:160-162` 的 `requestFileMention(sessionId, payload)` → `emit('chat:file-mention', {sessionId, payload})`，`[sid].vue:1087` 监听 → `onFileMentionRequest`（`:1014-1018`）→ `chatInputBoxRef.addFileMention(payload)`。**白板 mention 应完全克隆此模式**，但输出是 PNG 图片附件而非 `@path` 文本。

## 2. 任务一：Canvas2D 绘制核心

### 2.1 目标

用 HTML5 Canvas2D 实现手绘 stroke（画笔/橡皮），零第三方依赖。

### 2.2 改动清单

- [ ] **2.2.1** 新建 `client/app/composables/use-whiteboard-canvas.ts`（移植 ZCode `lib/whiteboard.ts` 逻辑到 Vue composable）：
  - `drawDocument(ctx, strokes, draftStroke?, backgroundColor)`——清画布 + 重绘所有 stroke
  - `drawStroke(ctx, stroke)`——`lineCap='round'`/`lineJoin='round'`；单点→`arc`（点），多点→`moveTo`/`lineTo`
  - 橡皮：用背景色画线模拟擦除
  - `createPngBlob(strokes, backgroundColor, width, height)`——离屏 canvas → `toDataURL('image/png')` → `Uint8Array`（移植 ZCode `createWhiteboardPngFile` `:165-181`）
  - 画布 1280×800 + `devicePixelRatio` 缩放

- [ ] **2.2.2** 定义类型：
  ```typescript
  interface WhiteboardStroke {
    tool: 'pen' | 'eraser'
    color: string       // hex
    width: number       // 2-18
    points: { x: number; y: number }[]  // 归一化到 0-1（相对画布尺寸）
  }
  ```

**验收**：F1 + F3。

## 3. 任务二：白板状态 store

### 3.1 目标

管理 strokes + undo/redo/clear。

### 3.2 改动清单

- [ ] **3.2.1** 新建 `client/app/stores/whiteboard.ts`（Pinia store，移植 ZCode `whiteboardStore.ts`）：
  - state: `boards: Record<boardId, { strokes: WhiteboardStroke[], undoneStrokes: WhiteboardStroke[], name: string }>`
  - `addStroke(boardId, stroke)`——push + 清空 `undoneStrokes`
  - `undo(boardId)`——pop strokes → push undoneStrokes
  - `redo(boardId)`——pop undoneStrokes → push strokes
  - `clear(boardId)`——清空两个数组
  - `renameBoard(boardId, name)`
  - `deleteBoard(boardId)`
  - **持久化（可选）**：Dexie v4 bump，新增 `whiteboards` 表——`'boardId, name'`，存 strokes JSON（可压缩）。ZCode 不持久化（刷新丢失），sherry 可超越 ZCode。

- [ ] **3.2.2** board 生命周期：
  - 打开白板 tab → 创建/恢复 board
  - 关闭 tab → 保留 board（in-memory，参考 ZCode）
  - 刷新 → （可选）Dexie 恢复

**验收**：F2。

## 8. 不做的事

| 项 | 不做的原因 |
|---|---|
| 引入 fabric/konva/excalidraw | Canvas2D 手写足够（ZCode 也是），零依赖更轻 |
| 文字/形状工具 | 第一版只做画笔/橡皮（对齐 ZCode）；文字/形状后续 |
| 多人协作 | 单人白板，协作需要后端实时同步 |
| 矢量导出（SVG） | PNG 位图导出已够用（图片附件是位图） |
| 白板历史回放 | 超 scope，后续可加 |
