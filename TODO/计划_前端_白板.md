## 0. 背景（已核实）

### 0.1 sherry 现状

sherry **无任何自由手绘画板**。`client/app` 里 Canvas2D 只有 `AvatarCropDialog.vue:179-189` 的 `cropperjs` 头像裁剪（`toDataURL('image/png')` 先例）。`@antv/g6`（知识图谱）/ `@antv/g2`（统计图表）是图表库，不是自由绘图。

### 0.2 ZCode 白板是纯 Canvas2D（可移植）

- 画布固定 1280×800（`whiteboard.ts:35-36`），backing store 按 `devicePixelRatio` 缩放。
- `drawWhiteboardDocument()`（`:96-151`）：清画布 + 重绘所有 stroke + draftStroke。
- `drawWhiteboardStroke()`：`lineCap='round'`/`lineJoin='round'`；单点→`arc`（点），多点→`moveTo`/`lineTo` 折线。橡皮用背景色画线模拟擦除（`:130-131`）。
- 工具只有 `pen` 和 `eraser`，6 色固定调色板，线宽 2-18。
- PNG 导出（`:165-181`）：离屏 canvas → `toDataURL('image/png')` → base64。
- 状态 in-memory only（无 persist），关闭 tab 不删 board，刷新丢失。

### 0.3 sherry 图片附件路径（"加入对话"的关键）

完整链路：`selectedImages`（useMediaPicker state，`[sid].vue:763`）→ 预览 tray（`:23-49`）→ `handleSend` 取 `getPendingMedia().images`（`use-chat-stream.ts:939`）→ `req.image_base64_list`（`:999-1002`）→ 浏览器模式上传 `POST /images/upload` → `image_path_list`（`agent-socket-upload.ts:36-74`）。

**关键约束**：`handleSend` 在发送时**从 pending tray 现取并覆盖** `image_base64_list`——任何直接构造 `MultiModalMessage.image_base64_list` 的都会被覆盖丢失。所以白板 PNG 必须 push 进 `selectedImages`，不能绕过 tray。

**inputBox 不持有图片状态**（`defineExpose:479` 无图片方法）——图片状态在页面 `[sid].vue`。白板（右栏独立面板）不在 `[sid].vue` 子组件树内，必须走 mitt relay。

### 0.4 mention relay 模式（白板镜像）

`requestFileMention(sessionId, payload)` → `emit('chat:file-mention', {sessionId, payload})`（`use-file-mention.ts:160-162`）→ `[sid].vue:1090` `on('chat:file-mention', onFileMentionRequest)` → handler 按 frozen `mySid` 过滤（`:1014-1018`）→ `chatInputBoxRef.addFileMention(payload)`。白板镜像此模式，payload 改为 `{base64, name}`，handler 改为 push `selectedImages`。

### 2.2 改动清单

- [ ] **2.2.1** 新建 `client/app/composables/use-whiteboard-canvas.ts`：
  ```typescript
  /** 画布逻辑尺寸（对齐 ZCode whiteboard.ts:35-36）。 */
  export const WHITEBOARD_WIDTH = 1280;
  export const WHITEBOARD_HEIGHT = 800;
  /** 固定调色板（对齐 ZCode 6 色）。 */
  export const WHITEBOARD_COLORS = ['#1f1f1f', '#e03131', '#1971c2', '#2f9e44', '#f08c00', '#9c36b5'];
  /** 线宽范围（对齐 ZCode）。 */
  export const WHITEBOARD_MIN_WIDTH = 2;
  export const WHITEBOARD_MAX_WIDTH = 18;

  export interface WhiteboardPoint { x: number; y: number; }  // 归一化 0-1（相对画布尺寸）

  export interface WhiteboardStroke {
    tool: 'pen' | 'eraser';
    color: string;       // hex
    width: number;       // 2-18
    points: WhiteboardPoint[];
  }

  /** 把归一化点转为画布像素坐标。 */
  function toPixel(p: WhiteboardPoint): [number, number] {
    return [p.x * WHITEBOARD_WIDTH, p.y * WHITEBOARD_HEIGHT];
  }

  /** 重绘整个画布：清 + 背景 + 所有 stroke + draft（对齐 ZCode drawWhiteboardDocument :96-151）。 */
  export function drawDocument(
    ctx: CanvasRenderingContext2D,
    strokes: WhiteboardStroke[],
    draftStroke?: WhiteboardStroke,
    backgroundColor = '#ffffff',
  ): void {
    ctx.fillStyle = backgroundColor;
    ctx.fillRect(0, 0, WHITEBOARD_WIDTH, WHITEBOARD_HEIGHT);
    for (const stroke of strokes) drawStroke(ctx, stroke, backgroundColor);
    if (draftStroke) drawStroke(ctx, draftStroke, backgroundColor);
  }

  /** 画一条 stroke（对齐 ZCode drawWhiteboardStroke :130-151）。 */
  export function drawStroke(
    ctx: CanvasRenderingContext2D,
    stroke: WhiteboardStroke,
    backgroundColor = '#ffffff',
  ): void {
    if (stroke.points.length === 0) return;
    ctx.lineCap = 'round';
    ctx.lineJoin = 'round';
    ctx.lineWidth = stroke.width;
    // 橡皮用背景色画线模拟擦除（对齐 ZCode :130-131）
    ctx.strokeStyle = stroke.tool === 'eraser' ? backgroundColor : stroke.color;
    if (stroke.points.length === 1) {
      // 单点 → arc（点）
      const [x, y] = toPixel(stroke.points[0]!);
      ctx.beginPath();
      ctx.fillStyle = ctx.strokeStyle;
      ctx.arc(x, y, stroke.width / 2, 0, Math.PI * 2);
      ctx.fill();
      return;
    }
    // 多点 → moveTo/lineTo 折线
    ctx.beginPath();
    const [x0, y0] = toPixel(stroke.points[0]!);
    ctx.moveTo(x0, y0);
    for (let i = 1; i < stroke.points.length; i++) {
      const [x, y] = toPixel(stroke.points[i]!);
      ctx.lineTo(x, y);
    }
    ctx.stroke();
  }

  /** 导出 PNG base64（对齐 ZCode createWhiteboardPngFile :165-181 + AvatarCropDialog :187）。 */
  export function exportPngBase64(
    strokes: WhiteboardStroke[],
    backgroundColor = '#ffffff',
  ): string | null {
    const canvas = document.createElement('canvas');
    canvas.width = WHITEBOARD_WIDTH;
    canvas.height = WHITEBOARD_HEIGHT;
    const ctx = canvas.getContext('2d');
    if (!ctx) return null;
    drawDocument(ctx, strokes, undefined, backgroundColor);
    return canvas.toDataURL('image/png');
  }

  /** 设置 canvas 的 devicePixelRatio 缩放（清晰渲染）。 */
  export function setupCanvasDpi(canvas: HTMLCanvasElement): CanvasRenderingContext2D | null {
    const ctx = canvas.getContext('2d');
    if (!ctx) return null;
    const dpr = window.devicePixelRatio || 1;
    canvas.width = WHITEBOARD_WIDTH * dpr;
    canvas.height = WHITEBOARD_HEIGHT * dpr;
    canvas.style.width = '100%';
    canvas.style.height = '100%';
    ctx.scale(dpr, dpr);
    return ctx;
  }
  ```

### 2.3 风险

- **Canvas 不支持（F3）**：`getContext('2d')` 返回 null → 面板显示"您的浏览器不支持 Canvas"提示，不崩。
- **点坐标归一化**：stroke 的 points 存归一化 0-1（相对 1280×800），绘制时乘回像素。这样画布尺寸变化不丢数据（对齐 ZCode）。

**验收**：F1 + F3。

  ```typescript
  import { defineStore } from 'pinia';
  import { ref } from 'vue';
  import type { WhiteboardStroke } from '~/composables/use-whiteboard-canvas';

  interface Board {
    strokes: WhiteboardStroke[];
    undoneStrokes: WhiteboardStroke[];
    name: string;
  }

  export const useWhiteboardStore = defineStore('whiteboard', () => {
    const boards = ref<Record<string, Board>>({});

    function ensureBoard(boardId: string): Board {
      if (!boards.value[boardId]) {
        boards.value[boardId] = { strokes: [], undoneStrokes: [], name: 'Whiteboard' };
      }
      return boards.value[boardId];
    }
    function addStroke(boardId: string, stroke: WhiteboardStroke): void {
      const board = ensureBoard(boardId);
      board.strokes.push(stroke);
      board.undoneStrokes = [];  // 新 stroke 清空 redo 栈（对齐 ZCode）
    }
    function undo(boardId: string): void {
      const board = ensureBoard(boardId);
      const stroke = board.strokes.pop();
      if (stroke) board.undoneStrokes.push(stroke);
    }
    function redo(boardId: string): void {
      const board = ensureBoard(boardId);
      const stroke = board.undoneStrokes.pop();
      if (stroke) board.strokes.push(stroke);
    }
    function clear(boardId: string): void {
      const board = ensureBoard(boardId);
      board.strokes = [];
      board.undoneStrokes = [];
    }
    function renameBoard(boardId: string, name: string): void {
      ensureBoard(boardId).name = name;
    }
    function deleteBoard(boardId: string): void {
      delete boards.value[boardId];
    }
    return { boards, ensureBoard, addStroke, undo, redo, clear, renameBoard, deleteBoard };
  });
  ```
  - **in-memory only**（对齐 ZCode，刷新丢失）。关闭 tab 不删 board（`ensureBoard` 恢复）。
  - **持久化（可选）**：Dexie 加 `whiteboards` 表存 strokes JSON。需 version 协调（与 commandHistory/shortcuts 共用 version，见 `计划_前端_快捷键系统.md` §2.3）。MVP 不持久化，进阶加。

    WHITEBOARD_COLORS as COLORS, WHITEBOARD_WIDTH, WHITEBOARD_HEIGHT } from '~/composables/use-whiteboard-canvas';
  import { extractBase64 } from '~/composables/media-resolver';
  import { emit } from '~/composables/mitt';
  import type { WhiteboardStroke } from '~/composables/use-whiteboard-canvas';

  const props = defineProps<{ payload?: { boardId?: string; sessionId?: string } }>();
  const boardId = computed(() => props.payload?.boardId ?? 'default');
  const store = useWhiteboardStore();
  const board = computed(() => store.ensureBoard(boardId.value));
  const strokes = computed(() => board.value.strokes);
  const boardName = ref(board.value.name);
  const tool = ref<'pen' | 'eraser'>('pen');
  const currentColor = ref(COLORS[0]);
  const lineWidth = ref(4);
  const canvasRef = ref<HTMLCanvasElement | null>(null);
  const draftStroke = ref<WhiteboardStroke | null>(null);
  let ctx: CanvasRenderingContext2D | null = null;

  const canUndo = computed(() => strokes.value.length > 0);
  const canRedo = computed(() => board.value.undoneStrokes.length > 0);

  function redraw(): void {
    if (!ctx) return;
    drawDocument(ctx, strokes.value, draftStroke.value ?? undefined);
  }

  onMounted(() => {
    const canvas = canvasRef.value;
    if (!canvas) return;
    ctx = setupCanvasDpi(canvas);
    if (!ctx) { /* F3: 显示不支持提示 */ return; }
    redraw();

  // 归一化指针坐标到 0-1
  function toNormalized(e: PointerEvent): { x: number; y: number } {
    const canvas = canvasRef.value!;
    const rect = canvas.getBoundingClientRect();
    return { x: (e.clientX - rect.left) / rect.width, y: (e.clientY - rect.top) / rect.height };
  }

  function onPointerDown(e: PointerEvent): void {
    e.preventDefault();
    (e.target as HTMLElement).setPointerCapture(e.pointerId);
    draftStroke.value = { tool: tool.value, color: currentColor.value, width: lineWidth.value, points: [toNormalized(e)] };
    redraw();
  }
  function onPointerMove(e: PointerEvent): void {
    if (!draftStroke.value) return;
    draftStroke.value.points.push(toNormalized(e));
    redraw();
  }
  function onPointerUp(): void {
    if (!draftStroke.value) return;
    if (draftStroke.value.points.length > 0) store.addStroke(boardId.value, draftStroke.value);
    draftStroke.value = null;
    redraw();
  }

  - push 后**无需额外代码**：预览 tray（`:23-49`）+ `handleSend` 取 `getPendingMedia().images`（`use-chat-stream.ts:939`）+ 上传管线（`agent-socket-upload.ts:36-74`）全自动。
  - `mySid` 过滤与 `onFileMentionRequest` 一致（frozen sid，避免 KeepAlive 缓存实例串台，见 `[sid].vue:454-465` 注释）。

### 4.4 风险与约束

- **F6 10 张上限**：`onAddImage` 检查 `selectedImages.length >= 10`（`use-media-picker.ts:31`），超限 toast 提示。
- **sessionId 来源**：白板 tab 是 session-scoped（`SCOPE_BY_KIND whiteboard: 'session'`），payload 带 sessionId（`openTab` 的 `ownerSessionId`）。但白板面板需要当前 session id 来 emit——从 `props.payload.sessionId` 或 `rightSidebarStore.activeSessionId` 取。
- **画布尺寸响应**：画布逻辑固定 1280×800（归一化坐标），CSS 用 `aspect-ratio: 16/10` + `width:100%`。ResizeObserver 不需要（归一化坐标 + CSS 缩放，重绘只读 strokes 不读尺寸）。
- **touch-none**：画布加 `touch-none` class 防止触摸滚动干扰绘制。

**验收**：F2 + F3 + F5 + F6。
