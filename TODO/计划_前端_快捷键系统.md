## 0. 背景（已核实）

### 0.1 sherry 现状

sherry **无快捷键面板**，快捷键零散硬编码在各组件的 `@keydown.*` 修饰符里：
- `inputBox.vue:19-22`：Enter 发送 / Shift+Enter 换行 / ↑↓ 浏览历史 / Esc
- `ToolbarPopover.vue:100`：唯一 `document.addEventListener('keydown', ...)`（Escape 关闭）
- `BrowserPanel.vue:192,519-523`：Escape/↑↓
- `HistoryItem.vue`、`ImagePreviewOverlay.vue`、`LlmModelManager.vue` 等：局部 Enter/Space/Esc

**无全局快捷键注册系统**，`client/app/plugins/` 无全局监听插件。

### 0.2 Dexie

当前 v3（`db.ts:391`），**无快捷键表**——需 v4 bump。

### 0.3 ZCode 做法

ZCode 的 `shortcuts/bindings.ts` 定义绑定，`ShortcutSettingsSection.tsx` 提供重绑 UI，`conflicts.ts` 做冲突检测，`useShortcutCommandLabel` 让 tooltip 跟随重绑。

## 2. 任务一：快捷键注册层

### 2.1 目标

建立统一快捷键注册 + 监听 + 冲突检测系统。

### 2.2 改动清单

- [ ] **2.2.1** 新建 `client/app/composables/use-shortcuts.ts`：
  ```typescript
  interface ShortcutBinding {
    id: string              // 'send-message' | 'new-session' | ...
    label: string          // i18n key
    defaultKeys: string    // 'Enter' | 'Ctrl+K' | 'Shift+Enter'
    category: string       // 'composer' | 'navigation' | 'global'
  }
  ```
  - `SHORTCUT_BINDINGS: ShortcutBinding[]`：所有默认绑定
  - `loadCustomBindings()`：从 Dexie 读自定义绑定
  - `resolveBinding(id)`：返回当前生效的 keys（自定义 > 默认）
  - `matchesKeys(event, bindingId)`：keydown 匹配判断
  - `detectConflict(newKeys, excludeId?)`：检测与其它绑定冲突

- [ ] **2.2.2** 新建 `client/app/plugins/shortcuts.ts`（Nuxt 插件）：
  - `document.addEventListener('keydown', globalHandler)`
  - `globalHandler`：遍历注册的快捷键，匹配则执行 handler + `preventDefault`
  - **排除**：输入框聚焦时只响应全局快捷键（如 `Ctrl+K`），不拦截组件局部快捷键（如 Enter）

- [ ] **2.2.3** 快捷键持久化：`db.ts` version bump v4，新增 `shortcuts` 表：`'id, keys'`（PK `id`）

**验收**：F1 + F2 + F3。

## 3. 任务二：迁移现有快捷键

### 3.1 目标

把零散硬编码的快捷键迁移到统一层。

### 3.2 改动清单

- [ ] **3.2.1** `inputBox.vue:19-22`：Enter/Shift+Enter/↑↓/Esc 迁移到 `use-shortcuts.ts` 注册 + handler
  - **注意**：Enter/↑↓/Esc 在输入框聚焦时才响应——这些是组件局部快捷键，注册为 `category: 'composer'`，只在 composer 聚焦时激活
- [ ] **3.2.2** `BrowserPanel.vue:192,519-523`：Escape/↑↓ 迁移
- [ ] **3.2.3** 新增全局快捷键：
  - `Ctrl+K`：命令面板（与 `计划_前端_命令面板.md` 共享）
  - `Ctrl+F`（或 `Ctrl+Shift+F`）：会话内搜索（与 `计划_前端_会话内搜索.md` 共享）
  - `Ctrl+N`：新建会话
  - `Ctrl+B`：切换左侧栏
  - `Ctrl+,`：打开设置
- [ ] **3.2.4** tooltip 集成：各按钮的快捷键提示从 `resolveBinding(id)` 读取

**验收**：F1。迁移后行为不变。
