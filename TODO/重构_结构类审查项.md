  （`read_file` `write_file` `patch_file` `terminal` `python_repl`）→ `SessionAwareTool` 基类或装饰器。

  → `@invalidates_evidence(file_path_arg=...)` 装饰器或统一 seam。

## 三、分层与抽象泄漏

- **LA1**：`server/` 直接依赖 LangGraph 内部类型与 state 形状（`interrupt_marker.py` 读 `snapshot.values["messages"]`
  并修 super-step 不变量；`context_usage_service.py`、`messages.py`、`heartbeat.py` 同类）
  → 在 `agent/` 引入 `AgentStatePort`（`get_messages` / `inject_human_message` / `heal_interrupted_turn`），server 只调 domain 方法。
- **S10（QC）**：`server/DAO/messages.py::clear_session` 在做编排（调 context_engine、checkpointer、runtime），
  违反 DAO 只做数据访问的层级。建议把编排移到 service（如 `session_purge_service`），DAO 只留纯数据操作。
- **P1**：code_intel 的 explore/callers/callees/impact 与 semantic search 在**构造时**冻结 root
  （`SHERRY_SG_ROOT` 或 `Path.cwd()`），不是按 call 解析 `session_workspace_root(session_id)`；
  与 ast_grep / LSP 的按 call 解析不一致，也与 AGENTS.md 的约定矛盾。缓解：这些工具按 spawn 构建、不是进程单例。

## 五、配置与日志的一致性清扫

- **C1**：`context_engine/curator/constants.py` 复制了 `CURATOR_DEFAULTS` 的 7 个值，导致 TypedDict 的默认字段实际是死的
  → 删除副本，curator 改读 `CURATOR_DEFAULTS["…"]`。
- **EH1**：工具错误返回两种格式（JSON 家族 vs `"Error: " + str(e)` 家族，跨家族不统一）
  → 家族内已一致（`write_file` 的 JSON/纯字符串混用已修）；跨家族统一是**模型可见行为**的变化，需单独立项评估。

  → 统一 `logger.exception(...)`。高风险点是逐个语义判断（部分 warning 是预期退化，不该升级）。
