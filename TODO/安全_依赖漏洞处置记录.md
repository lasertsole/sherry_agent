# 依赖漏洞处置记录

- 范围：`uv.lock`（Python 运行时）、`client/pnpm-lock.yaml`（前端）、
  `client/src-tauri/Cargo.lock`（Rust，随安装包发布）
- 原则：本文件只写**当前仍接受**的告警（逐条带理由）与**待决策项**；
  已修复的条目直接删除（过程见 git 历史）。
- 复审命令（与 CI 完全一致，本地复现用）：
  `uv export --frozen --no-hashes --no-emit-project --format requirements-txt`
  → `uvx pip-audit -r <file> --ignore-vuln <每行白名单 ID>`；前端 `cd client && pnpm audit`。

## 0. 复审约定（避免"精确锁定"悄悄失效）

- CI 的 pip-audit 门必须对**白名单之外**的告警保持 RED；每个白名单条目必须有一行理由。
- 白名单文件 `.github/security/pip-audit-ignore.txt` 逐条列精确 ID；任何一次依赖升级都要
  重审——升级会让某些条目失配，告警应"回来"而不是被版本区间吞掉。
- 计数口径：GitHub 按"依赖 × 告警"计数，同一 CVE 在 OSV 下有 PYSEC / GHSA 两条记录；
  比较时以唯一 CVE 为准，不要拿多套数字互相印证。
- GitHub 的 Dependabot 刷新不同步于 push：处置后告警数不会立刻下降，属正常。

## 3. `transformers` 5.x 迁移（2026-10-17 已完成）

- 6 条告警：4 条可修（5.0.0 / 5.3.0 / 5.5.0 / 5.10.0），2 条无修复

  `trust_remote_code=True` 仅出现在 ModelScope 的 STT AutoModel、vendored lightrag、
  STT 服务脚本三处，模型来自受信来源。
- **迁移已执行**（分支 `tf5-migration`）：`funasr>=1.4.16` +

  `transformers 5.20.1`；连带 `huggingface-hub 0.36→2.2`、numpy/scipy/accelerate 小升、
  torch 2.14.0→2.14.1（补丁）。
  - 白名单收敛（9 → **3** 条）：全部 6 条 transformers 条目退役——升级后以 CI 原命令复跑
  `pip-audit`，`transformers 5.20.1` **零命中**（4 条已在 5.x 修复，另 2 条的影响范围
  不含 5.x）；白名单只剩 accelerate / diskcache / ragas 三条无修复项。
  - 导入冒烟通过（真实 `.venv`）：`transformers` 5 的 `AutoProcessor` /
    `AutoModelForCausalLM` / `Qwen2VLForConditionalGeneration`、`funasr.AutoModel`、
    `mineru_vl_utils`、`models.extract_model`、`models.STT_model`（SenseVoiceSmall）。
- **真机 STT 冒烟通过**（2026-10-17，真实 `.venv`）：`funasr.AutoModel("iic/SenseVoiceSmall",
