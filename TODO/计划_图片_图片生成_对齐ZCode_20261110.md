## 0. ZCode 行为

### 0.1 OpenAI Responses API `image_generation` 工具

ZCode 注册了一个工具 `id:"openai.image_generation"`：
- **输入 schema**：`background`（auto/opaque/transparent）、`inputFidelity`（low/high）、`inputImageMask`（{fileId, imageUrl} — inpaint/编辑）、`model`、`moderation`、`outputCompression`（0-100）、`outputFormat`（png/jpeg/webp）、`partialImages`、`quality`、`size`、`user`
- **输出 schema**：`{result: string}`（base64 图片）
- **流式**：`response.image_generation_call.partial_image` 事件携带 `partial_image_b64` — 作为 `preliminary` 工具结果发出
- 工具名归一化：`"openai.image_generation"` → `"image_generation"`

### 0.2 Chat-completions 图片模型（DALL·E / GPT-Image）

Provider 类发送 `{model, prompt, n, size, ..., response_format:"b64_json"}` 并映射回 `{images: data.map(k=>k.b64_json)}`。

- **最大输出映射** `V_o`：`dall-e-3:1`、`dall-e-2:10`、`gpt-image-1:10`、`gpt-image-1-mini:10`、`gpt-image-1.5:10`、`gpt-image-2:10`、`chatgpt-image-latest:10`
- **格式守卫**：较新模型（`gpt-image-*`、`chatgpt-image-latest`）省略 `response_format`；较旧模型（`dall-e-*`）强制 `response_format:"b64_json"`
- **选项 schema**：quality/background/outputFormat/outputCompression + DALL·E style（vivid/natural）+ inputFidelity（high/low）
- **Token 用量**：`Lur` 将响应中的 `image_tokens` 在 `n` 张生成图片间分配

### 0.3 图片编辑

编辑通过 `inputImageMask` + `inputFidelity` 折叠进 `image_generation` — 无单独的编辑工具。

### 0.4 模型注册表

许多图片生成模型以 `"family":"gpt-image"`、`"attachment":true` 注册。

### 2.4 格式守卫

```python
NEW_IMAGE_MODELS = {"chatgpt-image-latest", "gpt-image-1", "gpt-image-1-mini", "gpt-image-1.5", "gpt-image-2"}

def should_force_response_format(model: str) -> bool:
    """Older models (dall-e-*) force response_format='b64_json'; newer models omit it."""
    return not any(model.startswith(prefix) for prefix in NEW_IMAGE_MODELS)
```

## 5. 备注

- 阶段 1 = 仅生成（文本 → 图片）。阶段 2 = 编辑（图片 + 遮罩 → 图片）。`inputImageMask` 参数在工具 schema 中存在，但阶段 1 不接线。
- 生成图片通过 artifact 存储（计划 #7）进行持久化和去重。
- 工具返回 markdown `![](sherry-artifact://...)` — 画廊/lightbox（计划 #5）渲染它。
- `.models` config 已有 `TTI_*` 家族键 — 本计划激活它们。
- 这是风险最高的计划：新 provider 集成、潜在的 API key/成本问题，且模型需由用户配置。
