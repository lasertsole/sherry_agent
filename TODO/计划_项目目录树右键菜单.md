## 3. 设计方案

### 3.1 菜单组件（`FileTreeNode.vue`）

在 `FileTreeNode.vue` 加 `@contextmenu.prevent="openContextMenu($event, node)"`
和 PrimeVue `<ContextMenu>`：

```vue
<template>
  <div
    class="file-tree-node"
    @click="onClick"
    @contextmenu.prevent="openContextMenu($event, node)"
  >
    <!-- 现有内容 -->
  </div>
  <ContextMenu ref="menuRef" :model="menuItems" />
</template>

<script setup lang="ts">
const menuRef = ref()
const menuItems = ref<ContextMenuItem[]>([])

function openContextMenu(event: MouseEvent, node: FileTreeNode) {
  menuItems.value = buildMenuItems(node)
  menuRef.value?.show(event)
}
</script>
```

### 3.2 菜单项构建（新增 composable `useFileTreeContextMenu.ts`）

```typescript
function buildMenuItems(node: FileTreeNode): ContextMenuItem[] {
  const items: ContextMenuItem[] = []

  // 1. Open
  items.push({
    label: t('projectFiles.open'),
    icon: 'pi pi-fw pi-folder-open',
    disabled: node.type === 'file' && node.deleted,
    command: () => emit('open', node),
  })

  // 2. Open with（子菜单——见 §3.3）
  if (node.type === 'file' && !node.deleted) {
    items.push({
      label: t('projectFiles.openWith'),
      icon: 'pi pi-fw pi-external-link',
      items: buildOpenWithSubmenu(node),
    })
  }

  // 3. Open in built-in browser（仅 .html/.htm）
  if (canOpenInBrowser(node)) {
    items.push({
      label: t('projectFiles.openInBrowser'),
      icon: 'pi pi-fw pi-desktop',
      command: () => openInBrowser(node),
    })
  }

  items.push({ separator: true })

  // 4. Reveal in File Manager
  items.push({
    label: getRevealLabel(),  // 平台动态：Finder/资源管理器/文件管理器
    icon: 'pi pi-fw pi-folder',
    disabled: !canReveal(),
    command: () => revealInFileManager(node),
  })

  // 5. Copy absolute path
  items.push({
    label: t('projectFiles.copyAbsolutePath'),
    icon: 'pi pi-fw pi-copy',
    command: () => copyPath(node.absolutePath),
  })

  // 6. Copy relative path
  items.push({
    label: t('projectFiles.copyRelativePath'),
    icon: 'pi pi-fw pi-copy',
    command: () => copyPath(node.path),
  })

  items.push({ separator: true })

  // 7. Add to chat
  items.push({
    label: t('projectFiles.addToChat'),
    icon: 'pi pi-fw pi-comment',
    command: () => addToChat(node),
  })

  return items
}
```

### 3.3 各项实现细节

#### ① Open / 打开

复用现有 `onClick` 逻辑——文件 emit `open`（→ `FileViewerPanel`），
目录 emit `toggle`（→ 展开/折叠）。纯前端，无后端。

#### ② Open with / 打开方式

ZCode 列出系统已安装编辑器。Sherry 的场景：

| 子项 | 条件 | 动作 | 实现 |
|------|------|------|------|
| 用文件查看器打开 | 文件 | 打开 `FileViewerPanel` | 已有（= Open） |
| 用系统默认应用打开 | 桌面端（Tauri） | `@tauri-apps/plugin-opener::openPath(path)` | Tauri only |
| 在浏览器中打开 | `.html`/`.htm` | = ③ Open in browser | 见 ③ |

Web 端只有"用文件查看器打开"（= Open）和"在浏览器中打开"（.html）。
桌面端多一个"用系统默认应用打开"（打开 .png 看图、.pdf 看文档等）。

#### ③ Open in built-in browser / 用内置浏览器打开

**条件**：`node.type === 'file'` 且 `node.path` 匹配 `.html`/`.htm`，
未删除。

**动作**：打开 `BrowserPanel`（右侧栏 tab），导航到文件路径。

**Tauri 桌面端**：
```typescript
// Tauri 的 asset protocol 可以加载本地文件
const fileUrl = convertFileSrc(node.absolutePath)  // @tauri-apps/api/core
// 打开 BrowserPanel tab，设置初始 URL
rightSidebar.openTab('browser', { instance: `file-${Date.now()}`, initialUrl: fileUrl })
```

**Web 端**：`file://` 协议在浏览器 iframe 中被安全策略拦截。Web 端
隐藏此菜单项（`canOpenInBrowser` 返回 false）。或者走后端——
`GET /project/file?path=xxx` 读内容，用 `Blob` + `URL.createObjectURL`
生成一个 `blob:` URL 在 iframe 里打开。但这只对静态 HTML 有效，带
相对路径引用（CSS/JS）的页面会断。

**推荐**：桌面端用 Tauri asset protocol，Web 端用 blob URL（尽力而为，
复杂 HTML 可能不完整），并在菜单项标签后加 `(桌面端)` 标记 Web 端降级。

#### ④ Reveal in File Manager / 在资源管理器中打开

**条件**：桌面端（Tauri），未删除。

**Tauri 实现**：
```typescript
import { revealItemInDir } from '@tauri-apps/plugin-opener'

async function revealInFileManager(node: FileTreeNode) {
  // 文件：reveal 所在目录；目录：reveal 自身
  const path = node.type === 'file'
    ? getContainingDirectory(node.absolutePath)
    : node.absolutePath
  await revealItemInDir(node.absolutePath)  // Tauri 会打开文件管理器并选中
}
```

**Web 端**：不可用（浏览器无法访问 OS 文件管理器）。隐藏此菜单项。

**标签**：平台动态——macOS "在 Finder 中打开"、Windows "在资源管理器中打开"。

#### ⑤ Copy absolute path / 复制绝对路径

```typescript
async function copyPath(path: string) {
  await copyTextToClipboard(path)
  toast.success(t('projectFiles.copied'))
}
```

`node.absolutePath` = `sessionRoot + node.path`（session 的项目根 + 相对路径）。
纯前端，`copyTextToClipboard` 已有。

#### ⑥ Copy relative path / 复制相对路径

同 ⑤，复制 `node.path`（相对于项目根的路径）。

#### ⑦ Add to chat / 添加到聊天

**目标**：把文件的路径（或内容）插入到聊天输入框，让 agent 知道用户
想讨论哪个文件。

**实现**：向聊天输入框插入一条引用文本：

```typescript
function addToChat(node: FileTreeNode) {
  const mention = node.type === 'file'
    ? `@${node.path}`                              // 文件：@path 引用
    : `[目录] ${node.path}`                         // 目录：文本提及
  // 插入到输入框（inputBox.vue 的 textarea）
  chatInput.insertText(mention)
  toast.info(t('projectFiles.addedToChat'))
}
```

Sherry 的 agent 有 `read_file` 工具——`@path` 引用后 agent 会自动读文件。
不需要传文件内容，传路径引用即可（agent 会自己 `read_file`）。

**比 ZCode 更轻**：ZCode 派发自定义事件传整个 payload（path + content），
Sherry 只传路径引用——agent 自己决定是否读内容。

### 第一档：纯前端，立刻可做

## 7. 边界场景

| 场景 | 行为 | 理由 |
|------|------|------|
| 右键已删除的文件 | Open disabled、Reveal disabled，Copy/Add to chat 可用 | 和 ZCode 一致 |
| 右键目录 | Open = 展开/折叠，Open with hidden，Open in browser hidden | 目录不是文件 |
| 右键 .html 文件 | 显示"Open in browser" | 满足条件 |
| 右键 .py 文件 | 不显示"Open in browser" | 非 HTML |
| Web 端右键 | Reveal 和 Open with (系统应用) hidden | 浏览器无法访问 OS |
| 桌面端右键 | 全部显示 | Tauri 可访问 OS |
| 复制路径后 | toast 提示"已复制" | 用户反馈 |
| Add to chat 后 | 输入框插入 `@path`，toast 提示 | agent 自动读文件 |
| 无项目目录绑定时 | 文件树不显示 | 已有逻辑（toolbar files button 仅在有 binding 时显示） |
| session 切换 | 文件树刷新，菜单项重新构建 | 已有逻辑 |

## 8. 不做的事

- **不做 New File / New Folder / Rename / Delete**——ZCode 也没做。
  Sherry 的文件树是只读的（`GET /project/tree` + `GET /project/file`），
  保持和 ZCode 一致的只读语义。写操作由 agent 通过 `write_file` / 
  `patch_file` 工具完成。
- **不做 Cut / Copy / Paste / Duplicate**——同上，ZCode 也没做。
- **不做 Open in Terminal**——Sherry 的终端面板是 OPERATOR 的 shell，
  不是 agent 的 terminal 工具。可以在终端面板里 `cd` 到目录，但
  "右键 → 在此打开终端"需要额外 wiring，当前不做。
- **不做 Git 右键操作**——Git 操作在 Git Graph 面板里（已有右键菜单），
  不在文件树里。
- **不传文件内容到 chat**——Add to chat 只传 `@path` 引用，agent 自己
  `read_file`。比 ZCode 的传整个 payload 更轻。
