## 0. 背景（已核实）

### 0.1 后端已就绪

sherry 后端 `trajectory_store.py` 已有完整的轨迹账本：

- **表结构**（`trajectory_store.py:73-85`）：`trajectory_events(event_id, session_id, turn_id, seq, ts, kind, is_error, summary, payload_json)`，有 `(session_id, turn_id, seq)` 和 `(turn_id, seq)` 两个索引
- **查询 API**（`trajectory_store.py:252-297`）：`read(session_id, turn_id=, limit=, offset=)` 返回 event dict 列表
- **HTTP 路由**（`trajectory.py:17-43`）：`GET /sessions/:session_id/trajectory?turn_id=X&limit=500&offset=0` 返回 `{session_id, turn_id, events: [...]}`
- **每个 event dict 携带**：`event_id, turn_id, seq, ts, kind, is_error, summary, payload`（payload 是 JSON 解析后的 dict）
- **payload 形状**：`tool_start`→`{tool_name, args}`；`tool_end` upsert 合并到 `tool_start` 同一行→增加 `{result, duration_ms, error}`；其他 kind 携带原始 frame dict

### 0.2 前端无查看器

sherry 前端没有消费这个 API 的面板。这是最低成本的一项——后端零改动，纯前端接一个右栏 tab。

### 0.3 ZCode 做法

ZCode 的 `ModelTrajectoryPane` 是一个原始协议/token/usage 检查器，支持搜索（`ModelTrajectorySearchBar`）和全部展开/折叠（`ModelTrajectoryExpandableMessage`）。

## 3. 任务二：TrajectoryPanel.vue 面板

### 3.1 目标

新建面板组件，调 `GET /sessions/:id/trajectory`，按 turn 分组渲染工具调用时间线。

### 3.2 改动清单

- [ ] **3.2.1** 新建 `client/app/composables/use-trajectory.ts`：
  - `fetchTrajectory(sessionId, turnId?, limit?, offset?)`：封装 `GET /sessions/:id/trajectory` 调用
  - `groupByTurn(events)`：按 `turn_id` 分组，每组内按 `seq` 排序
  - 返回 `{ turns: [{turn_id, events: [...]}], loading, error }`
  - fail-open：异常返回 `{ turns: [], loading: false, error: msg }`

- [ ] **3.2.2** 新建 `client/app/pages/home/components/TrajectoryPanel.vue`：
  - Props：`payload?: { sessionId?: string }`（从 tab payload 读，否则从 route sid）
  - 顶部：turn 选择器（下拉列出所有 turn_id，或显示当前 turn 的轨迹）
  - 时间线：每个 tool call 一行
    - 工具名（`payload.tool_name`）+ 状态图标（`is_error` → 红色 ✕，否则 ✓）
    - 时长（`payload.duration_ms`，格式化为 `1.2s`）
    - 时间戳（`ts`）
    - 可展开：参数（`payload.args` JSON）+ 结果（`payload.result` 截断显示）
  - turn 级聚合：总时长（最后一个 `turn_end` event 的 `payload.total_ms`）
  - 空状态：无轨迹时显示提示

- [ ] **3.2.3** 搜索栏：
  - 过滤 tool name / args 文本（客户端过滤已加载 events）
  - 匹配高亮

- [ ] **3.2.4** 展开/折叠控制：
  - 全部展开 / 全部折叠
  - 默认折叠（只看工具名 + 时长 + 状态）

**验收**：F1 + F2。新建 `client/app/pages/home/components/__tests__/TrajectoryPanel.test.ts`。
