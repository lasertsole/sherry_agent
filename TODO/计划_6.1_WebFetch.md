## 0. 问题

Sherry 只能搜（Tavily / SearXNG），不能读 URL。模型无法"给我看看这个网页的内容"。
也不能 fetch 本地 dev server（`http://localhost:3000`）——调试前端、验证本地
API 响应都做不到。这是真实的能力缺口。

## 1. 关键发现：安全基础设施已就绪

仓库**已有**完整的 SSRF 防护 + 安全 HTTP fetch 实现，不需要从零做：

| 已有组件 | 文件 | 能力 |
|---|---|---|
| `is_public_url(url)` | `pub/func/validator/public_url.py` | DNS 解析后校验每个地址是公网可路由（fail-closed）；拒绝 private/loopback/link-local/multicast/reserved |
| `safe_fetch(url)` | `pub/func/validator/safe_fetch.py` | DNS pinning（连接已校验 IP）；per-hop redirect 重新解析校验；streamed body cap；GET only；stdlib `http.client`（不用 httpx，因为 httpx 的 proxy 会破坏 pinning） |
| `FetchResult` | 同上 | `ok` / `body: bytes` / `reason` / `final_url` / `status` |
| 输出截断 | `pub/func/message/eviction.py` | `evict_tool_result` 自动对 > 20K 字符的工具结果做 head/tail 预览 + 落盘 |
| 工具注册 | `agent/tools/__init__.py` | `_MAIN_TOOLS_BUILDERS` list + builder 函数 |
| 工具分组 | `agent/tools/catalog.py` | `TOOL_GROUPS["web"]` 当前只有 `web_search` |

**唯一缺口**：无 HTML→Markdown 转换库。`pyproject.toml` 不含 `html2text` / `markdownify` / `beautifulsoup4`。

## 2. 设计

### 2.1 工具模块

**新文件**：`agent/tools/web_fetch.py`

```python
from langchain_core.tools import tool
from langchain_core.tools import BaseTool
from pydantic import BaseModel, Field
from typing import Annotated
from langgraph.prebuilt import InjectedState
from pub.func.validator import is_public_url
from pub.func.validator.safe_fetch import safe_fetch, FetchResult
import asyncio
import os

_ALLOW_LOCAL = os.getenv("SHERRY_WEB_FETCH_ALLOW_LOCAL", "0") == "1"

class WebFetchSchema(BaseModel):
    url: str = Field(description="The URL to fetch. Must be an http(s) URL.")
    prompt: str = Field(description="What to extract or answer about the fetched page.")
    session_id: Annotated[str, InjectedState("session_id")] = Field(default="", exclude=True)

@tool("web_fetch", args_schema=WebFetchSchema)
async def web_fetch(url: str, prompt: str, session_id: str = "") -> str:
    """Fetch a URL and return its content as markdown, then answer the prompt.
    Public http(s) URLs only by default (SSRF-protected via DNS pinning).
    Set SHERRY_WEB_FETCH_ALLOW_LOCAL=1 to also allow local/private URLs."""
    
    # --- 分支选择 ---
    if _is_local_url(url):
        if not _ALLOW_LOCAL:
            return (
                f"Error: URL '{url}' is a local/private address. "
                "Set SHERRY_WEB_FETCH_ALLOW_LOCAL=1 to enable local URL fetching."
            )
        result = await _fetch_local(url)
    else:
        if not is_public_url(url):
            return f"Error: URL '{url}' is not a public URL or could not be resolved."
        result = await asyncio.to_thread(safe_fetch, url, timeout=30, max_bytes=10_485_760)
    
    # --- 后续处理：两条路径共用 ---
    if not result.ok:
        return f"Error: fetch failed ({result.reason}). URL: {result.final_url or url}"
    body = result.body or b""
    try:
        text = body.decode("utf-8", errors="replace")
    except Exception:
        return f"Error: could not decode response body."
    markdown = _html_to_markdown(text)
    max_chars = 50_000
    if len(markdown) > max_chars:
        markdown = markdown[:max_chars] + f"\n\n[... truncated, {len(markdown)} total chars. Use read_file for the full content.]"
    return f"URL: {result.final_url or url}\nStatus: {result.status}\n\n{markdown}"

def build_web_fetch_tool() -> BaseTool:
    tool_obj = web_fetch
    tool_obj.handle_tool_error = True
    tool_obj.metadata = {"idempotent": False}
    return tool_obj
```

### 2.2 HTML→Markdown 转换

**方案**：加 `html2text` 依赖（轻量，纯 Python，无 C 扩展）。

```toml
# pyproject.toml

    ...
    "html2text>=2024.2.28",

```

```python
import html2text

_h = html2text.HTML2Text()
_h.ignore_links = False
_h.ignore_images = True
_h.body_width = 0  # 不换行

def _html_to_markdown(html: str) -> str:
    """Convert HTML to markdown. Strip script/style/noscript first."""
    import re
    html = re.sub(r"<(script|style|noscript)[^>]*>.*?</\1>", "", html, flags=re.DOTALL | re.IGNORECASE)
    return _h.handle(html)
```

**不用手写正则转换器**（ZCode 手写了，是维护负担）。`html2text` 是成熟库，~2000 行，覆盖 edge case 远超手写。

### 2.5 本地 URL 分支

**开关**：`SHERRY_WEB_FETCH_ALLOW_LOCAL=0`（默认关，tracked in `.env`）。
开关=1 时，agent 可以 fetch 本地 dev server（`http://localhost:3000`、
`http://127.0.0.1:8080`、`http://192.168.1.50` 等）。

**URL 分类**：

```python
import ipaddress
from urllib.parse import urlparse

def _is_local_url(url: str) -> bool:
    """True when the URL points at a private/loopback address.
    
    Only checks literal IPs and 'localhost' — does NOT do DNS resolution.
    A hostname resolving to 127.0.0.1 is not caught here; it falls through
    to the public path where is_public_url's DNS check rejects it.
    """
    try:
        parsed = urlparse(url)
        host = parsed.hostname or ""
    except Exception:
        return False
    if host == "localhost":
        return True
    try:
        ip = ipaddress.ip_address(host)
        return ip.is_private or ip.is_loopback or ip.is_link_local
    except ValueError:
        return False  # 非字面量 IP → 走公网路径
```

**本地 fetch 路径**：

```python
import httpx

async def _fetch_local(url: str) -> FetchResult:
    """Fetch a local URL without SSRF checks (the switch is already on).
    
    Uses httpx (not safe_fetch) because:
    - DNS pinning is meaningless for localhost (no rebinding on loopback)
    - safe_fetch uses stdlib http.client which doesn't support async natively
    - httpx is already a dependency; supports verify=False for self-signed certs
    """
    try:
        async with httpx.AsyncClient(
            timeout=10.0,           # 本地 10s 够了（公网 30s）
            follow_redirects=True,
            max_redirects=5,
            verify=False,           # 本地 dev server 常用自签证书
        ) as client:
            resp = await client.get(url)
            body = resp.content
            if len(body) > 10_485_760:  # 10MB，和公网一致
                body = body[:10_485_760]
            return FetchResult(
                ok=True,
                body=body,
                status=resp.status_code,
                final_url=str(resp.url),
                reason="ok",
            )
    except httpx.TimeoutException:
        return FetchResult(ok=False, reason="timeout", final_url=url)
    except httpx.ConnectError as e:
        return FetchResult(ok=False, reason=f"connection refused: {e}", final_url=url)
    except Exception as e:
        return FetchResult(ok=False, reason=str(e), final_url=url)
```

**为什么用 httpx 不用 safe_fetch**：
- `safe_fetch` 用 stdlib `http.client` + DNS pinning——loopback 无 rebinding
  风险，pinning 没意义
- `safe_fetch` 不支持 async（需要 `asyncio.to_thread` 包一层）
- httpx 已是依赖（web_search、browser_cdp 等都用），支持 async + `verify=False`

**两条路径后续处理共用**——body cap（10MB）+ HTML→Markdown（html2text）+
50K 截断 + `evict_tool_result` 自动落盘。本地路径只跳过 `is_public_url`，
不跳过其他保护。

**重定向跨边界**：httpx `follow_redirects=True` 自动跟随。本地→公网或
公网→本地的重定向不额外检查——开关=1 时用户已承担本地访问风险。开关=0
时公网路径的 `safe_fetch` per-hop redirect 校验会拦住公网→本地的重定向。

### 2.6 无依赖降级

如果 `html2text` 未安装（import 失败），降级为返回原始文本（剥 tag 后的纯文本）：

```python
def _html_to_markdown(html: str) -> str:
    try:
        import html2text
        ...
    except ImportError:
        # 降级：剥 tag 的纯文本
        import re
        text = re.sub(r"<[^>]+>", "", html)
        return text
```

## 3. 安全设计

| 威胁 | 防护 | 来源 |
|---|---|---|
| SSRF（内网扫描） | `is_public_url` DNS 解析后校验每个地址是公网可路由 | `public_url.py` |
| DNS rebinding | `safe_fetch` DNS pinning——解析一次，连接该 IP，不重新解析 | `safe_fetch.py` |
| 重定向到内网 | per-hop redirect 重新 `resolve_public_addresses` + 重新 pin | `safe_fetch.py` |
| 大响应灌爆内存 | streamed body cap（64KB chunks，`max_bytes` 截断） | `safe_fetch.py` |
| 大输出灌爆上下文 | 50K 工具内截断 + 20K ContextEviction 自动落盘 | `eviction.py` |
| 非公网 URL | `is_public_url` fail-closed（拒绝不可路由地址） | `public_url.py` |
| 私网 escape hatch | `SHERRY_ALLOW_PRIVATE_MEDIA_URLS=1`（媒体 URL 用） | `public_url.py` |
| 本地 URL fetch | `SHERRY_WEB_FETCH_ALLOW_LOCAL=1`（opt-in，默认关） | `.env` + `web_fetch.py` |

**不照抄 ZCode**：ZCode 的 SSRF 防护只覆盖字面量（拦 `localhost` / `*.local` 字符串），无 DNS 预检，不防 DNS rebinding。Sherry 的 `safe_fetch` 更强。

### 3.1 本地开关的安全模型

| 场景 | 开关=0 | 开关=1 |
|------|--------|--------|
| `web_fetch http://example.com` | ✅ 公网路径 | ✅ 公网路径 |
| `web_fetch http://localhost:3000` | ❌ 拒绝 + 提示开开关 | ✅ 本地路径 |
| `web_fetch http://192.168.1.50` | ❌ 拒绝 | ✅ 本地路径 |
| `web_fetch http://169.254.169.254` | ❌ 拒绝 | ✅ 本地路径（link-local 也放行） |
| 公网 URL 302 → localhost | ❌ safe_fetch per-hop 拦 | ⚠️ httpx 跟随（开关风险） |

开关=1 时的风险面：agent 能访问本机所有监听端口 + 内网所有服务。这是有意的——
用户开启 `SHERRY_WEB_FETCH_ALLOW_LOCAL=1` 就是允许 agent 调试本地服务。和
`SHERRY_ALLOW_PRIVATE_MEDIA_URLS=1`（媒体 URL 的私网开关）同一个设计模式：
opt-in，用户自担风险，默认关。

`_is_local_url` 只检查字面量 IP/hostname，不做 DNS 解析。一个域名解析到
`127.0.0.1` 不被识别为 local → 走公网路径 → `is_public_url` DNS 解析后拒绝。
两个开关状态下都不会被错误放行。代价是开关=1 时无法通过域名访问本地服务——
可接受，本地调试用 `localhost:port`。

## 6. 不做的事

- **不新建 `local_fetch` 工具**——同一个 `web_fetch` 内部分支。模型只看到一个工具，传什么 URL 都行，能不能访问由开关决定。
- **不做 DNS 解析识别本地域名**——`_is_local_url` 只看字面量。域名解析到 `127.0.0.1` 走公网路径被 `is_public_url` 拦。开关=1 时无法通过域名访问本地服务——可接受。
- **不做 HITL 审批**——HTTP GET 不走外部路径审批。和公网 `web_fetch` 一样是 agent 自主调用。
- **不做 per-session / per-spawn 开关**——进程级 `.env` 配置。本地调试是开发环境行为。
- **不做 URL 白名单**——开关打开 = 全部本地地址可访问。白名单增加复杂度但风险面不变。
