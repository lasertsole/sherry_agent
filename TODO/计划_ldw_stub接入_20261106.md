# 计划：ldw stub 接入（stub deepagents + --no-deps 装 ldw + 子模块直导）

> **方案 A**：不装 deepagents、不拷 ldw 代码。`pip install ldw --no-deps` + import 前 stub deepagents（sys.modules 注入假模块）+ 只导 sherry 需要的 5 个子模块（绕开 `__init__.py` 的 middleware/tool/leaves）。
>
> **比选择性 vendor 轻**：ldw 的 5「核心」模块传递依赖拉了 15+ 模块（含 _sandbox 1557 行/_local_subprocess 1260 行），vendor 不划算。stub 不拷任何代码，ldw 装着当黑盒执行后端。
>
> **sherry 不调 deepagents**：sherry 用 `roster.register(runnable=sherry_agent)` 注册自己的 agent 作 leaf，leaf 调用走 `runnable.ainvoke`（sherry agent），不进 ldw sandbox/subprocess 路径。deepagents 被 import（必须能解析）但不被 sherry 调用。
>
> **日期**：2026-11-06

## 一、deepagents 引用清单（已 grep）

ldw 里所有 deepagents import（7 处，6 文件）：

| 文件 | 引用 | sherry 调用？ |
|---|---|---|
| `_engine.py:15` | `from deepagents.backends.protocol import SandboxBackendProtocol` | 否（isinstance 检查，sherry agent 不是此类型 → False） |
| `_git_worktree.py:34` | 同上 | 否（git worktree，sherry 不用） |
| `_leaves.py:19` | `from deepagents import (create_deep_agent, ...)` | 否（deepagents 便利构造器，sherry 用 built_agent） |
| `_local_subprocess.py:46` | `from deepagents.backends.protocol import (...)` | 否（子进程 sandbox，sherry 不用 ldw sandbox） |
| `_sandbox.py:29` | `from deepagents.backends.composite import CompositeBackend` | 否 |
| `_sandbox.py:30` | `from deepagents.backends.protocol import (...)` | 否 |
| `_sandbox.py:48` | `from deepagents.backends.state import StateBackend` | 否 |

**结论**：deepagents 在 ldw 里用于 sandbox/subprocess 后端（sherry 不走这些路径）+ isinstance 检查（返回 False 无害）。stub 让 import 解析为空类/空函数，sherry 运行时不碰。

## 二、关键：只导子模块，绕开 `__init__.py`

ldw 的 `__init__.py`（198 行）导入了**几乎所有子模块**——含 `middleware.py`（`from langchain.agents.middleware import AgentMiddleware`，sherry 的 langchain 可能没这个）、`tool.py`（AST gate）、`_leaves.py`（deepagents 构造器）、`skills.py`。直接 `import langchain_dynamic_workflow` 会触发这些 → 可能除 deepagents 外还有 AgentMiddleware 等问题。

**解法**：sherry **只导 5 个子模块**，不走 `__init__.py`：

```python
from langchain_dynamic_workflow._engine import run_workflow
from langchain_dynamic_workflow._context import Ctx
from langchain_dynamic_workflow._dag import DagNode
from langchain_dynamic_workflow._roster import Roster
from langchain_dynamic_workflow._journal import InMemoryJournalStore, JournalStore
```

这 5 个子模块不 import middleware/tool/skills/`__init__`。它们传递依赖 _sandbox/_local_subprocess（import deepagents）→ stub 覆盖。不触发 AgentMiddleware 问题。

## 三、stub 设计（auto-stub 模块）

sherry 侧写一个 shim 模块，import ldw 前 stub deepagents：

```python
# agent/tools/subagent/ldw_shim.py
"""ldw 接入 shim：stub deepagents + 导出 ldw 核心子模块符号。

sherry 代码 import from this module, not from langchain_dynamic_workflow directly.
"""
import sys, types


class _AutoStubModule(types.ModuleType):
    """模块，任何属性访问自动创建空类（isinstance 安全——返回 False）。"""

    def __getattr__(self, name):
        cls = type(name, (), {})  # 真实类型，isinstance(x, cls) → False
        setattr(self, name, cls)
        return cls


def _install_deepagents_stub():
    """在 sys.modules 注入假 deepagents，让 ldw 的 import 解析成功。"""
    if "deepagents" in sys.modules:
        return  # 已有（不该发生在 sherry）

    da = _AutoStubModule("deepagents")
    da_backends = _AutoStubModule("deepagents.backends")
    da_protocol = _AutoStubModule("deepagents.backends.protocol")
    da_composite = _AutoStubModule("deepagents.backends.composite")
    da_state = _AutoStubModule("deepagents.backends.state")

    # 已知的函数 stub（sherry 不调，但 ldw import 时解析）
    da.create_deep_agent = lambda *a, **kw: None
    da.read_only_builder = lambda *a, **kw: None
    da.read_only_leaf = lambda *a, **kw: None

    # 已知的类 stub（isinstance 用，auto-stub 也会创建，但显式更清晰）
    da_protocol.SandboxBackendProtocol = type("SandboxBackendProtocol", (), {})
    da_composite.CompositeBackend = type("CompositeBackend", (), {})
    da_state.StateBackend = type("StateBackend", (), {})

    sys.modules["deepagents"] = da
    sys.modules["deepagents.backends"] = da_backends
    sys.modules["deepagents.backends.protocol"] = da_protocol
    sys.modules["deepagents.backends.composite"] = da_composite
    sys.modules["deepagents.backends.state"] = da_state


_install_deepagents_stub()

# 导出 ldw 核心子模块符号（不走 __init__.py）
from langchain_dynamic_workflow._engine import run_workflow
from langchain_dynamic_workflow._context import Ctx
from langchain_dynamic_workflow._dag import DagNode
from langchain_dynamic_workflow._roster import Roster
from langchain_dynamic_workflow._journal import InMemoryJournalStore, JournalStore

__all__ = ["run_workflow", "Ctx", "DagNode", "Roster", "InMemoryJournalStore", "JournalStore"]
```

- `_AutoStubModule`：任何 `from deepagents.xxx import YYY` 的 YYY 自动创建为空类（isinstance 安全）。已知的函数显式 stub（lambda None）。
- stub 在 `_install_deepagents_stub()` 里一次性注入，之后 ldw 的任何 `from deepagents...` 都解析到 stub。
- sherry 代码 `from agent.tools.subagent.ldw_shim import run_workflow, Ctx, DagNode, Roster`。

## 五、sherry agent 作 leaf

```python
from agent.tools.subagent.ldw_shim import Roster, run_workflow
from agent.core import built_agent
from langchain_core.runnables import RunnableLambda

def make_leaf_agent(functional_role, tools, model_profile):
    """sherry 子 agent（LangGraph 图 = Runnable）。"""
    return built_agent(tools=tools, model=build_model(model_profile), ...)

def wrap_leaf_with_session(agent_graph, session_id):
    """leaf 调用前设 session contextvar（sherry 工具进程级单例从 contextvar 读 session）。"""
    async def wrapped(input):
        with set_session_contextvar(session_id):
            return await agent_graph.ainvoke(input)
    return RunnableLambda(func=wrapped)

# 注册
roster = Roster()
roster.register(name="executor", runnable=wrap_leaf_with_session(graph, session_id))
```

**前提核实**：sherry 工具的 session-scoped state 通过 contextvar 传递（不是构造时捕获）。若构造时捕获 → 需改工具层从 contextvar 读（标为实现待办）。

## 六、验证

```python
# test_ldw_shim.py
from agent.tools.subagent.ldw_shim import run_workflow, Ctx, DagNode, Roster, InMemoryJournalStore
from langchain_core.runnables import RunnableLambda

# 假 leaf
roster = Roster()
roster.register(name="fake", runnable=RunnableLambda(func=lambda inp: {"output": f"done: {inp['messages'][-1].content}"}))

async def orchestrate(ctx):
    r1 = await ctx.agent(prompt="step1", agent_type="fake")
    r2 = await ctx.agent(prompt=f"step2 after {r1}", agent_type="fake")
    return {"r1": r1, "r2": r2}

result = asyncio.run(run_workflow(orchestrate, roster=roster))
assert "done: step1" in result["r1"]
# journal：同 prompt+agent_type 二次命中
result2 = asyncio.run(run_workflow(orchestrate, roster=roster))
# r1 应命中缓存（零调用）
```

1. `from agent.tools.subagent.ldw_shim import ...` 无 ImportError（stub 解析所有 deepagents）
2. 假 leaf + `ctx.agent` + `ctx.dag` 跑通
3. journal：同 prompt+agent_type 二次 `ctx.agent` 命中缓存（零调用）
4. `grep -r deepagents agent/tools/subagent/ldw_shim.py` 只有 stub 代码（无真实 deepagents 调用）

## 十、风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| ldw 核心路径运行时调 deepagents（非 import 时） | 中 | sherry 用 Roster.register(runnable=) 注册自己的 agent，leaf 走 runnable.ainvoke，不进 ldw sandbox/subprocess。Phase 0 验证：跑假 leaf + dag + journal，确认不触发 deepagents 调用 |
| stub 的 auto-class 被 ldw 当函数调（create_deep_agent 等） | 低 | 已知函数显式 stub lambda None；auto-class 是类型（callable，调用返回实例）——若 ldw 在 import 时调用且期望特定行为，可能断。但 _leaves 的函数 __init__.py 只 import 不调（sherry 不走 __init__.py，只导子模块） |
| ldw 子模块传递依赖拉了非 deepagents 的缺失包 | 低 | 5 子模块依赖 langgraph/langchain/pydantic（sherry 有）。_sandbox/_local_subprocess 可能拉其他（如 `subprocess`/`psutil`）——标准库或已有。Phase 0 验证 import 通 |
| sherry 工具构造时捕获 session（非 contextvar） | 中 | 核实；若是，改工具层（标为实现待办） |
| ldw 上游更新后 stub 不够（新 deepagents 引用） | 低 | auto-stub 自动覆盖新属性；已知函数显式 stub。ldw 更新后跑验证脚本 |

## 十二、与 ldw 重放/可视化计划的关系

- **替代「选择性 vendor」计划**（vendor 8000 行不划算，本计划零代码拷贝）。
- **是 ldw 重放计划（`计划_ldw重放已验证plan`）的 Phase 0**：stub 接入后，重放计划的 Phase 1+（sherry leaf + 编译器 + replay）基于 `ldw_shim` 的 `run_workflow`/`Roster`/`DagNode` 开始。
