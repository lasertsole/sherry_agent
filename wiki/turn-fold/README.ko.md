# 턴 실행 내역 접기

> 완료된 턴은 도구/추론 내역을 한 줄 요약 뒤로 접고 최종 답변은 항상 표시합니다.

## 🎯 개요

생성 턴이 끝나면 채팅은 어시스턴트의 실행 내역 — 도구 카드, 중간 어시스턴트
텍스트, 추론 — 을 작은 요약 행 뒤로 접습니다. 최종 어시스턴트 답변은 그 아래에 항상
표시됩니다. 요약을 펼치면 전체 선형 내역이 복원됩니다.

실행 중이거나, 도구 호출로 끝났거나, 최종 답변이 없거나, 미해결 도구 호출을 가진
턴은 **접지 않습니다**. 기존 선형 렌더링을 유지합니다. 이것이 fail-open 경계이며,
비정상 턴이 작업을 숨기지 않습니다.

## 🧭 분류

접기는 기존 message 행에서 파생됩니다. 어시스턴트 작업 그룹은 다음을 모두 만족할
때만 접을 수 있습니다:

| 조건 | 요구 사항 |
| :--- | :--- |
| 마지막 행 | 그룹의 마지막 행이 AI 행 |
| 완료됨 | `streaming`이 false |
| 표시 내용 | 텍스트 또는 미디어 첨부가 있음 |
| 완결됨 | 행이 도구 호출을 선언하지 않음(`hasToolCalls` false) |
| 일반 행 | 주입 캐리어가 아님(user가 아닌 `origin` 없음) |
| 접을 내용 | 앞에 내역 행이 있거나 추론이 있음 |

`history`는 최종 답변 이전의 모든 행입니다. 내역도 추론도 없는 단일 답변은 접을
내용이 없으므로 선형으로 유지됩니다.

## ⚙️ 상호작용

- 완료된 그룹은 **접힌 상태**로 시작합니다. 요약은 측정된 도구 작업(N개 도구와
  알려진 경우 합산 시간) 또는 추론을 표시합니다.
- 요약 행은 그 자리에서 내역을 토글합니다. 펼친 뒤에도 내부 도구 카드는 각자의
  펼침/접힘 상태를 유지합니다.
- 접힌 상태에서 최종 행은 사고 블록을 렌더링하지 않고 아바타는 유지합니다. 연속
  메시지로 오인하지 않게 하기 위해서입니다.
- 펼침 상태는 마운트된 채팅 페이지에 속합니다(영속화 없음). 새로고침하면 다시
  분류되어 접힌 상태로 돌아갑니다.
- 토글 후 가상 리스트가 행 높이를 다시 측정하므로 스크롤 형상이 정확하게 유지됩니다.

## 🧩 아키텍처

`use-chat-turn-groups`는 이미 발화자 경계로 행을 나눕니다. USER 행은 자체 그룹을
만들고, 뒤따르는 AI/TOOL 행이 하나의 어시스턴트 작업 그룹을 이룹니다.
`use-chat-turn-fold.ts::classifyTurnFold`가 그 그룹을
`{history, finalMessage, toolCount, durationMs, hasReasoning}`로 변환합니다.

`MessageItem.hasToolCalls`는 저장된 AI 행의 `tool_calls`에서 매핑되므로 도구 호출을
가진 행이 최종 답변으로 오인되지 않습니다. `ChatTurnHistoryStatus.vue`는 요약
트리거입니다. `ChatBox.vue`는 표시할 행을 고르고 접힌 상태에서 최종 행의 추론을
숨깁니다. `use-chat-card-expansion.ts`는 그룹별 펼침 집합을 소유합니다.

분류는 **의도적으로 클라이언트 측**입니다. message 행은 `turn_num`을 가지지만 안정적인
turn id가 없고, trajectory 원장은 도구 이벤트를 저장하지만 어시스턴트 텍스트는
저장하지 않습니다. 서버 render-unit API나 WebSocket frame은 클라이언트가 이미 가진
행을 복제할 뿐입니다. 로드된 message 프로토콜에서 파생하면 내역 새로고침과 재연결이
동일한 결과를 내고 schema나 frame을 추가하지 않습니다.

원래 계획의 선택적 structured-response 요약은 사용하지 않습니다. 접기는 LLM 협력이
필요 없고 최종 답변은 어시스턴트 행 원문을 그대로 사용합니다.

## 🧪 테스트

`use-chat-turn-fold.test.ts`는 분류(완료된 최종 답변, 스트리밍, 끝의 도구, 도구 호출이
있는 AI 행, 추론만, 알 수 없는 시간, 미디어만, 캐리어 처리)를 고정합니다. ChatBox
통합 테스트는 접힌 요약, 펼침, 실행 중 선형 폴백, 일반 답변 비접기, 끝의 도구
fail-open을 고정합니다. 로케일과 i18n block 테스트가 4개 언어 라벨을 커버합니다.
