# Characters used ONLY in Simplified Chinese.
#
# Shared by two gates so they cannot drift apart:
#   * scripts/check_doc_language.py — the ja/ko pages of README and wiki must not
#     carry Simplified Chinese text (the English pages ban CJK ideographs outright);
#   * client/app/composables/__tests__/locales.test.ts and i18nBlocks.test.ts —
#     a ja/ko locale value must not carry Simplified Chinese (an en value may not
#     carry CJK at all).
#
# Curated, not exhaustive: every character here is a Simplified-only form that
# does NOT occur in Japanese shinjitai (e.g. 时 vs 時, 图 vs 図, 问 vs 問) and is
# not used in Korean prose, so a hit is a real mixed-language leak. Characters
# whose simplified form coincides with a common Japanese word are deliberately
# ABSENT: 后 (皇后), 万 (万歳), 号 (番号), 体 (体), 国 (国), 数 (数), 条 (条),
# 断 (断), 制 (制), 写 (写), 些 (些細); and so are the simplified forms JAPANESE
# USES TOO — 装 (実装 / 武装 / 偽装), 没 (没入 / 沈没), 据 (据える) — a live run
# caught them as false positives. A label built only from shared characters
# (模型配置, 分叉) is therefore not detectable — this gate targets mixed prose,
# not every possible label.
