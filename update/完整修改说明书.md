## 任务一：会话管理改造

**目标**：移除左侧硬编码的"示例会话"，改为点击"新建对话"时用 `crypto.randomUUID()` 生成随机 session_id 创建新会话窗口，并显示在左侧会话栏。首屏加载时自动创建一个新会话。

> **注意**：以下路径 1~8 中的 `client/` 对应旧版本中的 `client_future/`。如果尚未执行任务三的重命名，请将路径中的 `client/` 替换为 `client_future/`。

### 改动 2：实现 handleCreateSession 函数

**文件**：`client_future/app/pages/home/index.vue`

**旧代码**（约第 653 行）：
```typescript
/** 新增会话 */
const handleCreateSession = () => {};
```

**新代码**：
```typescript
/** 新增会话：生成随机 session_id，创建新会话窗口并切换 */
const handleCreateSession = () => {
  const sessionId = crypto.randomUUID();
  const now = new Date();
  const pad = (n: number) => String(n).padStart(2, '0');
  const createTime = `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())} ${pad(now.getHours())}:${pad(now.getMinutes())}`;
  const newSession: SessionRecord = {
    id: sessionId,
    title: t('history.newSession'),
    createTime
  };
  historyList.value = [newSession, ...historyList.value];
  currentSession.value = newSession;
  currentSessionId.value = sessionId;
  chatMessages.value = [];
  isSidebarOpen.value = false;
};
```

**原因**：实现"新建对话"功能——生成随机 session_id，创建会话记录插入左侧列表顶部，切换为当前会话，清空聊天区。
