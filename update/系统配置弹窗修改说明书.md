## 背景

### 需求

将 client 页面右上角主题切换（ModeSwitch）左侧的菜单栏改为：点击后弹出模态框，模态框中分 4 个 Tab 配置服务器的 `workspace/AGENTS.md`、`workspace/IDENTITY.md`、`workspace/SOUL.md`、`workspace/USER.md`，字数限制对齐服务端（2000 字符）。

### 改动前状态

- 右上角工具栏（`headerTools`）有 2 个按钮："配置知识库"（`pi pi-file-edit`，event=`knowledgeBase`）和"个人中心"（`pi pi-user`，event=`userCenter`），两者在 `handleOperate` 中都是空操作（直接 `return`）。
- 主题切换组件 `ModeSwitch` 在工具栏最左侧。
- 移动端通过齿轮按钮（`pi pi-cog`）打开 PrimeVue `Menu` 弹出菜单，但 `:model` 直接绑定 `headerTools` 数组，缺少 `command` 回调，点击菜单项无响应（原有 bug）。
- 服务端已有完整 API（`GET/PUT/PATCH /system_prompt`），`bridge.ts` 已有 `readSystemPrompt()`、`writeSystemPrompt()`、`updateSystemPrompt()` 函数可直接调用。
- 服务端字符限制：每个文件内容不超过 2000 字符（`server/service/workplace.py` 第 26 行 `len(content) > 2_000`）。

### 改动后状态

- 右上角工具栏仅 1 个按钮："系统配置"（`pi pi-cog`，event=`systemConfig`），点击打开模态框。
- 模态框包含 4 个 Tab：核心规则（AGENTS.md）、身份信息（IDENTITY.md）、人格灵魂（SOUL.md）、用户信息（USER.md）。
- 每个 Tab 内为 `Textarea` 编辑器，实时显示字符计数（`当前字数 / 2000`），超限变红、接近上限变橙。
- 打开模态框时自动调用 `readSystemPrompt()` 加载当前内容；保存时仅提交有改动的文件，调用 `writeSystemPrompt()`。
- 保存按钮在加载中/保存中/内容超限/内容为空时禁用。
- 移动端 Menu 弹出菜单修复为使用 `headerMenuModel` computed，包含 `command` 回调。

## 改动 1：新建 ConfigDialog.vue 组件

**操作**：创建新文件。

**文件路径**：`client/app/pages/home/components/ConfigDialog.vue`

**完整文件内容**：

```vue
<template>
  <Dialog
    v-model:visible="visible"
    :header="t('config.title')"
    :modal="true"
    :closable="true"
    class="w-[90vw] md:w-[700px]"
    @show="loadContent"
    @hide="onHide">
    <div class="flex flex-col gap-3">
      <div v-if="loading" class="flex items-center justify-center py-8">
        <ProgressSpinner style="width: 2rem; height: 2rem" />
      </div>
      <template v-else>
        <TabView v-model:activeIndex="activeTab">
          <TabPanel
            v-for="tab in tabs"
            :key="tab.file"
            :header="t(tab.i18nKey)">
            <div class="flex flex-col gap-2">
              <div class="flex items-center justify-between">
                <span class="text-sm text-gray-500 dark:text-gray-400">{{ t(tab.i18nDescKey) }}</span>
                <span
                  :class="[
                    'text-xs',
                    (editContent[tab.file]?.length ?? 0) > MAX_CHARS
                      ? 'text-red-500'
                      : (editContent[tab.file]?.length ?? 0) > MAX_CHARS * 0.9
                        ? 'text-orange-500'
                        : 'text-gray-400'
                  ]">
                  {{ editContent[tab.file]?.length ?? 0 }} / {{ MAX_CHARS }}
                </span>
              </div>
              <Textarea
                v-model="editContent[tab.file]"
                :autoResize="true"
                rows="12"
                class="w-full font-mono text-sm"
                :maxlength="MAX_CHARS"
                :pt="{ root: { style: 'max-height: 400px; overflow: auto' } }" />
            </div>
          </TabPanel>
        </TabView>
      </template>
    </div>
    <template #footer>
      <div class="flex gap-2 justify-end">
        <Button
          :label="t('config.cancel')"
          icon="pi pi-times"
          severity="secondary"
          @click="visible = false" />
        <Button
          :label="t('config.save')"
          icon="pi pi-check"
          :loading="saving"
          :disabled="!canSave"
          @click="handleSave" />
      </div>
    </template>
  </Dialog>
</template>

<script lang="ts" setup>
import { ref, computed, watch } from 'vue';
import { useI18n } from 'vue-i18n';
import { readSystemPrompt, writeSystemPrompt } from '@/composables/bridge';

const { t } = useI18n();

const props = defineProps<{ modelValue: boolean }>();
const emits = defineEmits<{ 'update:modelValue': [value: boolean] }>();

const visible = computed({
  get: () => props.modelValue,
  set: (v) => emits('update:modelValue', v),
});

const MAX_CHARS = 2000;

const tabs = [
  { file: 'AGENTS.md', i18nKey: 'config.tabs.agents', i18nDescKey: 'config.desc.agents' },
  { file: 'IDENTITY.md', i18nKey: 'config.tabs.identity', i18nDescKey: 'config.desc.identity' },
  { file: 'SOUL.md', i18nKey: 'config.tabs.soul', i18nDescKey: 'config.desc.soul' },
  { file: 'USER.md', i18nKey: 'config.tabs.user', i18nDescKey: 'config.desc.user' },
] as const;

const activeTab = ref(0);
const loading = ref(false);
const saving = ref(false);
const editContent = ref<Record<string, string>>({});
const originalContent = ref<Record<string, string>>({});

const canSave = computed(() => {
  if (loading.value || saving.value) return false;
  return tabs.every(
    (tab) =>
      (editContent.value[tab.file]?.length ?? 0) <= MAX_CHARS &&
      (editContent.value[tab.file]?.length ?? 0) > 0,
  );
});

const loadContent = async () => {
  loading.value = true;
  try {
    const data = await readSystemPrompt();
    const content: Record<string, string> = {};
    for (const tab of tabs) {
      content[tab.file] = data[tab.file] ?? '';
    }
    editContent.value = { ...content };
    originalContent.value = { ...content };
  } catch (e) {
    console.error('[ConfigDialog] Failed to load system prompts:', e);
  } finally {
    loading.value = false;
  }
};

const handleSave = async () => {
  saving.value = true;
  try {
    const fileToContent: Record<string, string> = {};
    for (const tab of tabs) {
      const content = editContent.value[tab.file] ?? '';
      if (content !== (originalContent.value[tab.file] ?? '')) {
        fileToContent[tab.file] = content;
      }
    }
    if (Object.keys(fileToContent).length > 0) {
      await writeSystemPrompt(fileToContent);
    }
    visible.value = false;
  } catch (e) {
    console.error('[ConfigDialog] Failed to save system prompts:', e);
  } finally {
    saving.value = false;
  }
};

const onHide = () => {
  activeTab.value = 0;
};
</script>
```

**原因**：创建独立的系统配置模态框组件，包含 4 个 Tab 对应 4 个 workspace 文件，通过 `readSystemPrompt()` / `writeSystemPrompt()` 与服务端 API 交互，2000 字符限制对齐服务端 `server/service/workplace.py` 第 26 行。

**关键设计说明**：

- `MAX_CHARS = 2000`：对齐服务端 `len(content) > 2_000` 限制（`server/service/workplace.py` 第 26、44 行）。
- `Textarea` 设置 `:maxlength="MAX_CHARS"`：浏览器层面硬限制输入长度。
- `canSave` computed：所有 Tab 内容都不超限且不为空时才允许保存。
- `handleSave`：仅提交有改动的文件（`content !== originalContent`），减少不必要的网络请求。
- `@show="loadContent"`：每次打开弹窗时重新加载服务端最新内容。
- 字符计数颜色逻辑：超限红色 `text-red-500`，超过 90% 橙色 `text-orange-500`，正常灰色 `text-gray-400`。
- 依赖 PrimeVue 组件：`Dialog`、`TabView`、`TabPanel`、`Textarea`、`Button`、`ProgressSpinner`（项目已全局注册 PrimeVue，无需手动 import）。
- 依赖 `bridge.ts` 中的 `readSystemPrompt()` 和 `writeSystemPrompt()`（已存在，无需新建）。

## 改动 6：index.vue 修复移动端 Menu 点击无响应

**文件路径**：`client/app/pages/home/index.vue`

### 6a. Menu 组件的 `:model` 绑定

**旧代码**（约第 83-88 行，模板中 Menu 组件）：
```html
          <Menu
            class="md:hidden"
            ref="headerToolsMenuRef"

```

**新代码**：
```html
          <Menu
            class="md:hidden"
            ref="headerToolsMenuRef"
            id="header_tools"
            :model="headerMenuModel"
            :popup="true"></Menu>
```

### 6b. 新增 headerMenuModel computed

**旧代码**（约第 694-696 行，`headerToolsMenuRef` 和 `openHeaderMenu` 定义处）：
```typescript
const headerToolsMenuRef = ref<InstanceType<typeof Menu>>();
const openHeaderMenu = (event: Event) => {
  headerToolsMenuRef.value?.toggle(event);
};
```

**新代码**：
```typescript
const headerToolsMenuRef = ref<InstanceType<typeof Menu>>();
const headerMenuModel = computed(() =>
  headerTools.map((tool) => ({
    label: t(tool.toolName),
    icon: tool.icon,
    command: () => handleOperate('headerBar', tool.event),
  })),
);
const openHeaderMenu = (event: Event) => {
  headerToolsMenuRef.value?.toggle(event);
};
```

**原因**：PrimeVue `Menu` 组件的 `:model` 需要包含 `label`、`icon`、`command` 字段的菜单项对象数组。原代码直接传入 `headerTools`（只有 `toolName`、`icon`、`event` 等字段，缺少 `command` 回调和 `label`），导致移动端点击菜单项无响应。新增 `headerMenuModel` computed 将 `headerTools` 转换为 PrimeVue Menu 所需格式，`command` 回调中调用 `handleOperate('headerBar', tool.event)`。
