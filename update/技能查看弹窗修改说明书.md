## 背景

### 需求

在 client 页面右上角添加"技能"按钮，点击后弹出模态框，可以查看内置技能、auto 技能和第三方技能。其中内置技能和 auto 技能不能修改，仅能查看。第三方技能也仅查看。

### 改动前状态

- 服务端无 HTTP `/skills` 端点，技能仅通过 LangChain agent 工具（`skill_list`、`skill_view`、`skill_manage`）访问。
- `bridge.ts` 无技能相关函数。
- 技能目录结构：
  - `skills/builtin/` — 内置技能（随项目发布，只读）
  - `skills/auto/` — Agent 自动创建的技能（curator 管理）
  - `skills/plugins/` — 第三方技能（通过 ClawHub 安装）
- 技能加载逻辑在 `skills/loader.py` 的 `scan_skills()` 中，递归扫描 `SKILLS_DIR/**/SKILL.md`。
- `SKILLS_DIR` 定义在 `config/path.py`：`SKILLS_DIR = ROOT_DIR / "skills"`。

### 改动后状态

- 服务端新增 `GET /skills`（列出所有技能）和 `GET /skills/<path>`（读取单个技能详情）。
- `bridge.ts` 新增 `listSkills()`、`readSkill()` 函数和 `SkillInfo`、`SkillDetail` 类型。
- 新建 `SkillsDialog.vue` 组件：3 个分类标签（内置/Auto/第三方），左侧技能列表 + 右侧详情面板，所有分类仅查看不可编辑。

## 改动 1：新建服务端 HTTP 端点 skills.py

**操作**：创建新文件。

**文件路径**：`server/trigger/http/skills.py`

**完整文件内容**：

```python
from server.trigger.core import app
from loguru import logger
from skills.loader import scan_skills, parse_frontmatter
from config import SKILLS_DIR


def _get_category(location: str) -> str:
    parts = location.strip("./").split("/")
    if len(parts) >= 2:
        cat = parts[1]
        if cat == "plugins":
            return "third_party"
        return cat
    return "unknown"


@app.get("/skills")
async def list_skills_handler(request):
    skills = scan_skills(use_cache=False)
    result = []
    for s in skills:
        result.append({
            "name": s["name"],
            "description": s["description"],
            "location": s["location"],
            "category": _get_category(s["location"]),
        })
    result.sort(key=lambda x: (x["category"], x["name"]))
    logger.debug(f"Listed skills: count={len(result)}")
    return {"skills": result}


@app.get("/skills/<skill_path:path>")
async def read_skill_handler(request, skill_path: str):
    from pathlib import Path
    from config import ROOT_DIR

    full_path = ROOT_DIR / skill_path
    if not full_path.exists() or not full_path.is_file():
        logger.warning(f"Skill file not found: {skill_path}")
        return {"error": "Skill file not found"}, 404

    content = full_path.read_text(encoding="utf-8")
    meta = parse_frontmatter(content)
    category = _get_category(f"./{skill_path}")

    logger.debug(f"Read skill: path={skill_path}, name={meta.get('name', '')}")
    return {
        "name": str(meta.get("name", full_path.parent.name)),
        "description": str(meta.get("description", "")),
        "content": content,
        "category": category,
        "location": f"./{skill_path}",
    }
```

**关键设计说明**：

- `_get_category(location)`：从技能的 `location` 路径（如 `./skills/builtin/core/cron/SKILL.md`）提取第二段目录名作为分类。`plugins` 目录映射为 `third_party`。
- `GET /skills`：调用 `scan_skills(use_cache=False)` 强制扫描磁盘（不用 JSON 缓存），为每个技能补充 `category` 字段，按 `(category, name)` 排序。
- `GET /skills/<skill_path:path>`：Robyn 路由参数 `<skill_path:path>` 支持斜杠路径。用 `ROOT_DIR / skill_path` 拼接绝对路径，读取文件内容，解析 frontmatter，返回完整技能信息。
- 依赖已有：`scan_skills` 和 `parse_frontmatter` 来自 `skills/loader.py`，`ROOT_DIR` 来自 `config`。

## 改动 3：bridge.ts 新增 SkillInfo/SkillDetail 类型和 listSkills/readSkill 函数

**文件路径**：`client/app/composables/bridge.ts`

### 3a. 新增类型定义（文件末尾追加）

在文件最末尾追加：

```typescript
// ── Skills ───────────────────────────────────────────────

export interface SkillInfo {
  name: string;
  description: string;
  location: string;
  category: 'builtin' | 'auto' | 'third_party';
}

export interface SkillDetail extends SkillInfo {
  content: string;
}
```

### 3b. 新增 listSkills 和 readSkill 函数

在 `checkHealth` 函数之前（`// ── Health ───` 注释行之前）插入：

```typescript
/**
 * List all skills (builtin, auto, third_party).
 */
export async function listSkills(): Promise<{ skills: SkillInfo[] }> {
  return fetchApi({ url: '/skills', method: 'get' }) as unknown as Promise<{ skills: SkillInfo[] }>;
}

/**
 * Read a single skill's full SKILL.md content.
 */
export async function readSkill(location: string): Promise<SkillDetail> {
  const cleanPath = location.replace(/^\.\//, '');
  return fetchApi({ url: `/skills/${cleanPath}`, method: 'get' }) as unknown as Promise<SkillDetail>;
}
```

**关键设计说明**：

- `listSkills()`：调用 `GET /skills`，返回 `{ skills: SkillInfo[] }`。
- `readSkill(location)`：`location` 格式为 `./skills/builtin/xxx/SKILL.md`，去掉 `./` 前缀后拼入 URL 路径，调用 `GET /skills/skills/builtin/xxx/SKILL.md`。
- 两个函数仅在浏览器模式（非 Tauri）下工作——通过 `fetchApi` 发 HTTP 请求。如需 Tauri 模式支持，需额外添加 `isTauri()` 分支和对应的 Rust IPC 命令。
- 类型定义放在文件末尾，函数放在 Health 区块之前。

## 改动 4：新建 SkillsDialog.vue 组件

**操作**：创建新文件。

**文件路径**：`client/app/pages/home/components/SkillsDialog.vue`

**完整文件内容**：

```vue
<template>
  <Dialog
    v-model:visible="visible"
    :header="t('skills.title')"
    :modal="true"
    :closable="true"
    class="w-[90vw] md:w-[800px]"
    @show="loadSkills"
    @hide="onHide">
    <div class="flex flex-col gap-3">
      <div v-if="loading" class="flex items-center justify-center py-8">
        <ProgressSpinner style="width: 2rem; height: 2rem" />
      </div>
      <template v-else>
        <div class="flex gap-2 flex-wrap">
          <Button
            v-for="cat in categories"
            :key="cat.key"
            :label="t(cat.i18nKey) + ' (' + groupedSkills[cat.key]?.length + ')'"
            :severity="activeCategory === cat.key ? undefined : 'secondary'"
            size="small"
            @click="activeCategory = cat.key" />
        </div>
        <div class="flex gap-3" style="min-height: 400px;">
          <div class="w-48 shrink-0 overflow-auto flex flex-col gap-1" style="max-height: 450px;">
            <div
              v-for="skill in currentSkills"
              :key="skill.location"
              :class="[
                'px-3 py-2 rounded-lg cursor-pointer text-sm truncate border border-transparent',
                selectedSkill?.location === skill.location
                  ? 'bg-primary-50 dark:bg-primary-900/20 border-primary-200 dark:border-primary-700'
                  : 'hover:bg-gray-50 dark:hover:bg-gray-800'
              ]"
              @click="selectSkill(skill)">
              {{ skill.name }}
            </div>
            <div v-if="currentSkills.length === 0" class="text-sm text-gray-400 px-3 py-2">
              {{ t('skills.empty') }}
            </div>
          </div>
          <div class="flex-1 overflow-auto rounded-lg bg-gray-50 dark:bg-gray-800/50 p-4" style="max-height: 450px;">
            <div v-if="detailLoading" class="flex items-center justify-center h-full">
              <ProgressSpinner style="width: 2rem; height: 2rem" />
            </div>
            <template v-else-if="skillDetail">
              <div class="flex items-center justify-between mb-3">
                <div class="flex flex-col">
                  <span class="text-lg font-bold">{{ skillDetail.name }}</span>
                  <span v-if="skillDetail.description" class="text-sm text-gray-500 dark:text-gray-400">{{ skillDetail.description }}</span>
                </div>
                <div class="flex items-center gap-2">
                  <Tag
                    v-if="isReadonly(activeCategory)"
                    :value="t('skills.readonly')"
                    severity="warn"
                    size="small" />
                  <Tag
                    :value="t(categoryI18nKey(activeCategory))"
                    severity="info"
                    size="small" />
                </div>
              </div>
              <pre v-if="skillDetail.content" class="text-sm whitespace-pre-wrap font-mono m-0">{{ stripFrontmatter(skillDetail.content) }}</pre>
            </template>
            <div v-else class="flex items-center justify-center h-full text-sm text-gray-400">
              {{ t('skills.selectHint') }}
            </div>
          </div>
        </div>
      </template>
    </div>
  </Dialog>
</template>

<script lang="ts" setup>
import { ref, computed } from 'vue';
import { useI18n } from 'vue-i18n';
import { listSkills, readSkill } from '@/composables/bridge';
import type { SkillInfo, SkillDetail } from '@/composables/bridge';

const { t } = useI18n();

const props = defineProps<{ modelValue: boolean }>();
const emits = defineEmits<{ 'update:modelValue': [value: boolean] }>();

const visible = computed({
  get: () => props.modelValue,
  set: (v) => emits('update:modelValue', v),
});

const categories = [
  { key: 'builtin' as const, i18nKey: 'skills.tabs.builtin' },
  { key: 'auto' as const, i18nKey: 'skills.tabs.auto' },
  { key: 'third_party' as const, i18nKey: 'skills.tabs.thirdParty' },
];

const loading = ref(false);
const detailLoading = ref(false);
const allSkills = ref<SkillInfo[]>([]);
const activeCategory = ref<'builtin' | 'auto' | 'third_party'>('builtin');
const selectedSkill = ref<SkillInfo | null>(null);
const skillDetail = ref<SkillDetail | null>(null);

const groupedSkills = computed(() => {
  const groups: Record<string, SkillInfo[]> = { builtin: [], auto: [], third_party: [] };
  for (const s of allSkills.value) {
    const cat = s.category;
    if (groups[cat]) groups[cat].push(s);
    else groups.third_party.push(s);
  }
  return groups;
});

const currentSkills = computed(() => groupedSkills.value[activeCategory.value] ?? []);

const isReadonly = (category: string) => category === 'builtin' || category === 'auto';

const categoryI18nKey = (category: string) => {
  const found = categories.find((c) => c.key === category);
  return found ? found.i18nKey : 'skills.tabs.thirdParty';
};

const stripFrontmatter = (content: string) => {
  if (content.startsWith('---')) {
    const parts = content.split('---', 3);
    if (parts.length >= 3) return parts[2].trim();
  }
  return content;
};

const loadSkills = async () => {
  loading.value = true;
  try {
    const resp = await listSkills();
    allSkills.value = resp.skills ?? [];
  } catch (e) {
    console.error('[SkillsDialog] Failed to load skills:', e);
  } finally {
    loading.value = false;
  }
};

const selectSkill = async (skill: SkillInfo) => {
  selectedSkill.value = skill;
  skillDetail.value = null;
  detailLoading.value = true;
  try {
    skillDetail.value = await readSkill(skill.location);
  } catch (e) {
    console.error('[SkillsDialog] Failed to read skill:', e);
  } finally {
    detailLoading.value = false;
  }
};

const onHide = () => {
  selectedSkill.value = null;
  skillDetail.value = null;
  activeCategory.value = 'builtin';
};
</script>
```

**关键设计说明**：

- **3 个分类标签按钮**：顶部 `Button` 组，显示分类名 + 数量，点击切换 `activeCategory`。
- **左右布局**：左侧 `w-48` 技能列表（可滚动），右侧详情面板（灰底，可滚动）。
- **`groupedSkills` computed**：将 `allSkills` 按 `category` 字段分到 3 个数组。未知分类归入 `third_party`。
- **`isReadonly`**：`builtin` 和 `auto` 返回 `true`，显示"只读"Tag。第三方也仅查看，但不显示只读标签（因为用户需求仅提及内置和 auto 不可修改）。
- **`stripFrontmatter`**：从 SKILL.md 内容中去掉 YAML frontmatter（`---` 包裹部分），只展示正文。
- **`@show="loadSkills"`**：每次打开弹窗时调用 `listSkills()` 加载最新技能列表。
- **`selectSkill`**：点击左侧技能项时，调用 `readSkill(location)` 加载详情，显示在右侧面板。
- 依赖 PrimeVue 组件：`Dialog`、`Button`、`ProgressSpinner`、`Tag`（已全局注册）。
- 依赖 `bridge.ts` 中的 `listSkills`、`readSkill` 函数和 `SkillInfo`、`SkillDetail` 类型。
