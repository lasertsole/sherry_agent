## 背景

### 需求

在系统配置弹窗中添加修改 AI 头像、AI 名称、用户头像、用户名称的功能。保存后页面立即刷新显示新的角色信息。

### 改动前状态

- `ConfigDialog.vue` 有 4 个 Tab（AGENTS.md / IDENTITY.md / SOUL.md / USER.md），仅编辑系统提示词文件。
- 服务端已有 `GET/PUT/PATCH /character` 端点，`bridge.ts` 已有 `readCharacter()` / `writeCharacter()` / `updateCharacter()` 函数。
- 服务端 `update_character()` 支持部分更新 `user.name`、`user.avatar`、`assistant.name`、`assistant.avatar` 四个字段（`server/service/workplace.py` 第 74-91 行）。
- 服务端无头像上传端点，`bridge.ts` 无头像上传函数。
- `index.vue` 已有 `loadCharacter()` 函数从服务端加载角色信息并更新 `characterInfo` ref。
- 头像图片存储在 `static/` 目录下，前端通过 `{baseURL}/static/{path}` 访问。

### 改动后状态

- 服务端新增 `POST /character/avatar` 端点：接收图片字节，保存到 `static/avatar/`，返回相对路径如 `avatar/xxx.png`。
- `bridge.ts` 新增 `uploadAvatar(file)` 函数。
- `ConfigDialog.vue` 新增第 5 个 Tab"角色配置"：AI 头像（上传+预览）+ AI 名称（文本输入），用户头像（上传+预览）+ 用户名称（文本输入）。保存时调用 `updateCharacter()` 提交变更，并 emit `saved` 事件通知父组件刷新。
- `index.vue` 监听 ConfigDialog 的 `@saved` 事件，触发 `loadCharacter()` 重新加载角色信息。

```python
from robyn import Response

```

**原因**：新增 `Response`（Robyn 响应对象）、`STATIC_DIR`（静态文件目录，来自 `config/path.py`）、`uuid`（生成唯一文件名）。

### 1b. 文件末尾追加头像上传端点

在文件末尾（`update_character_handler` 之后）追加：

```python


_CONTENT_TYPE_TO_EXT: dict[str, str] = {
    "image/png": ".png",
    "image/jpeg": ".jpg",
    "image/webp": ".webp",
    "image/gif": ".gif",
    "image/bmp": ".bmp",
}


@app.post("/character/avatar")
async def upload_avatar_handler(request):
    """
    Upload an avatar image. Saves to static/avatar/ and returns the relative path.
    """
    body = request.body
    if isinstance(body, bytes):
        data = body
    elif isinstance(body, str):
        data = body.encode("utf-8")
    else:
        data = b""

    if not data:
        logger.warning("Avatar upload rejected: empty body")
        return Response(
            status_code=400,
            headers={"Content-Type": "application/json"},
            description='{"success": false, "message": "Empty request body"}',
        )

    content_type = request.headers.get("Content-Type", "")
    ct = content_type.split(";")[0].strip().lower()
    ext = _CONTENT_TYPE_TO_EXT.get(ct, ".png")

    filename = f"{uuid.uuid4().hex}{ext}"
    avatar_dir = STATIC_DIR / "avatar"
    avatar_dir.mkdir(parents=True, exist_ok=True)
    file_path = avatar_dir / filename
    file_path.write_bytes(data)

    relative_path = f"avatar/{filename}"
    logger.info(f"Avatar uploaded: filename={filename}, size={len(data)}")
    return Response(
        status_code=200,
        headers={"Content-Type": "application/json"},
        description=f'{{"success": true, "path": "{relative_path}"}}',
    )
```

**关键设计说明**：

- `_CONTENT_TYPE_TO_EXT`：Content-Type 到文件扩展名映射，用于根据上传图片类型选择正确扩展名。
- `POST /character/avatar`：接收原始图片字节（request body），保存到 `static/avatar/{uuid}.{ext}`。
- 返回 JSON `{"success": true, "path": "avatar/xxx.png"}`，`path` 是相对 `static/` 的路径，前端拼成 `{baseURL}/static/avatar/xxx.png` 访问。
- `avatar_dir.mkdir(parents=True, exist_ok=True)`：首次上传时自动创建 `static/avatar/` 目录。
- 使用 `Response` 手动构造响应，因为需要返回自定义 JSON body（与现有 `image.py` 的 `upload_image` 端点模式一致）。

**新代码**：
```typescript
/**
 * Partially update character configuration (merge).
 */
export async function updateCharacter(data: CharacterData): Promise<void> {
  if (isTauri()) {
    const invoke = await getInvoke();
    await invoke('character_update', { payload: { character_data: data } });
  } else {
    await fetchApi({
      url: '/character',
      opts: { character_data: data },
      method: 'put',
    });
  }
}

/**
 * Upload an avatar image to the server. Returns the relative path (e.g. "avatar/xxx.png").
 */
export async function uploadAvatar(file: File): Promise<string> {
  const baseURL = import.meta.env.VITE_API_BACK_URL || 'http://localhost:8080';
  const resp = await fetch(`${baseURL}/character/avatar`, {
    method: 'POST',
    headers: { 'Content-Type': file.type },
    body: file,
  });
  if (!resp.ok) throw new Error(`Avatar upload failed: HTTP ${resp.status}`);
  const json = await resp.json();
  return json.path;
}

// ── Health ───────────────────────────────────────────────
```

**关键设计说明**：

- 使用原生 `fetch` 而非 `fetchApi`，因为头像上传是原始字节（`body: file`），不是 JSON，`fetchApi` 的 JSON 序列化逻辑不适用。
- `Content-Type` 设为 `file.type`（如 `image/png`），服务端据此判断扩展名。
- 返回 `json.path`（如 `"avatar/abc123.png"`），是相对 `static/` 的路径。
- 不支持 Tauri 模式（无 `isTauri()` 分支）。如需 Tauri 支持，需添加对应的 Rust IPC 命令。

## 改动 3：ConfigDialog.vue 重写（新增角色 Tab + saved 事件）

**文件路径**：`client/app/pages/home/components/ConfigDialog.vue`

**操作**：用以下完整内容替换整个文件。

> **注意**：此改动基于"系统配置弹窗修改说明书"中创建的 ConfigDialog.vue（4 Tab 版本）。如果旧版本没有 ConfigDialog.vue，请先按"系统配置弹窗修改说明书"创建 4 Tab 版本，再执行此改动。

**新代码（完整文件）**：

```vue
<template>
  <Dialog
    v-model:visible="visible"
    :header="t('config.title')"
    :modal="true"
    :closable="true"
    class="w-[90vw] md:w-[700px]"
    @show="loadContent"
    @hide="onHide">
    <div class="flex flex-col gap-3">
      <div v-if="loading" class="flex items-center justify-center py-8">
        <ProgressSpinner style="width: 2rem; height: 2rem" />
      </div>
      <template v-else>
        <TabView v-model:activeIndex="activeTab">
          <TabPanel
            v-for="tab in tabs"
            :key="tab.file"
            :header="t(tab.i18nKey)">
            <div class="flex flex-col gap-2">
              <div class="flex items-center justify-between">
                <span class="text-sm text-gray-500 dark:text-gray-400">{{ t(tab.i18nDescKey) }}</span>
                <span
                  :class="[
                    'text-xs',
                    (editContent[tab.file]?.length ?? 0) > MAX_CHARS
                      ? 'text-red-500'
                      : (editContent[tab.file]?.length ?? 0) > MAX_CHARS * 0.9
                        ? 'text-orange-500'
                        : 'text-gray-400'
                  ]">
                  {{ editContent[tab.file]?.length ?? 0 }} / {{ MAX_CHARS }}
                </span>
              </div>
              <Textarea
                v-model="editContent[tab.file]"
                :autoResize="true"
                rows="12"
                class="w-full font-mono text-sm"
                :maxlength="MAX_CHARS"
                :pt="{ root: { style: 'max-height: 400px; overflow: auto' } }" />
            </div>
          </TabPanel>

          <TabPanel :header="t('config.tabs.character')">
            <div class="flex flex-col gap-4">
              <div class="flex items-center gap-4">
                <div class="flex flex-col items-center gap-2">
                  <img
                    v-if="charPreview.aiAvatar"
                    :src="charPreview.aiAvatar"
                    class="w-16 h-16 rounded-full object-cover border border-solid border-gray-light dark:border-gray-dark" />
                  <div v-else class="w-16 h-16 rounded-full bg-gray-100 dark:bg-gray-700 flex items-center justify-center text-2xl">🤖</div>
                  <input ref="aiAvatarInputRef" type="file" accept="image/*" class="hidden" @change="onAvatarSelected('assistant', $event)" />
                  <Button :label="t('config.uploadAvatar')" icon="pi pi-upload" size="small" variant="text" @click="aiAvatarInputRef?.click()" />
                </div>
                <div class="flex-1 flex flex-col gap-1">
                <label class="text-sm text-gray-500 dark:text-gray-400">{{ t('config.aiName') }}</label>
                <InputText v-model="charEdit.assistant.name" class="w-full" />
                </div>
              </div>

              <div class="flex items-center gap-4">
                <div class="flex flex-col items-center gap-2">
                  <img
                    v-if="charPreview.userAvatar"
                    :src="charPreview.userAvatar"
                    class="w-16 h-16 rounded-full object-cover border border-solid border-gray-light dark:border-gray-dark" />
                  <div v-else class="w-16 h-16 rounded-full bg-gray-100 dark:bg-gray-700 flex items-center justify-center text-2xl">👤</div>
                  <input ref="userAvatarInputRef" type="file" accept="image/*" class="hidden" @change="onAvatarSelected('user', $event)" />
                  <Button :label="t('config.uploadAvatar')" icon="pi pi-upload" size="small" variant="text" @click="userAvatarInputRef?.click()" />
                </div>
                <div class="flex-1 flex flex-col gap-1">
                <label class="text-sm text-gray-500 dark:text-gray-400">{{ t('config.userName') }}</label>
                <InputText v-model="charEdit.user.name" class="w-full" />
                </div>
              </div>
            </div>
          </TabPanel>
        </TabView>
      </template>
    </div>
    <template #footer>
      <div class="flex gap-2 justify-end">
        <Button
          :label="t('config.cancel')"
          icon="pi pi-times"
          severity="secondary"
          @click="visible = false" />
        <Button
          :label="t('config.save')"
          icon="pi pi-check"
          :loading="saving"
          :disabled="!canSave"
          @click="handleSave" />
      </div>
    </template>
  </Dialog>
</template>

<script lang="ts" setup>
import { ref, computed, useTemplateRef } from 'vue';
import { useI18n } from 'vue-i18n';
import { readSystemPrompt, writeSystemPrompt, readCharacter, updateCharacter, uploadAvatar } from '@/composables/bridge';

const { t } = useI18n();

const props = defineProps<{ modelValue: boolean }>();
const emits = defineEmits<{
  'update:modelValue': [value: boolean];
  saved: [];
}>();

const visible = computed({
  get: () => props.modelValue,
  set: (v) => emits('update:modelValue', v),
});

const MAX_CHARS = 2000;

const tabs = [
  { file: 'AGENTS.md', i18nKey: 'config.tabs.agents', i18nDescKey: 'config.desc.agents' },
  { file: 'IDENTITY.md', i18nKey: 'config.tabs.identity', i18nDescKey: 'config.desc.identity' },
  { file: 'SOUL.md', i18nKey: 'config.tabs.soul', i18nDescKey: 'config.desc.soul' },
  { file: 'USER.md', i18nKey: 'config.tabs.user', i18nDescKey: 'config.desc.user' },
] as const;

const activeTab = ref(0);
const loading = ref(false);
const saving = ref(false);
const editContent = ref<Record<string, string>>({});
const originalContent = ref<Record<string, string>>({});

const charEdit = ref<{ user: { name: string; avatar: string }; assistant: { name: string; avatar: string } }>({
  user: { name: '', avatar: '' },
  assistant: { name: '', avatar: '' },
});
const charOriginal = ref('');
const charPreview = ref<{ userAvatar: string; aiAvatar: string }>({ userAvatar: '', aiAvatar: '' });

const aiAvatarInputRef = useTemplateRef<HTMLInputElement>('aiAvatarInputRef');
const userAvatarInputRef = useTemplateRef<HTMLInputElement>('userAvatarInputRef');

const backendBaseUrl = import.meta.env.VITE_API_BACK_URL || 'http://localhost:8080';
const resolveAvatarUrl = (path: string) => (path ? `${backendBaseUrl.replace(/\/+$/, '')}/static/${path.replace(/^\/+/, '')}` : '');

const canSave = computed(() => {
  if (loading.value || saving.value) return false;
  const promptValid = tabs.every(
    (tab) =>
      (editContent.value[tab.file]?.length ?? 0) <= MAX_CHARS &&
      (editContent.value[tab.file]?.length ?? 0) > 0,
  );
  const charValid = charEdit.value.assistant.name.trim().length > 0 && charEdit.value.user.name.trim().length > 0;
  return promptValid && charValid;
});

const loadContent = async () => {
  loading.value = true;
  activeTab.value = 0;
  try {
    const [data, charData] = await Promise.all([readSystemPrompt(), readCharacter()]);
    const content: Record<string, string> = {};
    for (const tab of tabs) {
      content[tab.file] = data[tab.file] ?? '';
    }
    editContent.value = { ...content };
    originalContent.value = { ...content };

    const user = charData?.user ?? {};
    const assistant = charData?.assistant ?? {};
    charEdit.value = {
      user: { name: user.name ?? '', avatar: user.avatar ?? '' },
      assistant: { name: assistant.name ?? '', avatar: assistant.avatar ?? '' },
    };
    charOriginal.value = JSON.stringify(charEdit.value);
    charPreview.value = {
      userAvatar: resolveAvatarUrl(user.avatar ?? ''),
      aiAvatar: resolveAvatarUrl(assistant.avatar ?? ''),
    };
  } catch (e) {
    console.error('[ConfigDialog] Failed to load:', e);
  } finally {
    loading.value = false;
  }
};

const onAvatarSelected = async (role: 'user' | 'assistant', event: Event) => {
  const input = event.target as HTMLInputElement;
  const file = input.files?.[0];
  if (!file) return;
  try {
    const relativePath = await uploadAvatar(file);
    charEdit.value[role].avatar = relativePath;
    charPreview.value[role === 'user' ? 'userAvatar' : 'aiAvatar'] = resolveAvatarUrl(relativePath);
  } catch (e) {
    console.error('[ConfigDialog] Avatar upload failed:', e);
  } finally {
    input.value = '';
  }
};

const handleSave = async () => {
  saving.value = true;
  try {
    const fileToContent: Record<string, string> = {};
    for (const tab of tabs) {
      const content = editContent.value[tab.file] ?? '';
      if (content !== (originalContent.value[tab.file] ?? '')) {
        fileToContent[tab.file] = content;
      }
    }
    if (Object.keys(fileToContent).length > 0) {
      await writeSystemPrompt(fileToContent);
    }

    const charChanged = JSON.stringify(charEdit.value) !== charOriginal.value;
    if (charChanged) {
      await updateCharacter({
        user: { name: charEdit.value.user.name, avatar: charEdit.value.user.avatar },
        assistant: { name: charEdit.value.assistant.name, avatar: charEdit.value.assistant.avatar },
      });
    }

    emits('saved');
    visible.value = false;
  } catch (e) {
    console.error('[ConfigDialog] Failed to save:', e);
  } finally {
    saving.value = false;
  }
};

const onHide = () => {
  activeTab.value = 0;
};
</script>
```

**关键设计说明**：

- **第 5 个 TabPanel**（`config.tabs.character`）：包含两组"头像+名称"表单，一组 AI（`assistant`），一组用户（`user`）。
- **头像上传流程**：点击"上传头像"按钮 → 触发隐藏的 `<input type="file">` → 选择图片后 `onAvatarSelected` 调用 `uploadAvatar(file)` 上传到服务器 → 服务器返回相对路径 `avatar/xxx.png` → 更新 `charEdit[role].avatar` 和 `charPreview` 预览图。
- **`useTemplateRef`**：Vue 3.5+ API，用于获取 `<input>` DOM 引用以编程触发 `click()`。
- **`resolveAvatarUrl(path)`**：将 `avatar/xxx.png` 拼接为 `{baseURL}/static/avatar/xxx.png` 完整 URL，用于 `<img :src>` 预览。
- **`loadContent`**：使用 `Promise.all` 并行加载 system prompt 和 character 数据，减少加载时间。
- **`charOriginal`**：保存 character 数据的 JSON 字符串快照，`handleSave` 时对比检测是否有变更，仅在变更时调用 `updateCharacter()`。
- **`emits('saved')`**：保存成功后通知父组件 `index.vue` 重新加载角色信息，使页面立即显示新头像和名称。
- **`canSave` computed**：在原有 system prompt 校验基础上，新增 `charValid` 校验（AI 名称和用户名称均非空）。
- 依赖 PrimeVue 组件：`Dialog`、`TabView`、`TabPanel`、`Textarea`、`Button`、`ProgressSpinner`、`InputText`（已全局注册）。

## 附录：服务端 API 参考

### 已有端点（无需修改）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/character` | 读取 `workspace/character.json`，返回 `{"user": {"name": "...", "avatar": "..."}, "assistant": {"name": "...", "avatar": "..."}}` |
| PUT | `/character` | 全量覆盖 `character.json`，请求体 `{"character_data": {...}}` |
| PATCH | `/character` | 部分更新（实际 Robyn 路由中浏览器模式走 PUT） |

### 新增端点

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | `/character/avatar` | 原始图片字节（Content-Type: image/png 等） | `{"success": true, "path": "avatar/xxx.png"}` |

### 服务端 character.json 格式

```json
{
    "user": {
        "name": "用户名",
        "avatar": "avatar/xxx.png"
    },
    "assistant": {
        "name": "AI名",
        "avatar": "avatar/yyy.png"
    }
}
```

- `avatar` 字段是相对 `static/` 的路径，前端通过 `{baseURL}/static/{avatar}` 访问图片。
- `update_character()` 仅更新 `name` 和 `avatar` 字段，验证规则：必须为非空字符串（`server/service/workplace.py` 第 74-91 行）。

### 静态文件服务

`config/path.py` 中 `STATIC_DIR = ROOT_DIR / "static"`。头像保存到 `static/avatar/` 子目录，通过 `http://{host}:{port}/static/avatar/xxx.png` 访问（Robyn 静态文件服务）。

## 附录：旧版 ConfigDialog.vue 原始代码

> 这是执行本改动前的 ConfigDialog.vue（4 Tab 版本，由"系统配置弹窗修改说明书"创建）。

```vue
<template>
  <Dialog
    v-model:visible="visible"
    :header="t('config.title')"
    :modal="true"
    :closable="true"
    class="w-[90vw] md:w-[700px]"
    @show="loadContent"
    @hide="onHide">
    <div class="flex flex-col gap-3">
      <div v-if="loading" class="flex items-center justify-center py-8">
        <ProgressSpinner style="width: 2rem; height: 2rem" />
      </div>
      <template v-else>
        <TabView v-model:activeIndex="activeTab">
          <TabPanel
            v-for="tab in tabs"
            :key="tab.file"
            :header="t(tab.i18nKey)">
            <div class="flex flex-col gap-2">
              <div class="flex items-center justify-between">
                <span class="text-sm text-gray-500 dark:text-gray-400">{{ t(tab.i18nDescKey) }}</span>
                <span
                  :class="[
                    'text-xs',
                    (editContent[tab.file]?.length ?? 0) > MAX_CHARS
                      ? 'text-red-500'
                      : (editContent[tab.file]?.length ?? 0) > MAX_CHARS * 0.9
                        ? 'text-orange-500'
                        : 'text-gray-400'
                  ]">
                  {{ editContent[tab.file]?.length ?? 0 }} / {{ MAX_CHARS }}
                </span>
              </div>
              <Textarea
                v-model="editContent[tab.file]"
                :autoResize="true"
                rows="12"
                class="w-full font-mono text-sm"
                :maxlength="MAX_CHARS"
                :pt="{ root: { style: 'max-height: 400px; overflow: auto' } }" />
            </div>
          </TabPanel>
        </TabView>
      </template>
    </div>
    <template #footer>
      <div class="flex gap-2 justify-end">
        <Button
          :label="t('config.cancel')"
          icon="pi pi-times"
          severity="secondary"
          @click="visible = false" />
        <Button
          :label="t('config.save')"
          icon="pi pi-check"
          :loading="saving"
          :disabled="!canSave"
          @click="handleSave" />
      </div>
    </template>
  </Dialog>
</template>

<script lang="ts" setup>
import { ref, computed, watch } from 'vue';
import { useI18n } from 'vue-i18n';
import { readSystemPrompt, writeSystemPrompt } from '@/composables/bridge';

const { t } = useI18n();

const props = defineProps<{ modelValue: boolean }>();
const emits = defineEmits<{ 'update:modelValue': [value: boolean] }>();

const visible = computed({
  get: () => props.modelValue,
  set: (v) => emits('update:modelValue', v),
});

const MAX_CHARS = 2000;

const tabs = [
  { file: 'AGENTS.md', i18nKey: 'config.tabs.agents', i18nDescKey: 'config.desc.agents' },
  { file: 'IDENTITY.md', i18nKey: 'config.tabs.identity', i18nDescKey: 'config.desc.identity' },
  { file: 'SOUL.md', i18nKey: 'config.tabs.soul', i18nDescKey: 'config.desc.soul' },
  { file: 'USER.md', i18nKey: 'config.tabs.user', i18nDescKey: 'config.desc.user' },
] as const;

const activeTab = ref(0);
const loading = ref(false);
const saving = ref(false);
const editContent = ref<Record<string, string>>({});
const originalContent = ref<Record<string, string>>({});

const canSave = computed(() => {
  if (loading.value || saving.value) return false;
  return tabs.every(
    (tab) =>
      (editContent.value[tab.file]?.length ?? 0) <= MAX_CHARS &&
      (editContent.value[tab.file]?.length ?? 0) > 0,
  );
});

const loadContent = async () => {
  loading.value = true;
  try {
    const data = await readSystemPrompt();
    const content: Record<string, string> = {};
    for (const tab of tabs) {
      content[tab.file] = data[tab.file] ?? '';
    }
    editContent.value = { ...content };
    originalContent.value = { ...content };
  } catch (e) {
    console.error('[ConfigDialog] Failed to load system prompts:', e);
  } finally {
    loading.value = false;
  }
};

const handleSave = async () => {
  saving.value = true;
  try {
    const fileToContent: Record<string, string> = {};
    for (const tab of tabs) {
      const content = editContent.value[tab.file] ?? '';
      if (content !== (originalContent.value[tab.file] ?? '')) {
        fileToContent[tab.file] = content;
      }
    }
    if (Object.keys(fileToContent).length > 0) {
      await writeSystemPrompt(fileToContent);
    }
    visible.value = false;
  } catch (e) {
    console.error('[ConfigDialog] Failed to save system prompts:', e);
  } finally {
    saving.value = false;
  }
};

const onHide = () => {
  activeTab.value = 0;
};
</script>
```
